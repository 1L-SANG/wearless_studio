## 제1조 개인정보의 처리 목적

회사는 다음 목적을 위하여 개인정보를 처리합니다. 처리하는 개인정보는 다음 목적 이외의 용도로는 이용하지 않으며, 목적이 변경되는 경우 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 이행합니다.

| 목적 | 구체 내용 |
|---|---|
| 1. 모델 지원 심사 | 지원서 접수, 자격 요건(만 19세 이상·전속 소속사 없음·본인 사진) 확인, 심사 결과 회신 |
| 2. 회원 관리 | 계정 생성·로그인, 본인 식별, 부정 이용 방지, 고지·통지 |
| 3. 본인확인 | 정부 발급 신분증(모바일 신분증) 기반 성인 여부 및 동일인 확인, 등록 사진과 신분증 얼굴의 동일인 검증 |
| 4. 디지털 DNA(아이덴티티 팩) 제작 | 모델이 제출한 얼굴·전신 사진으로 AI가 모델을 일관되게 그리기 위한 참조 자산(다각도 얼굴 시트, 조각 이미지, 모델별 학습 가중치 등)을 제작 |
| 5. 착용컷 생성 | 셀러가 라이선스 조건 안에서 요청한 상품 착용컷 생성 시 모델의 얼굴 참조 입력 |
| 6. 라이선스 관리 | 모델이 정한 사용 조건(허용·제외 품목, 단가, 유효기간)의 저장·변경 이력 관리, 사용 게이트 판정, 라이선스 증서(VC) 발급·검증 |
| 7. 사용 기록·정산 | 착용컷 사용 건별 기록(셀러·품목·일시·금액), 원장 및 블록체인 공증, 정산 명세 작성, 지급, 세무 신고 |
| 8. 알림 | 심사 결과·등록 진행·사용 발생·정산 안내 등 서비스 통지 |
| 9. 품질 검사·분쟁 대응 | 생성 결과물의 얼굴 동일성 검사, 무단 사용 신고 처리, 위반 조사, 분쟁 해결 |
| 10. 서비스 개선 (선택 동의 시) | 생성 품질 향상을 위한 모델별 자산의 통계·품질 분석 |
| 11. 마케팅 (선택 동의 시) | 모집·소식 안내 이메일·문자 발송 |

## 제2조 처리하는 개인정보의 항목

### 1. 모델(개인 회원)

| 단계 | 필수 항목 | 선택 항목 |
|---|---|---|
| 지원서 | 성·이름, 이메일, 생년월일, 거주 지역(시·국가), 성별, 모델 경력 수준, 관심 품목, 회사가 안내한 장수의 사진 | 전화번호, SNS 링크, 유입 경로 |
| 계정 | 이메일, 로그인 자격증명(비밀번호 또는 소셜 로그인 식별자) | — |
| 본인확인 | 본인확인기관이 회사에 전달하는 **본인확인 결과값**(성인 여부, 출생 연도, 중복가입확인정보(DI)/연계정보(CI)), 모바일 신분증 검증 결과. **신분증 얼굴 부분은 동일인 대조를 위해 메모리에서만 일시 처리하고 저장하지 않음** | — |
| 얼굴·신체 | **얼굴 사진(정면·측면·45도 등 N장, 서비스 설정에 따라 최대 20장)**, **얼굴 특징정보(동일인 검증용 벡터)**, 키 밴드·체형·상의/하의 사이즈, 어울리는 스타일 | 전신 사진 |
| 라이선스 | 허용·제외 품목, 건당 가격(또는 회사가 정한 가격 모델에 따른 요율), 유효기간, 라이선스 증서(VC) 및 분산식별자(DID), 조건 변경 이력 | — |
| 정산 | 정산 대상 사용 기록, 실명, 계좌 정보(예금주·은행·계좌번호), 세무 신고에 필요한 정보(주민등록번호는 **소득세법 등 법령이 요구하는 경우에 한해** 지급 시점에 별도 고지·수집) | — |
| 활동명·프로필 | 활동명(또는 성만 표시된 이름), 연령대, 대표 컷·테스트 컷 | — |

### 2. 셀러(사업자 이용자)

이메일·로그인 정보, 사업자 정보(상호·사업자등록번호·대표자·연락처), 결제 정보(결제대행사가 처리하며 회사는 결제 승인 결과·거래 식별자만 보유), 착용컷 생성 요청·라이선스 구매 기록.

### 3. 자동으로 수집되는 정보

IP 주소, 접속 일시, 브라우저·기기 정보, 서비스 이용 기록(화면 이동·생성 요청·오류 로그), 세션 쿠키. 광고 식별자(ADID/IDFA)와 행태정보는 수집하지 않습니다.

### 4. 민감정보(생체인식정보) — 별도 동의

얼굴 사진, 얼굴 특징정보, 디지털 DNA(아이덴티티 팩 및 모델별 학습 가중치)는 「개인정보 보호법」 제23조의 **민감정보(생체인식정보)**에 해당합니다. 회사는 이를 **일반 개인정보와 분리하여 별도의 동의**(동의서 B-1)를 받아 처리하며, 그 동의는 정보주체 본인만 할 수 있습니다. 상세는 제14조.

### 5. 고유식별정보

회사는 주민등록번호·여권번호·운전면허번호·외국인등록번호를 수집하지 않습니다. 본인확인은 본인확인기관과 모바일 신분증 검증 서비스를 통해 이루어지며, 회사는 **신분증 원본 이미지를 저장하지 않고** 신분증 번호를 받지 않습니다. 정산 지급 시 세법상 주민등록번호 수집이 불가피한 경우에는 소득세법 제145조 등 법령 근거를 고지하고 지급 단계에서 별도로 수집합니다.

## 제3조 개인정보의 처리 및 보유 기간

회사는 법령에 따른 보유·이용기간 또는 정보주체로부터 동의받은 보유·이용기간 내에서 개인정보를 처리·보유합니다.

| 처리 업무 | 보유 기간 | 근거 |
|---|---|---|
| 지원서(반려·취소) | 심사 종료 후 **30일** 내 삭제(익명화) | 정보주체 동의 |
| 지원서(승인) | 회원 탈퇴 또는 라이선스 종료 시까지(운영 기록) | 계약 이행 |
| 계정 정보 | 회원 탈퇴 시까지. 단, 부정 이용 기록은 탈퇴 후 1년 | 계약 이행·부정 이용 방지 |
| 본인확인 결과값(CI/DI·출생 연도) | 회원 탈퇴 시까지 | 계약 이행·중복 가입 방지 |
| **신분증 얼굴 부분(대조용)** | **저장하지 않음** — 자동 대조 처리 직후 메모리에서 삭제 | — |
| **얼굴 사진·얼굴 특징정보·디지털 DNA** | 라이선스 유지 기간. 철회·탈퇴 시 **30일 내 파기, 백업 저장소 90일 내 완전 삭제** | 정보주체 동의(민감정보) |
| 라이선스 조건·변경 이력·증서(VC) | 라이선스 종료 후 **5년** (증서는 폐기 상태로 보존) | 분쟁 대응, 전자상거래법 제6조 |
| 사용 기록·정산 명세 | **5년** | 전자상거래법 제6조, 국세기본법 제85조의3 |

| 동의 기록(동의 일시·문서 버전·IP) | 해당 동의의 효력 종료 후 **5년** | 「개인정보 보호법」 제22조 입증 책임 |
| 알림·문의·분쟁 처리 기록 | **3년** | 전자상거래법 제6조 |
| 개인정보처리시스템 접속기록(취급자) | **2년** (민감정보 처리 시스템) | 개인정보의 안전성 확보조치 기준 제8조 |
| 회원 로그인 기록 | 1년 | 통신비밀보호법 제15조의2 |
| 블록체인 공증 기록 | 삭제 불가능한 매체 특성상 **개인정보를 기록하지 않음**(해시값과 금액만 기록) | — |

## 제4조 개인정보의 제3자 제공

회사는 정보주체의 동의, 법률의 특별한 규정 등 「개인정보 보호법」 제17조 및 제18조에 해당하는 경우에만 개인정보를 제3자에게 제공합니다.

| 제공받는 자 | 제공 목적 | 제공 항목 | 보유·이용 기간 |
|---|---|---|---|
| 셀러(쇼핑몰 사업자) — 모델을 선택·사용한 자 | 상품 상세페이지 착용컷 게시 | **완성된 착용컷 이미지**, 라이선스 명세(활동명, 사용 품목, 기간, 라이선스 번호) | 해당 라이선스 기간(영구 옵션 포함) |
| 셀러 전체(로그인한 사업자) 및 프로필 공개를 선택한 경우 누구나 | 모델 검색·선택 | 활동명(또는 성만 표시된 이름), 연령대, 키 밴드·체형·사이즈·스타일, 사용 조건, 대표 컷·테스트 컷 축소본 | 프로필 공개 기간 |
| 라이선스 검증 페이지 열람자 | 라이선스 진위 확인 | 라이선스 번호, 상태(활성·철회·만료), 사용 조건, **마스킹된 이름** | 라이선스 종료 후 5년 |
| 수사기관·법원 등 | 법령에 따른 요청 | 법령이 정한 범위 | 법령이 정한 기간 |

셀러에게는 **원본 사진, 얼굴 특징정보, 디지털 DNA 자산을 제공하지 않으며**, 착용컷 이외의 얼굴 이미지는 어떤 경우에도 회사 파이프라인 밖으로 반출되지 않습니다. 셀러는 회사와의 라이선스 이용조건에 따라 착용컷을 정해진 범위(스튜디오 배경 상품 착용컷, 해당 상품 상세페이지) 밖으로 사용할 수 없습니다.

## 제7조 개인정보의 파기 절차 및 방법

1. 회사는 보유기간 경과, 처리 목적 달성, 동의 철회 등 개인정보가 불필요하게 되었을 때 지체 없이 파기합니다.
2. 전자적 파일은 복구·재생이 불가능한 방법으로 영구 삭제하고, 종이 문서는 분쇄·소각합니다. 법령에 따라 보존해야 하는 정보는 별도 저장소로 옮겨 접근을 통제한 뒤 보존합니다.
3. **생체정보 파기 캐스케이드**: 모델이 라이선스를 철회하거나 탈퇴하면 ① 즉시 프로필을 내리고 새 생성을 차단하며 ② 30일 이내에 원본 사진·얼굴 특징정보·디지털 DNA 자산(시트·조각·학습 가중치)·테스트 컷을 회사 시스템과 처리위탁자의 시스템에서 파기하고 ③ 백업 저장소에서는 90일 이내에 완전히 삭제하며 ④ 파기 완료 시 정보주체에게 통지합니다. 파기 대상에서 제외되는 것은 다음뿐입니다. ⓐ 이미 발행된 건별 라이선스의 착용컷과 라이선스 명세·출처 정보(해당 라이선스 종료 시 파기) ⓑ 법령이 보관을 요구하는 기록(제3조) ⓒ 진행 중인 분쟁의 증빙.
4. 블록체인에는 개인정보가 기록되지 않으므로 파기 대상이 없습니다. 라이선스 증서(VC)는 철회 시 폐기 상태로 전환되어 검증 시 "철회됨"으로 표시됩니다.

## 제13조 AI 학습·생성에 관한 투명성

1. **본인 디지털 DNA 제작을 위한 처리**: 회사는 모델이 제출한 사진으로 그 모델만을 위한 참조 자산과 모델별 학습 가중치(예: 미세조정 가중치)를 만듭니다. 이는 제1조 제4호의 목적 내 처리이며, 그 결과물은 해당 모델의 착용컷 생성에만 사용되고 다른 인물의 생성이나 범용 모델의 학습에 사용되지 않습니다.
2. **타 모델 학습 금지**: 회사는 정보주체의 얼굴 정보를 다른 인물을 생성하는 모델이나 범용 생성 모델의 학습 데이터로 사용하지 않으며, 제3자에게 학습 목적으로 제공하지 않습니다.
3. **선택 동의에 따른 품질 향상 처리**: 정보주체가 별도로 동의한 경우에 한하여 생성 결과의 품질 통계·오류 분석에 해당 모델의 생성 기록을 활용합니다. 동의하지 않아도 서비스 이용에 제한이 없으며 언제든 철회할 수 있습니다.
4. **삭제 요구**: 정보주체는 언제든 본인 자산의 삭제를 요구할 수 있으며 제7조 제3항의 절차에 따릅니다.
5. **생성물 표시**: 회사가 생성한 착용컷에는 AI 생성물임을 알 수 있는 표시와 출처 정보(C2PA 콘텐츠 자격증명)를 부착하며(외부 플랫폼 업로드 시 재인코딩으로 출처 정보가 제거될 수 있음), 라이선스 검증 페이지에서 정식 라이선스 여부를 확인할 수 있습니다.

| 처리 목적 | ① 동일인 검증 ② 디지털 DNA 제작 ③ 라이선스 조건 안에서의 착용컷 생성 ④ 생성 품질 검사 — 이 네 가지 외에는 사용하지 않음 |
| 보유 기간 | 라이선스 유지 기간. 철회·탈퇴 시 30일 내 파기, 백업 90일 내 완전 삭제. 신분증 얼굴 부분은 저장하지 않음 |
| 제3자 제공 | 완성된 착용컷만 셀러에게 제공. 원본·특징정보·자산은 어떤 제3자에게도 제공하지 않음 |
| 처리 위탁·국외 이전 | 제5·6조. 이미지 생성 사업자에는 생성 요청 시에만 전송, 사업자 정책에 따라 최대 55일 보관 후 삭제(학습 미사용) |
| 공개 가능성 | 회사는 원본 얼굴 사진을 공개하지 않음. 프로필 공개를 선택한 경우 대표 컷·테스트 컷 축소본이 노출되며 언제든 비공개로 전환 가능 |
| 동의 방식 | 일반 개인정보 동의와 분리한 별도 동의서(B-1)에 본인이 직접 동의. 소속사·가족·대리인의 대리 동의 불인정. 회사는 **초상 라이선스 계약에 전자서명한 뒤에만** 얼굴 사진의 업로드와 처리를 시작함 |
| 처리 시작 시점 | 지원서 사진은 심사 목적으로만 처리하며 디지털 DNA 제작에 쓰지 않음. 생체정보 처리는 등록 위저드에서 B-1·B-2·B-3 동의와 계약 서명이 끝난 뒤 시작 |
| 안전성 조치 | 공개 URL 금지, 1시간 서명 주소, 접근 권한 최소화, 원본 반출 차단(제10조) |

## 제15조 미성년자 보호

서비스는 **만 19세 이상**만 이용할 수 있습니다. 회사는 만 14세 미만 아동의 개인정보를 수집하지 않으며, 본인확인 결과 만 19세 미만으로 확인되면 등록을 중단하고 수집한 정보를 지체 없이 파기합니다. 보호자 동의를 통한 미성년자 등록 경로를 운영하지 않습니다.
