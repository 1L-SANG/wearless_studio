# 의류 협찬 참여 동의
### E-2. 의류 협찬 참여 (선택)

> **기본 꺼짐, 전체 동의 제외.** 협찬을 하지 않아도 등록·얼굴 사용·정산에는 아무 불이익이 없어요. 참여 토글과 프로필 정보 수집 체크는 각기 다른 동의이며 사전 체크하지 않아요. 배송정보 동의는 실제 요청이 생기는 후속 단계에서만 받아요. 요청 기능이 준비 중인 동안은 참여 의사와 프로필만 저장하며, 배송지를 받거나 게시 의무를 발생시키지 않아요.

#### E-2a. 참여 토글 (선택, 켜는 동작이 동의 행위)

**의류 협찬 받기: 꺼짐(기본값)**

**나는 만 19세 이상이며 소속 에이전시가 없고 본인이 직접 참여합니다. 아래 내용을 읽고 의류 협찬 참여에 동의합니다.**

- 받는 것은 셀러가 증정하는 옷이에요. 증정, 반납 없음, 현금 지급 없음이에요.
- 옷 수령 후 7일 이내 본인 인스타그램 피드에 착용 게시물 1회 게시하고, 게시일부터 90일 유지해요. 릴스·영상·브랜드 채널 납품은 포함하지 않아요.
- 켜 둔 동안 셀러가 바로 요청하며 건별 수락은 없어요. 요청 품목은 내가 정한 기존 허용 품목 안으로 한정돼요. 팔로워 수에 따른 참여 제한이나 요청 보장은 없어요.
- 마이페이지에서 언제든 끌 수 있어요. 끄면 새 요청은 멈추고, 켜 둔 동안 유효하게 온 요청은 진행해요. 라이선스 철회·탈퇴 시에도 자동으로 꺼져요. 미배송·하자·품목 위반 등은 회사에 알려 조정을 요청할 수 있고 법령상 권리는 그대로예요.
- 게시물은 내가 촬영·게시하는 내 콘텐츠예요. 셀러나 회사가 쇼핑몰·광고 등에 2차 활용하려면 별도 합의와 필요한 권리 처리가 있어야 해요. 협찬은 초상 라이선스·착용컷 정산과 별개이며 VC에 들어가지 않아요.
- 옷만 받아도 경제적 이해관계를 표시해요. 회사가 제공하는 캡션 문구는 첫 줄의 **“광고 | ○○에서 의류를 무상 제공받아 작성했어요.”** 예요. ○○에는 실제 제공 브랜드명 또는 셀러 상호를 넣어요. 사진과 캡션이 함께 보이지 않으면 사진 안에도 “광고·의류 무상 제공”을 표시하고, 더보기 뒤나 댓글에만 숨기지 않아요.

근거: 「추천·보증 등에 관한 표시·광고 심사지침」(공정거래위원회예규 제499호, 2026-06-01 시행) Ⅴ.6.가., 나.(1)~(4), 다.(2)(가)①~④. 캡션은 회사가 정한 구체적 문구이며 지침에 이 문장 전체가 고정 문안으로 정해져 있는 것은 아니에요.

#### E-2b. 프로필 정보 수집 (선택, 협찬을 켤 때는 필수 체크)

**☐ 프로필 정보 수집에 동의합니다.**

| 항목 | 내용 |
|---|---|
| 수집 항목 | 인스타그램 계정, 팔로워 수(본인 입력)와 기준일, 상의·하의 사이즈 |
| 목적 | 협찬 참여 설정과 프로필 관리. 협찬 모델을 찾는 로그인한 셀러(쇼핑몰 사업자)에게 인스타그램 계정·팔로워 수·사이즈를 열람시켜요. 배송지·연락처는 포함하지 않고, 비로그인 대중에게는 공개하지 않아요 |
| 보유 기간 | 협찬 off 또는 탈퇴 시 지체 없이 파기. 진행 중 건의 최소 이행 정보와 증빙은 처리방침 제3조에 따라 분리해요 |
| 거부권·효과 | 거부할 수 있어요. 이 정보 없이는 협찬 설정만 할 수 없고, 모델 등록·초상 라이선스·정산은 계속 이용할 수 있어요. 인스타그램 계정을 적었다면 이 체크 없이는 협찬을 켤 수 없어요 |
| 철회 | 마이페이지에서 협찬을 끄거나 개인정보 보호책임자에게 요청해요 |

#### E-2c. (E-2b에 합침, 2026-09-22 오너 결정)

로그인한 셀러에게 협찬 프로필을 열람시키는 것은 E-2b의 수집 목적에 고지해 한 번의 체크로 받아요. 별도의 제3자 제공 동의가 필요한지는 변호사 검토 포인트로 남겨요.

토글은 동의 목록 안이 아니라 인스타그램 계정 입력란 옆에 둬요. 토글을 켜면 입력란과 E-2b 체크가 함께 나타나고, 체크 없이는 켬을 저장할 수 없어요. 전체 동의로 한꺼번에 체크하지 않아요. 비로그인 대중에게 공개하는 동의가 아니에요.

#### E-2d. 요청 후 배송정보 동의 (선택, 등록 단계에서는 표시하지 않음)

등록 단계에서는 배송지·연락처를 묻지 않아요. 실제 협찬 요청이 온 뒤 그 요청 화면에서만 아래 두 체크를 받아요.

**☐ 해당 요청의 배송을 위한 개인정보 수집·이용에 동의합니다.** (E-2d-1)

| 항목 | 내용 |
|---|---|
| 수집 항목 | 배송지, 배송 연락처 |
| 목적 | 해당 요청의 의류 발송·배송 연락 |
| 보유 기간 | 발송 완료 후 30일 이내 파기. 발송 취소·동의 철회·목적 조기 달성 시 지체 없이 파기해요 |
| 거부권·효과 | 거부할 수 있어요. 거부하면 해당 요청의 배송을 진행할 수 없고, 기존 모델 활동에는 불이익이 없어요 |
| 철회 | 해당 요청 화면 또는 개인정보 보호책임자에게 요청해요 |

**☐ 해당 요청 셀러에게 아래 정보를 제공하는 것에 동의합니다.** (E-2d-2, 위 체크와 별개)

| 항목 | 내용 |
|---|---|
| 제공받는 자 | 해당 협찬 요청의 실제 셀러 상호와 사업자 식별정보를 동의 직전 표시해요. 미표시 상태에서는 동의를 받지 않아요 |
| 목적 | 해당 의류 발송과 배송 연락 |
| 제공 항목 | 배송지·연락처·상의 및 하의 사이즈·인스타그램 계정. 팔로워 수는 발송 목적으로 제공하지 않아요 |
| 보유·이용 기간 | 발송 완료 후 30일 이내 파기. 발송 취소·제공 동의 철회·목적 조기 달성 시 지체 없이 파기해요 |
| 거부권·효과 | 거부할 수 있어요. 거부하면 해당 셀러에게 정보를 주지 않아 배송이 진행되지 않아요. 거부 자체로 제재하거나 기존 모델 활동을 제한하지 않아요 |
| 철회 | 해당 요청 화면 또는 개인정보 보호책임자에게 요청하면 회사가 셀러에게 알리고 파기 여부를 확인해요 |

배송 동의는 이미 온 요청의 개인정보 처리 선택이며 **건별 협찬 수락 버튼이 아니에요.** 아직 누구인지 모르는 모든 셀러에게 등록 시점에 포괄 동의하지 않아요. 거부·철회로 이행이 어려워진 건은 별도 조정하며 동의를 강요하지 않아요.

#### E-2 기록·철회·개정 규칙

각 동의·철회에 계정 ID, 서버 UTC 일시, 유형, 문서 버전, IP, 화면, 행위, 문안 해시를 기록해요. 요청별 동의에는 요청 ID와 실제 셀러 식별정보, 제공 목적·항목·보유기간 고지본을 더해요. 배송지·연락처 원문은 동의 로그에 복제하지 않아요. 기본 꺼짐은 동의나 철회로 추정하지 않아요.

off와 라이선스 철회·탈퇴 때 참여·프로필 정보 수집 철회 이력을 각각 남기고, 신규 요청 차단과 프로필 비노출을 같은 저장 작업으로 처리해요. 진행 중 요청의 배송 동의 철회는 요청별 기록으로 구분해요. 동의 증빙은 해당 동의 효력 종료 후 5년 보관하며 기본 프로필과 섞지 않아요.

협찬 처리 범위가 바뀌면 해당 항목 버전을 올리고 참여자에게 다시 동의를 받아요. 동의 전에는 새 범위 처리와 새 요청만 막으며, 비참여 기존 모델에게 협찬 동의를 필수로 요구하지 않아요. 처리방침은 확인·고지하고, 개인정보 처리 동의를 대신하지 않아요.
