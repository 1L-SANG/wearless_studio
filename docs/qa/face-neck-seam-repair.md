# 목·옷깃 경계 수리

Qwen 얼굴 패스 성공 뒤 사진별 손상 문장·마스크·합성 범위를 만들고, Sunburst로 목 크롭을 편집한다. 기본값은 `FACE_SEAM_REPAIR=off`다.

## 처리 흐름

1. FacePlan과 패딩으로 최종 Qwen의 목 크롭 좌표를 계산한다. 자동 확대·패딩을 거친 원본 베이스에서도 정확히 같은 픽셀 영역만 보존한다. 전체 원본은 후처리 context에 담지 않는다.
2. `FACE_SEAM_VISION_MODEL`(기본 `gpt-5.4`, reasoning high, detail high)이 현재 크롭과 원본의 같은 크롭을 비교한다. 결함 위치·수리 문장·편집 및 합성 다각형·정렬 여부를 사진마다 만든다. 원본은 옷 모양의 기준이며 다른 사람의 피부를 복사하는 기준이 아니다.
3. 파일명별 분기나 `neck_offset` 기준 모드 판정은 없다. `neck_offset`은 메타에만 기록한다. 결함 유무 체크리스트로 건너뛰지 않으며, 불완전한 응답이나 유효하지 않은 마스크는 실패로 처리한다. 고정 넓은 마스크로 대체하지 않는다.
4. Sunburst `images/edits`는 현재 목 크롭 한 장과 투명 마스크만 받는다. 모델 `gpt-image-2.5-sunburst`, high, 1024×1024, PNG, n=1이다. 원본 베이스는 편집 API에 보내지 않는다.
5. 기존 수작업을 옮긴 정렬·안쪽 feather 합성으로 원본 Qwen에 붙인다. 얼굴 보호 영역과 합성 범위 밖 alpha는 정확히 0이다. 각 칼라/띠의 손상 구간을 하나로 포함하도록 계획해 서로 다른 골지나 윤곽을 섞는 일을 줄인다.
6. 범위 밖 변경 0, SFace 하락 ≤0.02, PNG 저장·디코딩 일치를 검증한다. 최종 합성 크롭도 비전으로 원본 옷과 비교해 나시 띠 폭·파임, 목/칼라 정렬, 이중 골지·겹친 띠, 피부 질감을 확인한다. 불확실하거나 실패한 후보는 채택하지 않는다.

코드가 사진별 판단을 수행한다는 것과 새 사진에서도 시각 품질이 입증됐다는 것은 다르다. 모델의 손상 누락·오탐과 부정확한 다각형은 실사진 평가로 확인해야 한다. 수치 통과만으로 시각 통과를 선언하지 않는다.

## 배선과 비용

공유 `apply_face_pass` 성공 경로와 `test_cut_build.render_variant`의 직접 성공 경로에 연결한다. context 준비가 실패해도 이미 성공한 Qwen 결과는 유지한다.

- off: 추가 크롭·API 호출 없음.
- shadow: 후보를 검증하고 Qwen 바이트를 그대로 반환.
- on: 수치·비전 검증을 모두 통과한 후보만 반환.

정상 완료 경로는 계획 비전 1회 + Sunburst 1회 + 최종 비전 1회다. API 재시도나 다른 provider 폴백은 없다. 수치 검증에 실패하면 최종 비전 호출을 생략한다. 전체가 API 1회라는 이전 설명은 이 자동화 경로에 해당하지 않는다.

이미지 사용량은 기존 `image_usage`의 `face_seam_repair` 단계로 기록한다. 비전의 숫자 사용량·지연, 빈틈 판단, 검증 결과, 크롭 좌표, 프롬프트 해시, 픽셀 수와 신원 점수만 메타에 남긴다. 사진·키·프롬프트·비전 서술·응답 본문·서명 URL은 로그나 Git에 남기지 않는다. 제공자가 반환한 모델 문자열도 로그에 복사하지 않는다.

## 로컬 평가

`server/scripts/evaluate_face_seam_repair.py`는 명시한 원본/Qwen/신원 참조/로컬 모델만 사용한다. `.env`에서는 OpenAI 키만 읽고 운영 DB에 연결하지 않는다. 참조 사진은 로컬 신원 측정용이며 API에 보내지 않는다. 이미지 결과는 Git 바깥 또는 Git이 무시하는 폴더에만 저장한다.

- `--prepare-only`: 현재/원본 목 크롭 저장, API 없음.
- `--plan-only`: 사진별 문장·마스크만 평가, 이미지 편집 없음.
- `--live`: 계획 → 편집 → 합성 → 수치/비전 검증.
- `--plans-dir`: 동일한 현재/원본 크롭의 검토된 계획 재사용.
- `--responses-dir`: 동일한 현재/원본 크롭·계획·응답으로 로컬 합성만 재평가. 비전 검증을 통과했다는 뜻은 아니다.
- `--replay-dir`: 최초 수작업의 계획·응답으로 합성 코드 비교. 자동 계획의 품질 증거로 세지 않는다.

먼저 기존 12컷의 실제 손상 문장과 전체 마스크 범위를 확인한다. 그레이 전신만 목/칼라 빈틈으로 판단해야 한다는 사용자 기준이 어긋나면 결과 표를 남기고 이미지 편집 평가를 진행하지 않는다. 기존 12장과 다른 원본 9장도 후속 평가 후보로 확인했다.

## 이전 평가와 활성화 조건

이전 고정 마스크·공통 문장 방식은 정상 칼라와 파임을 바꿔 시각 평가에 실패했다. 당시 수치는 [이전 평가 JSON](face-neck-seam-evaluation-2026-09-17.json)에 보존한다. 이후 두 컷을 수동 합성한 결과도 사용자가 나시 폭 차이와 이중 골지 때문에 거절했다. 최초 성공 이미지의 복원은 자동화 품질 검증으로 계산하지 않는다.

이 PR은 Draft이며 기본 off를 유지한다. 시각 보존 실패를 해결하고 사람이 실사진 결과를 확인한 뒤 실서비스 shadow 20컷 이상을 관찰해야 한다. 운영 DB·SSM·매니페스트와 main 병합은 변경하지 않는다.
