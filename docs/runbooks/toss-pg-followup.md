## 반영한 내용

1. 사업장 주소에 `3층 A-4호 스타트업스테이션`을 명시했다. 스튜디오 회사정보 원본을 통해 랜딩 푸터와 관련 공개 문서에 동기화했다.
2. 랜딩과 스튜디오 요금제에 결제 완료 즉시 이용, 1개월 구독 이용기간, 월 자동갱신, 해지 후 현재 주기까지 이용, 부가세 포함 안내를 넣었다.
3. 약관에서 현재 판매상품을 월간으로 명시하고 연간 판매를 안내하던 부분을 정리했다. 과거 계약의 권리를 축소하지 않는 문구를 남겼다.
4. 환불정책의 업그레이드 설명을 소스의 잔여기간 비례 차액 청구, 비례 크레딧 지급, 기존 결제일 유지 방식에 맞췄다.
5. 기존 임시 이메일 로그인과 낮은 화면의 내부 스크롤 수정을 최신 코드에 옮겼다. 공개 표시는 `이메일 로그인`이다.
6. 운영의 Starter 29,900원/600, Seller 69,900원/1,600, Pro 119,000원/2,800 기준과 최신 코드의 증정 문구를 유지했다.

## 최종 게시 전 반드시 확정할 내용

- **크레딧 이월 확정**: 오너가 구독 유지 중 이월, 해지 후 이용기간 종료 시 이월분까지 소멸하는 기존 정책을 확정했다. 서버 동작은 유지하고 이용약관·환불규정·랜딩·스튜디오 요금 안내를 같은 기준으로 정정했다. 토스가 앞서 이해한 이월 불가와 다르므로 회신 시 이를 명시한다.
- **미사용 부분 환불**: 일부 사용과 기간 경과를 이유로 미제공 부분의 권리를 일괄 배제하던 문구를 정리했다. 접수는 contact@wearless.kr이며 결제액, 해당 결제의 지급·사용 크레딧과 잔여 이용기간을 확인해 관계 법령에 따라 산정 근거를 안내한다. 임의의 정률 공제나 새로운 자동 환불 계산식은 구현하지 않았다. 담당자 처리 절차와 PG가 요구하는 구체적 산식은 제출 전 확인 대상이다.
- **시행일**: 개정안 버전은 v1.2, 시행일은 작업 당시 7일 뒤인 2026-09-29를 임시로 넣었다. 실제 공지가 이루어진 것이 아니다. 기존 약관의 공지 조건, 최종 정책과 게시 시점에 맞춰 시행일을 확정해야 하며 이미 지난 날짜로 배포하지 않는다.
- **동의 버전**: 공개 최신본과 신규 회원 동의 버전은 v1.2다. 기존 v1.1 동의는 공지기간 동안 유지하고, 서울 시간 2026-09-29부터 v1.2 재동의를 자동으로 요구한다.

잘못된 화면 안내도 정리했다. 환불은 존재하지 않는 설정·결제내역 메뉴로 보내지 않고 이메일로 접수한다. 요금제 변경은 고객센터 문의 후 가능한 경우 사전 금액·적용일 안내와 확인을 거치도록 적었다. 사용자에게 없는 변경금액 미리보기 화면을 약속하지 않는다. 스튜디오 구매 전에 이월·소멸 조건과 환불 요약을 직접 표시한다.

실제 반영 후에는 전달한 테스트계정의 비밀번호를 다시 바꾸지 말고 이메일 로그인과 빌링 카드 등록창 진입을 확인한다. 정책과 화면이 일치한 뒤 최신 화면을 캡처해 PPTX로 제출한다. 배포 전의 localhost 화면을 운영 증빙으로 제출하지 않는다.

## 검증 기록

### 독립 리뷰 후 보완

- 사용자 ID가 바뀌면 계정·구독 조회 캐시를 지우고 이전 계정의 늦은 응답을 무시한다. 같은 사용자 토큰 갱신과 게스트 제작 초안은 유지하며 로그아웃 후 강제 새로고침은 추가하지 않았다.
- 결제 실패로 재시도가 중단된 구독도 유예기간 내 카드 변경에 성공하면 기존 청구 워커에 재시도를 예약한다. 유예기간과 실패 횟수는 유지하며, 카드 발급 중 기한이 지나면 새 키를 폐기하고 만료를 안내한다.
