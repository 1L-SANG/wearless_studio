2026-09-16. 제공 자료: https://claude.ai/artifact/V8ZAG92D13g7aePcSWDE89

## 적용 범위

모델이 지원 전에 촬영 준비물을 이해하고, 승인 후 18장을 순서대로 등록하는 웹 흐름이다. 등록 슬롯과 서버 계약은 이미 18장이다. 사전 지원서는 심사용 프로필을 받고, 승인 뒤 등록에서 18장을 받는 기존 절차를 유지하면서 두 용도를 명확히 안내한다.

## 디자인 기준과 결정

주 기준은 기존 FaceMarket 테마와 등록 화면이다. 제공 촬영 가이드의 번호, 9·3·3·3 묶음, 약 15분, 준비물, 기준 사진 주의사항을 적용한다. Refero 라이브 도구는 없어 번들 craft-details.md의 폼, 포커스, 상태 안내와 copywriting.md의 조건·다음 행동 원칙을 보조 기준으로 사용한다.

## 검증 결과

- `pnpm build` 최종 통과. 기존 대용량 청크 경고는 남아 있다.
- `pnpm test:frontend`: 1,768개 중 1,766개 통과. 실패한 2개는 변경된 묶음 이름, 이미지 대체 설명, 푸터 문구의 기존 기대값이었다. 기대값을 갱신하고 사진 교체 후 미리보기 주소 보존까지 검사했다.
- 등록, 푸터, 신규 가이드 65개 재검사에서 64개 통과 후, 남은 이미지 대체 설명 기대값을 수정하여 해당 사진 교체 테스트 1개도 통과했다. 미해결 테스트 실패는 없다.
- 신규 가이드 테스트 2개에서 18개 항목 일치, 9·3·3·3 구성, 공개 복귀 경로, 10장 저장 상태 복원, 남은 장수와 다음 버튼 잠금을 확인했다.
- 내장 브라우저로 공개 지원 페이지에서 가이드 연결, 데스크톱과 390px·320px 모바일 표시, 좁은 화면의 가로 넘침 없음, 단계 바로가기, 안내 펼침을 확인했다.
- 실제 등록 렌더러를 사용하는 로컬 검증 화면에서 0·9·12·15·18장 저장 상태와 최종 확인 화면을 확인했다. 서버에 실제 인물 사진을 올리는 검증은 하지 않았다. 업로드 API 호출, 사진 교체·삭제·복원은 기존 컴포넌트 테스트로 검증했다.
- 서버, 데이터베이스, 배포 설정은 변경하지 않았다. 커밋과 배포는 수행하지 않았다.

## 확정된 클레이 이미지 적용

사용자가 C안에서 밝은 피부의 20대 성인 여성, 검정 포니테일, 양쪽 옆모습의 무표정 표기를 선택하고 실제 적용을 요청했다. 이 확정 시안을 기준으로 내장 `image_gen`을 사용해 같은 인물의 그늘 9칸과 햇빛 9칸을 생성했다. 이전 선 그림을 대체하며, 그늘의 시선 변화와 햇빛의 방향·역광을 구분한다.

- 사용 이미지: `public/models/registration/clay-ponytail-v1/shade.jpg`, `public/models/registration/clay-ponytail-v1/sunlight.jpg`.
- 생성 프롬프트와 출처: `documents/design-assets/facemarket-clay-ponytail-prompts.json`.
- 원본 크기를 유지한 JPEG 변환으로 두 파일 합계 약 650KiB. 인물을 다시 그리거나 좌우 반전하지 않았다.
- 생성본의 실제 시선을 확인해 5번은 그늘 그림의 둘째 줄 오른쪽, 6번은 둘째 줄 가운데에 연결했다. 전체 얼굴을 반전시키지 않아 헤어스타일이 바뀌지 않는다.
- `photoGuideAssets.js`에서 서버 슬롯 이름과 그림 위치를 연결한다. `PhotoPoseIllustration`은 SVG 뷰포트로 생성 비트맵의 한 칸을 표시하고, 가이드와 업로드·재촬영 화면이 같은 컴포넌트를 사용한다.
- 설명 문구는 이미지 밖의 HTML로 유지한다. 양쪽 옆모습 제목과 설명에 무표정을 명시했다. 촬영 크기와 평소 머리 모양 안내는 별도 문장으로 표시해 캐릭터의 포니테일을 촬영 조건으로 오해하지 않게 했다.
- 가이드·등록 테스트 62개 통과. 내장 브라우저에서 모바일 가이드의 5·6번 시선과 데스크톱·390px 업로드 카드를 확인했다. 가로 넘침과 콘솔 오류는 없었다.

### 햇빛 그림자 강조

후속 요청에 따라 햇빛 9칸은 `public/models/registration/clay-ponytail-v1/sunlight-shadow-v2.jpg`로 교체했다. 왼쪽 햇빛에서는 오른쪽 코·볼·턱 그림자를, 오른쪽 햇빛에서는 반대쪽 얼굴의 음영을 강조했다. 역광에서는 얼굴을 어둡게 하고 머리·어깨 테두리의 빛을 살렸다. 인물과 자세, 칸 순서는 유지했다. 내장 이미지 생성 프롬프트는 `documents/design-assets/facemarket-clay-shadow-v2-prompt.json`에 저장했다. 가이드와 업로드 화면이 공유하는 이미지 연결을 변경하고 모바일 측면광·역광 화면을 확인했다.

### 촬영 전 체크리스트를 상단으로 이동

사용자 요청으로 8가지 체크 항목을 페이지 제목 바로 아래, 촬영 준비와 사진 예시보다 먼저 배치했다. 각 항목은 의미를 나타내는 아이콘, 짧은 제목, 한 줄 핵심 설명으로 줄였다. 데스크톱은 4열, 모바일은 2열이며 카드 전체를 눌러 체크할 수 있다. 자세한 구도와 기준 사진 안내는 뒤의 기존 설명에서 확인한다. 빌드와 모바일 넘침 여부, 데스크톱 배치, 실제 체크 동작을 확인했다.

### 큰 그림 아이콘과 검사 시점 안내

작은 선 아이콘을 직접 구성한 두 가지 색상의 SVG 도해로 교체했다. 데스크톱 80px, 모바일 68px이며 기존 FaceMarket 색상 변수를 사용한다. 촬영 전 가이드의 긴 재촬영 사유 목록을 삭제하고, 등록 화면에 올린 뒤 확인한다는 한 줄만 남겼다. 촬영 중 실시간 검사는 없지만 `facemarket_enrollment.upload_enrollment_photo`에서 업로드 시 `check_enrollment_photo`를 호출하고, 담당자의 재촬영 요청 기능도 있다. 이 서버 동작은 변경하지 않았다. 빌드와 모바일 8개 아이콘 렌더, 가로 넘침 없음, 기존 사유 목록 제거를 확인했다.

### 2026-09-17, 읽는 안내 4개와 짧은 등록 문구

사용자 확정 문구에 맞춰 촬영 준비 안내를 안경 모자 벗기, 혼자 나오기, 후면카메라 촬영, 같은 날 찍기의 네 가지로 줄였다. 체크박스, 클릭 유도, 선택 상태를 없애고 큰 아이콘과 설명만 남겼다. 삭제한 네 항목의 아이콘도 정리했다.

가이드의 구도 설명과 사진별 안내를 한두 문장으로 줄이고, `3/4` 제목은 `비스듬히`로 바꿨다. 반복되던 기준 사진 배너와 촬영 화면의 추가 안내 문장은 제거했다. 번호별 자세와 같은 자리에서 찍는 조건은 해당 사진과 촬영 묶음에서 안내한다. 기준 사진 재촬영 설명은 실제 재촬영 요청 화면에만 표시한다.

지원서 제목, 본인확인 안내, 신분증 촬영 안내, 사진 등록, 사용 조건, 발급 대기·실패·완료 화면을 간결하게 정리했다. 동의 체크와 원문 링크, 수집 목적과 보유 기간, 사용료·정산 비율, 심사 종료 기한, 인증·업로드 동작은 유지한다.

검증: 빌드 통과. 관련 테스트 202개 중 200개 통과 후, 변경된 심사 안내의 기대 문구를 수정했다. 함께 작업 중이던 체형 이미지 항목은 최신 파일 상태로 확인했다. 해당 항목을 포함한 재검사 4개가 모두 통과했다. 내장 브라우저에서 촬영 준비 항목 4개·체크박스 0개·모바일 가로 넘침 없음을 확인했고, 등록 화면 문구는 실제 렌더 컴포넌트를 사용하는 로컬 확인 화면에서 검수했다.
