# 생성예시가 컷의 포즈와 방향을 정한다

상태: Accepted
결정일: 2026-10-09, 사용자 승인

정상 콘티 컷은 생성예시를 고른 뒤 생성한다. 사용자에게 포즈와 방향을 별도로 지정하게 하지 않고, 선택한 예시의 포즈와 방향을 사용한다. 제품 디테일의 방향은 연결된 원본 촬영 대상이 정하는 기존 규칙을 유지한다.

## 결정

- 스튜디오의 고정 포즈 순환과 방향 자동 배분을 제거한다.
- 콘티와 에디터 새 이미지 추가에서 방향 선택 버튼을 제거한다. 에디터 현재 이미지 수정의 수동 방향 변경도 제거한다.
- 생성예시 갤러리는 방향별 분류와 제목 없이 기존 사진 목록으로 보여 준다. 카드의 방향 캡션도 제거한다. 방향을 사용자에게 다른 선택 방식으로 다시 노출하지 않는다(작업 중 사용자 정정).
- 분류 없는 목록을 3×2 페이지로 보여 준다. 페이지당 최대 6장이고 나머지는 옆으로 넘겨 본다(2026-10-10 사용자 결정).
- 저장 블록의 과거 `pose`, `poseLabel`, `poseThumb` 선택값은 제거한다. 과거 포즈 값이 예시의 포즈나 색상별 미세 변주를 덮지 못한다.
- 방향과 `sideStyle`은 생성예시의 내부 메타데이터로 유지한다. 알려진 예시가 있으면 과거의 수동 방향보다 예시가 우선한다. 가상모델의 사선도 해당 메타데이터에 맞는 생성 지시를 받는다.
- `refScope='pose'`와 포즈 참조 자산은 사용자 포즈 지정값과 다른 개념이다. 예시에서 자세만 참고하는 계약은 유지한다.
- 같은 예시를 다른 색상으로 반복한 낱장 컷의 작은 포즈 변주, 동일 컷 재사용과 촬영 세트의 예시 포즈 보존은 유지한다.
- 에디터 현재 이미지 수정의 기존 포즈·표정 메뉴와 별도 윈도우 작업의 새 비슷한 컷 파이프라인은 이번 범위에서 바꾸지 않는다. 수동 방향 선택만 제거한다.

색상, 샷, 매칭 의류와 아우터 열림 정도는 계속 카드의 상품 설정이다. 이전 ADR의 사용자 포즈·방향 우선 문구는 이 결정으로 대체한다. blocks 배열, 섹션과 행 저장 구조, DB 스키마, 요금 정책은 바꾸지 않는다.
