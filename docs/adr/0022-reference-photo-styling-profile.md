# 일반 스타일링의 촬영 질감을 참고 사진에 맞춘다

상태: 구현 검토 중. PR만 허용하며 머지와 운영 배포는 별도 승인 대상이다.
결정일: 2026-10-16

## 목적과 근거

같은 상품·마네킹·모델·매칭 입력으로 피그마 참고 사진과 가까운 일상 착용컷을 만든다. 사진마다 다른 노출, 색온도, 명암, 선명도, 질감을 하나의 최신 아이폰 또는 화보 스타일로 덮어쓰지 않는 것이 목적이다.

로컬 탐색은 네 상품, 세 모델, 여덟 참고 사진으로 진행했다. 기존 장문 지시, 촬영 문구만 교체, 사진 중심의 간결한 지시, Flare와 Sunburst, 소품·시선·구도 보강, 작은 출력, 동일 요청 반복을 비교했다. 48회 중 각 조건 대부분은 한 장이고 반복은 두 사례뿐이다. 통계적 우승이나 사용자 최종 선택으로 취급하지 않는다.

관찰상 사진 중심 지시와 Sunburst의 조합은 그늘과 낮은 대비를 잘 유지하면서 예시 인물의 긴 머리·안경이 선택 모델로 넘어오는 문제를 줄였다. 모델만 바꾸거나 촬영 문단만 바꾼 조건은 일부 역광에서 다시 과장된 인물 사진과 좁은 구도로 돌아갔다. 작은 출력이 항상 낫다는 근거는 없어 서비스의 기존 2K를 유지한다. 소품을 제거하는 문구가 헤드룸을 바꾸는 회귀도 있어 여백과 인물 크기를 별도로 지시한다.

실험 자산은 `.scratch/wearshot-style-lab-20261016/`에 두며 저장소에 사진을 넣지 않는다. 탐색 기준선은 운영 문구에 연구용 자산을 넣은 비교이고 운영 카탈로그 재실행은 아니다. 코드 연결 검증도 고정한 오프라인 호출자 입력을 실제 생성 함수에 전달하는 방식이다. 발행, 라이선스, 운영 작업 큐의 전체 실사 테스트와 구분한다.

## 적용 범위

- `STYLING_PHOTO_PROFILE=reference-v2`이며 생성예시가 있는 일반 `styling` 컷에만 적용한다. 검증된 confirmed 입력과 일반 에디터 입력을 모두 지원한다.
- `spaceGroupId`가 있는 장소 세트, 호리존, 시그니처, 상품컷, 예시 없는 컷은 기존 분기를 유지한다. 장소 세트의 공통 장소 이미지와 컷별 자세 이미지 구성도 변경하지 않는다.
- 모델은 `gpt-image-2.5-sunburst`다. 기존 호리존과 상품 디테일 전용 모델 설정은 건드리지 않는다. 2차 국소 수정에서도 같은 모델을 선택하되 수정 프롬프트와 입력 계약은 기존대로 둔다.
- 라이브러리 기본값은 `legacy`다. API와 상세 워커 manifest에만 새 프로필을 명시한다. 해당 설정을 `legacy`로 바꾸거나 지우면 이전 모델과 문구를 함께 복원한다. 이 PR 자체는 배포 승인이 아니다.

## 바꾸는 것과 유지하는 것

참고 사진은 실제 촬영 질감과 장면의 분위기를 소유한다. 선택 모델의 얼굴·머리·체형, 상품 원본의 구조·원단·마감, 매칭 의류의 권한은 기존 입력에 남긴다. 상품색은 환경광 아래의 같은 소재색으로 표현하며 배경색에 맞춰 상품 자체를 다시 칠하지 않는다. 피부, 의류, 배경의 노출과 접촉 그림자를 하나의 장면으로 맞춘다.

장면은 같은 장소 유형과 주된 벽 방향, 깊이, 팔레트, 빛의 방향·부드러움, 복잡도를 유지하는 가까운 변형이다. 특징적인 상호, 가방, 안경, 헤어스타일을 예시 인물에게서 빌려오지 않는다. 지지나 얼굴 가림에 필요한 물체는 일반적인 무상표 물체로 유지할 수 있다. 모든 환경 글자를 지우는 정책은 아니다.

헤드룸, 인물 점유율, 의도된 크롭, 시선, 표현 강도와 지지 관계는 예시별로 읽는다. 자세의 의미를 유지하는 작은 관절·팔 역할 변화는 허용한다. 모든 사람을 렌즈 쪽으로 돌리거나, 모든 팔을 뒷짐으로 바꾸지 않는다. 출력 비율이 다르면 세로 구도를 보존하며 배경 폭을 조정하고 몸을 늘리지 않는다. 방향 변경을 명시한 컷은 기존 방향 권한이 먼저다.

confirmed 컴파일러는 기존 역할 순서, 범위, 셀러 근거, 불확실성 검증을 그대로 재사용한다. 마네킹의 색·착용 핏 권한도 그대로다. 일반 컴파일러는 기존의 더 좁은 마네킹 권한, 방향·라이선스 얼굴·체형·상품 블록을 유지하고 기본 촬영 문구만 분리한다. 서로 다른 두 입력 계약을 하나로 위장하지 않는다.

추가 전처리, 이미지 순서 변경, 해상도 축소, 색 필터, 얼굴 교체, 유료 QC 호출, 자동 재생성은 추가하지 않는다. confirmed 경로는 원본 MIME와 바이트 보존을 유지하고 일반 경로는 기존 공급자 정규화를 그대로 따른다. 기존 QC의 `confirmed_gpt_v1` 권한 분류는 입력 소유권 계약이 같으므로 유지한다. 렌더링 모델과 실제 문구는 기존 체크포인트 지문에 포함되어 이전 결과와 섞이지 않는다.

## 검증과 남은 한계

`test_reference_photo_profile.py`는 실제 생성 함수의 공급자 경계에서 모델, 문구, 입력 바이트와 순서, 해상도, 되돌리기, 범위 제외, 수정 모델, 체크포인트 분리와 잘못된 입력 차단을 검증한다. 기존 confirmed 문구의 해시 고정 테스트도 유지한다. 전체 서버 테스트와 로컬 DB 테스트로 다른 생성 경로의 회귀를 확인한다.

사진의 자연스러움과 상품의 모든 세부 재현은 코드 테스트로 합격 처리하지 않는다. 작은 참고 사진의 모공이나 원단 미세 조직은 판단하지 않으며, 자동 검토 의견은 오너의 최종 선택이 아니다. 헤드룸의 작은 차이, 복잡한 팔 지지, 선택 얼굴의 정밀 유사도는 실제 출력 리뷰에서 계속 확인해야 한다.
