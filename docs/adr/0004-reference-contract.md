# 예시·레퍼런스의 기여 규칙을 계약으로 정한다

> 2026-10-09 후속 결정: 사용자 포즈·방향 지정과 스튜디오 자동 배정은 ADR-0015로 대체됐다. 착용컷은 고른 예시가 포즈·방향을 정하며 과거 포즈 선택값은 제거한다. 제품컷의 방향은 셀러가 고른 원본 사진의 면을 따른다(ADR-0008, ADR-0015의 2026-10-10 개정). 예시 포즈 참고, 작은 변주, 상품 정본과 세트 연속성은 유지한다.

분위기 예시·레퍼런스의 기여 계약을 확정한다(2026-06-29):

- **생성예시는 촬영 연출만 참고한다.** `전부`는 장소·조명·분위기·포즈·프레이밍·구성을 참고하되, 스타일링컷은 같은 장소 유형·촬영 분위기 안에서 자연스러운 다른 구체 장소를 만들고 호리존컷은 같거나 거의 같은 중립 스튜디오를 허용한다. `포즈만`은 자세만 참고하고 현재 카드의 `shot`이 풀샷·중간샷 프레이밍을 정한다. `배경만`은 빈 플레이트를 결과의 정확한 기본 무대로 쓰며 현재 카드가 새 인물의 포즈·프레이밍을 정한다(참고 범위는 ADR-0009, 포즈 자유와 장소 변주는 ADR-0011을 따른다). 예시 속 옷·신발·액세서리의 구체적인 디자인은 가져오지 않는다. 상품 의류와 사용자가 고른 매칭 의류만 상품 고유 디자인·색·구조의 근거이며, 이 둘이 주지 않은 코디 영역만 무지·무브랜드의 중립 기본 의류·신발로 채울 수 있다. 예시는 제작 시 메타데이터(샷·각도·조명·배경·포즈)를 태깅하고, 선택 시 허용 범위의 값이 생성 설정으로 복사되며 이미지 자체도 해당 범위의 스타일 레퍼런스로 주입된다.
- **내 레퍼런스(업로드)의 베끼기 규칙**: 조명·색감·공간 무드는 참고한다. 포즈 뉘앙스는 고른 예시와 상품 설정에 충돌하지 않을 때만 참고한다. 레퍼런스 속 옷·모델·컷 종류 대분류는 복사하지 않는다. 업로드는 모든 컷에서 허용하고(차단 없음, 방어는 이 계층 규칙), `refImages`는 블록 소속이므로 **프로젝트 한정**이며 전역 자산으로 저장하지 않는다.
- **방향 토큰은 내부 면 분류다**: `front`는 정면에서 살짝 비튼 각도까지 포함하는 대역(band)이다. 착용컷은 생성예시의 방향·`sideStyle` 메타데이터를 따르고 제품컷은 선택한 원본 면을 따른다. 사용자 방향 버튼이나 방향별 예시 분류는 제공하지 않는다(ADR-0015).
- **촬영 세트**: 임의 문자열 묶음은 지원하지 않는다. 발행된 세트를 고를 때만
  `spaceGroupId=ssg1__<setId>__<instanceId>`를 만들며, 같은 ID의 연속 블록들이
  한 세트다. `spaceVariation`은 릴리스가 정한 `fixed`(호리존 설정 고정) 또는
  `subtle`(같은 장소 안에서 카메라 위치·포즈·프레이밍을 자연스럽게 바꿈)만 쓴다.
  이전 임의 그룹은 테스트 프로젝트 초기화 전제이므로 호환하거나 마이그레이션하지 않는다.

## Consequences

- 중간샷 크롭은 품목에 따른다. 상의·아우터·원피스는 머리~허리, 하의는 다리~허리로 예시 버킷 규칙과 같으며 상품 정보에서 자동 결정한다.
