# 일반 생성예시는 포즈 의미와 촬영 분위기를 보존하되 자연스러운 다른 장소로 변주한다

상태: Accepted
결정일: 2026-08-13

## 배경

일반 `all` 생성예시를 실제 의류컷에 적용할 때 두 극단이 반복됐다. 예시의 문·벽·화분·가구
배치를 거의 그대로 복제하거나, 반대로 다른 장소임을 증명하려고 `공간 구조 1개 + 소품 배치
2개` 같은 수량 조건을 채우면서 없던 화분·가구·간판을 부자연스럽게 추가했다. 포즈도 관절과
좌우 좌표를 정밀 복제하면 여러 결과가 같은 마네킹 자세처럼 굳었다.

셀러는 생성예시를 고를 때 포즈와 전체 배경 분위기를 중심으로 본다. 따라서 예시의 연출은
알아볼 수 있어야 하지만, 특정 장소의 평면도나 인물의 정확한 골격 좌표를 복사하는 계약은
아니다.

## 결정

### 일반 `all` 스타일링·거울컷

생성예시는 **촬영 연출 참고**다.

- 유지: 장소 유형, 전체 분위기와 톤, 큰 색 관계, 시간·날씨, 광원 방향과 부드러움,
  공간 밀도, 넓은 구도, 카메라 높이·비스듬함·거리, 헤드룸, 화면 속 인물 크기와 원근 관계.
- 포즈 유지: 행동, 몸 방향, 체중과 지지측, 중요한 접촉·지지물의 기능, 큰 팔다리 역할,
  시선과 비대칭의 의미.
- 작은 자유: 관절각, 손·손가락 위치, 고개 각도, 느슨한 머리카락과 원단 반응. 이 자유로
  포즈를 좌우 대칭 마네킹 자세로 펴거나 다른 행동으로 바꾸면 안 된다.
- 장소 변주: 같은 시각적 가족에 속하는 **자연스러운 다른 구체 장소**를 만든다. 특징적인
  건축·가구·소품 관계를 같은 현장·같은 순간으로 읽힐 만큼 복제하지 않는다.
- 수량 할당 금지: 장소 차이를 만들기 위한 구조·가구·화분·간판·설비·소품 변경 개수를
  정하지 않는다. 다르게 보이기 위해 요소를 추가·이동·복제·부자연스럽게 배치하지 않는다.
  포즈에 의자·난간 같은 지지물이 필요하면 기능은 유지하되 같은 물체와 위치를 복사하지 않는다.
- 환경 문자: 배경의 자연스러운 문자·간판을 무조건 지우지 않는다. 다만 예시의 고유 브랜드나
  간판을 그대로 복제하거나, 없던 가짜 상호·읽을 수 없는 두드러진 문자를 새로 만들지 않는다.

명시적인 촬영 질감 A/B가 없으면 예시의 촬영 등급을 유지한다. 촬영 질감 A/B가 있더라도
변수는 렌더링·심도·노출 처리·화이트밸런스·대비·선예도 같은 capture 표현으로 한정하고,
위 카메라 위치·거리·헤드룸·인물 크기·구도는 두 팔에서 동일하게 유지한다.

### 상품 문자와 임시 태그

상품 자체의 영구 라벨·인쇄·자수·로고는 셀러 상품 픽셀이 정본이다. 요청한 착용 방향에서
자연스럽게 보이는 경우에만 철자·모양·색·위치·방향·개수를 보존하며, 안쪽 라벨을 억지로
노출하지 않는다. 가격표·매장 행택·클립 태그 같은 임시 판매 표식은 상품 디자인으로 옮기지
않는다. 환경 간판과 상품 문자를 같은 `no text` 규칙으로 지우지 않는다.

## 별도 예외

- `horizon`: 일반적인 중립 스튜디오라면 예시와 같거나 거의 같은 배경을 허용한다.
- `bg`: 빈 플레이트를 정확한 편집 캔버스로 쓰는 별도 하위 방식이다. 다음 `all` 실험에는
  포함하지 않지만, 과거 저장값·조건부 API 호환 기능까지 폐기한다는 결정은 아니다.
- 공간 세트: 예시와 다른 새 장소를 프로젝트에 한 번 배정한 뒤, 세트 멤버끼리는 그 새 장소를
  공유한다. 멤버마다 다른 장소를 새로 만들지 않는다.
- 제품컷: 사람 없는 상품 확인 계약을 따르며 일반 lifestyle 장소 변주를 적용하지 않는다.

## 영향

- ADR-0004의 `소품 2~3개`, ADR-0009의 일반 `all` 설명, PRD와 공통 계약에 남은 수량 규칙은
  이 ADR이 대체한다.
- 일반 `all` 생성 프롬프트와 그 QC는 같은 자연 변주 계약을 사용한다. 생성기가 수량 조건을
  따르지 않는데 QC만 그 조건으로 실패시키는 조합을 금지한다.
- 역사 실험 산출물은 당시 프롬프트와 함께 보존한다. 이 결정을 이유로 과거 결과·해시를
  다시 쓰지 않는다.
