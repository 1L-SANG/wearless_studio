# ADR-0023: 같은 옷 검수(AG-P2)를 Claude Opus 5.5 low로 전환

상태: 2026-10-17 오너 결정("opus low로 바꾸자").

## 결정

마네킹 컷의 같은 옷 검수 `image_qc.verdict`는 Claude Opus 5.5(effort low)를 먼저 부른다. 같은 호출에 들어 있는 매칭 하의 검수와 편집 전후 비교 검수(paired)도 함께 옮긴다. 한 작업 안에서 처음 판정과 편집 뒤 판정의 기준이 달라지지 않게 하기 위해서다.

- Claude에 보내는 사진은 긴 변 1536px로 줄인다(JPEG 85, 작은 사진은 그대로). 비교 실험과 같은 조건이고, 줄이지 않으면 호출당 비용이 두 배쯤 된다. 이미지 해시와 대체 경로에는 원본을 쓴다.
- Claude 호출이 실패하거나 시간을 넘기면 지금의 경로(Gemini, 그다음 GPT)로 같은 판정을 다시 받는다. 검수 결과의 모양과 판정 규칙은 바꾸지 않는다.
- 장소 일치 검수 `scene_verdict`는 측정하지 않았으므로 그대로 둔다.
- 설정: `MODEL_IMAGE_QC`(비우면 이전 경로), `IMAGE_QC_CLAUDE_EFFORT`(기본 low), `IMAGE_QC_TIMEOUT_SECONDS`(기본 90초). 되돌리려면 `MODEL_IMAGE_QC`만 비운다.

## 근거

세 번의 비교에서 순위가 같았다(Opus, Argon, Pro 순).

| 평가 | Opus low | Argon | Pro(현행) |
|---|---|---|---|
| Claude 정답 7건 | 7/7 | 4/7 | 4/7 |
| 오너 정답 6건 | 5/6 | 4/6 | 2/6 |
| 합성 결함 16건 | 11/16 | 10/16 | 8/16 |

합성 결함 세트(10/17) 실측: Opus는 24건 모두 응답, 호출당 중앙값 9.8초, 최대 15초, 약 0.065달러. Pro는 2건, Argon은 2건이 120초 시간 초과였다. 원자료는 `.scratch/model-eval-20261016/results/judge_defects_A_summary.md`.

## 감수하는 것

- 호출당 비용이 Pro(약 0.019달러)의 세 배 남짓이다. 마네킹 작업 하나에 검수는 보통 1~3번이다.
- 모든 모델이 질감, 줄무늬 간격, 미세한 길이 차이는 놓쳤다. 이번 전환으로 풀리지 않는다.
- 편집 전후 비교 검수(paired)는 따로 측정하지 않았다. 운영 로그로 확인한다.
