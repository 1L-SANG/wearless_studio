# 제품컷 샷은 고스트샷과 디테일샷 두 종류로 통합한다

상태: Accepted
결정일: 2026-07-19

서비스에서 사용자가 고르고 저장하는 제품컷 샷은 `ghost | detail` 두 값만 쓴다.

- `ghost`(고스트샷)는 모델 없이 옷 전체를 보여준다. 기본 표현은 사람이 입은 듯한 부피와 실루엣이 있는 고스트 마네킹 방식이다.
- 생성예시가 옷을 펼쳐 위에서 찍은 플랫레이 표현이면, 같은 `ghost` 샷 안에서 그 표현과 프레이밍을 따른다. 플랫레이는 별도 서비스 샷이 아니라 고스트샷의 예시 주도 표현 방식이다.
- `detail`(디테일샷)은 입력 사진에서 실제로 확인되는 부위만 확대한다. 보이지 않는 구조·재질·부자재는 만들지 않는다.

기존 `flatlay` 저장값이 유입되면 `ghost`로 방어 정규화한다. 수집 원본과 생성예시 후보의 `sourceShot`·`presentationMethod`에는 `flatlay`를 증거로 보존할 수 있지만, 선택 목적지와 서비스 저장값은 `ghost`다.

디테일의 현재 자동 추천·생성·발행은 ADR-0012·0014를 따른다. 상품별 총 컷수는 현재 콘티 구성으로 결정하며 이 ADR에서 고정하지 않는다.

생성예시 선택판에서는 기존 ghost·flatlay 후보와 선택을 하나의 고스트샷 묶음으로 합친다. 원본 표현 방식은 후보별 `presentationMethod`로 보존한다. 합칠 때는 선택을 먼저 모두 복원하고, 최종화 단계에서 일반 묶음 최대 6장 규칙을 적용하되 제외 대상과 이유를 기록한다.

ADR-0007의 착용컷 `full | medium` 통합과 같은 원칙으로 서비스 선택 토큰을 줄이되, 수집 원본 증거는 다시 쓰지 않는다.

## 영향

- `ProductShotType`은 `ghost | detail`이다.
- 제품 전체의 방향은 계속 `front | back`을 쓴다. 방향을 정하는 방법은 아래 2026-10-10 개정을 따른다.
- 제품용 행거샷은 계속 제공하지 않는다.
- 프롬프트는 고스트샷의 기본 부피 표현과 플랫레이 생성예시가 있을 때의 예외 표현을 한 섹션에서 설명한다.

## 2026-10-10 개정, 제품컷 방향은 고른 원본 사진이 정한다

오너 결정(2026-10-10). 제품컷(고스트샷, 디테일샷)의 방향 `front | back`은 셀러가 고른 원본 사진의 면이다. 앞면 사진을 고르면 앞면, 뒷면 사진을 고르면 뒷면이다.

- 화면은 "앞면, 뒷면" 칩이 아니라 카드 색상의 "내 앞면 사진, 내 뒷면 사진" 중에서 고르게 한다. 디테일 촬영 대상과 같은 사진 타일 방식이다. 상품 사실의 기준 사진을 고르는 것이며, ADR-0015가 없앤 방향 선택이 아니다.
- 디테일은 촬영 대상(`detailTargetId`)이 있으면 그 대상의 원본 면을 따른다(ADR-0012). 대상 없이 원본에서 촬영하면 고스트샷처럼 원본 사진을 고른다.
- 생성예시는 연출 참고로만 쓴다. 저장, 콘티 불러오기, 예시 선택, 자동 배정, 생성 어디서도 예시 방향이 제품컷 방향을 덮지 않는다.
- 카드 색상에 그 면의 사진이 없으면 그 사진은 고를 수 없다. 색상을 바꿔 고른 면의 사진이 없어지면 사진이 있는 면으로 바꾼다.
- 서버가 같은 설정의 컷을 한 번만 생성하고 복사하는 판정은 방향이나 원본 사진이 다른 제품컷을 같은 컷으로 보지 않는다. 상의 확장형의 앞면, 뒷면 고스트샷은 각각 생성한다.
- 저장 필드는 기존 `direction`을 그대로 쓴다. 블록 저장 구조, 서버 API의 생성 요청 형식, DB는 바꾸지 않는다.
- 에디터 `현재 이미지 수정`에서 제품컷 결과 사진 한 장을 원본 확인 없이 다시 그리던 AG-07 경로는 없앴다. 원본 검수 레시피가 있는 디테일컷만 같은 부위를 다시 촬영한다(PRD 10.8).

기본 콘티의 제품 확인 시드는 2026-08-07 개편과 ADR-0012 이후 `src/lib/api/shapes.js`가 정본이다. 위 결정 본문의 "Detail 입력이 없으면 `ghost(back)`" 시드 설명은 대체됐다. 지금 기본형은 기준색 고스트샷 앞면, 추가 색상 고스트샷 앞면, 추천 디테일이고, 확장형은 추가 색상 고스트샷 앞면, 기준색 고스트샷 앞면과 뒷면, 추천 디테일이다. 기준 색상은 앞면, 뒷면 사진이 필수라 시드의 뒷면 고스트샷은 늘 원본 사진이 있다.
