# ADR-0029: 셀러가 정한 옷 색은 생성 뒤 옷 부분에만 같은 보정으로 반영한다

- 날짜: 2026-11-21
- 상태: 오너 확정(11/12 방향, 11/21 구현 지시)
- 정본 명세: `documents/garment_color_target_spec.md`

## 배경

마네킹 단계를 끄면서(2026-11-18) 마네킹 화면 안의 색 조절이 셀러 화면에서 사라졌다. 켜져 있는 `GARMENT_COLOR_TUNE`은 추가 색상 컷을 올린 사진의 색 방향으로 조금 당길 뿐이고, 대표 색상 컷은 색 보정을 받지 않는다. 11/11 실험에서 AI는 흰 옷의 누런 기는 스스로 걷어 내지만 색 있는 옷은 사진의 틀린 색을 베꼈다. 지시문에 색을 적는 방식은 옷을 어둡게 그리는 부작용이 있었다.

## 결정

1. 셀러는 코디보드의 "내 상품" 줄이나 보드의 내 상품 그림을 눌러 여는 색 조절 판(11/12 확정 9차 시안)에서 색상마다 진하기, 밝기, 따뜻함을 맞춘다. 셀러가 정하는 것은 "실물의 색"(목표 색)이다.
2. 생성 지시문, 검수, 추가 색상 색 입히기는 바꾸지 않는다.
3. 모든 컷이 끝난 뒤 그 색상 컷들의 옷 가운데 색을 재고, 목표 색이 되게 하는 보정 한 벌을 그 색상의 모든 컷 옷 부분에 똑같이 건다. 보정은 선형광 곱셈과 픽셀 자기 휘도 둘레 채도 조절이라 컷마다 다른 빛의 세기와 색온도가 남는다.
4. 셀러가 움직인 축만 맞춘다. 손대지 않은 색상은 생성된 그대로 둔다(자동 맞추기를 기본으로 켜지 않는다).
5. 슬라이더 끝값은 사진에 안전하게 옮길 수 있는 한도에 맞춘다. 큰 차이는 상한까지만 옮긴다.
6. 1차부터 모든 색상 옵션에 적용한다. 실존 모델 얼굴이 든 컷은 제외한다.
7. 에디터에서 다시 맞추기는 2차다. 1차는 끝 단계에서 원본과 윤곽을 보관해 2차가 다시 생성 없이 쓸 수 있게 한다.

## 버린 안

- **슬라이더 움직인 양을 결과에 그대로 덧입히기:** AI가 이미 일부 고친 만큼 두 번 고쳐진다(흰 옷이 푸르게 됨).
- **컷끼리 똑같은 색으로 맞추기:** 장면 조명 차이가 사라져 옷만 오려 붙인 것처럼 보인다.
- **지시문에 색 적기, 검수 기준 바꾸기, 상품 사진 색 바꿔 넣기:** 옷이 어두워지는 부작용, 효과 불확실, 고칠 곳이 셋으로 늘어난다.
- **같은 색 안전망(`correct_color_option`)의 `seller_color` 쓰기:** 허용 폭 안이면 사진을 움직이지 않아 셀러가 정한 색을 지키지 못한다.

## 결과

- 새 서버 키 `analysis.garmentColorTargets`와 전용 API 4개, 상세 생성 끝 단계, 스위치 `GARMENT_COLOR_TARGET_ENABLED`(기본 꺼짐).
- 비용은 셀러가 색을 정한 색상에만 든다. 15컷 페이지 약 0.15달러.
- ADR-0025(추가 색상 색 입히기)와 ADR-0028(핏 칩)은 그대로다. 이 결정은 그 뒤에 붙는다.
