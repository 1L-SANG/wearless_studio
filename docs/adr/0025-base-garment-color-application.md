# ADR-0025: 대표 색상의 의류 재현을 공유하는 추가 색상

- 날짜: 2026-11-06
- 상태: 사용자 의도 확정, 로컬 구현과 검증
- 근거: 이 작업의 사용자 정정 설명, 독립 Codex 기획과 Opus 5.5 xhigh 검토

## 문제

대표 색상은 여러 방향과 디테일 사진이 있지만 추가 색상은 정면 몇 장만 받는다. 추가색 착용컷을 그 적은 사진만으로 독립 생성하면 대표색에서 얻은 구조와 핏 근거를 잃는다. 확정 GPT 경로는 기준색만 허용해 추가색 선택이 생성 단계에서 실패할 수도 있었다.

## 결정

사용자 저장값 `colorId`는 최종 목표색으로 유지한다. 추가색 착용컷은 대표색 상품 사진과 분석, 마네킹을 사용해 기존 생성과 채택 절차를 먼저 실행한 뒤, 그 결과에 목표색 실사진을 적용한다. 엔진 자체에 추가색 권한을 섞거나 기존 확정 GPT 템플릿을 바꾸지 않는다.

최종 색 적용은 판매 의류의 색과 실제 배색만 바꾼다. 원본이 소유하는 형태, 핏, 주머니, 봉제선, 여밈, 무늬 구조, 질감, 인물, 포즈, 코디와 장면을 재설계하지 않는다. 목표색 사진의 포즈나 조명, 실물 재질의 불확실성을 원본 재현 위에 덮지 않는다. 대표색 생성의 기존 검수는 그대로이며, 그 검수를 목표색 결과의 검수로 재사용하지 않는다.

기존 자동 검수가 켜져 있으면 색 적용용 원본, 목표색 사진, 결과를 별도 비교한다. 구조, 질감, 인물과 장면, 목표색, 명백한 상품 디자인 불일치를 확인한다. 명시적인 불일치는 컷 실패, 판정 불능은 경고로 남기며 확인하지 않은 결과를 통과로 기록하지 않는다. 취소는 경고로 바꾸지 않고 그대로 전파한다.

얼굴 관련 최종 보정은 색 적용 뒤에 필요할 때 실행한다. 따라서 내부 원본은 기존 생성과 QC에서 채택한 대표색 결과이며, 모든 이미지가 사전 검증을 완벽히 통과했다는 뜻이 아니다. 실제 인물의 보호 표식과 라이선스 경계는 중간 원본에도 동일하게 적용한다.

제품 단독컷은 목표색 원본에서 직접 만든다. 디테일 촬영 대상의 원본 바인딩과 기준색 제한은 유지한다. 해당 색상에 없는 제품 뒷면을 다른 색상의 뒷면으로 자동 대체하지 않는다.

## 재사용, 실패와 비용

추가색 결과에서 색을 다시 바꾸더라도 이전 색 변경본 위에 연달아 편집하지 않는다. 같은 프로젝트 소유의 내부 기준색 원본을 우선 사용한다. 옛 자산처럼 연결이 없는 경우 현재 고른 원본을 시작점으로 삼아 이후 연결을 남긴다.

콘티에 미리 넣은 비슷한 컷과 에디터에서 만든 비슷한 컷도 같은 규칙을 따른다. 대표색 원본에서 새 자세를 만들고, 그 새 원본에 목표색을 적용한다. 후속 컷의 원본 연결은 부모의 예전 자세가 아니라 새 자세를 가리킨다. 열림 정도를 변경한 결과처럼 새로운 의류 상태가 생긴 경우에는 과거 원본을 재사용해 변경을 되돌리지 않고 현재 사진을 새 기준으로 삼는다.

내부 원본은 별도 자산으로 보관하되 의류 탭, 최종 사진 장수와 사용자 크레딧 계산에서 제외한다. 추가색 착용컷의 내부 이미지 호출은 늘지만 사용자에게 중간 결과를 한 장으로 추가 차감하지 않는다. 실패와 취소, lease 상실 때 중간 자산도 기존 정리 경계에 포함한다.

색 적용이 실패하면 해당 컷이 실패한다. 대표색 사진을 목표색으로 표기해 내보내는 폴백은 금지한다. 체크포인트는 목표색 사진의 해시와 색 적용 정책을 포함하므로 입력이 바뀐 결과를 재사용하지 않는다. 서로 다른 컷의 원본 공유는 하지 않는다. 색만 다른 것처럼 보여도 예시 미세 변주와 구도, 코디가 달라질 수 있기 때문이다.

## 화면과 향후 파이프라인

새 프로듀싱 콘티의 인스펙터에서 최종 색 하나만 고른다. 실제 첨부 사진, 색상 이름과 사진이 없는 이유를 확인할 수 있게 한다. 사용자에게 대표색 렌더 단계나 생성 모드를 고르게 하지 않는다.

새 최종컷 파이프라인은 대표색 이미지와 생성 설정을 반환하면 된다. 이후 색 적용과 내부 원본 연결, 목표색 저장 계약을 그대로 사용할 수 있다. DB 마이그레이션과 새로운 콘티 블록 종류는 필요 없다.

## 검증의 한계

로컬 소량 시험에서는 색과 대체적인 사람, 포즈, 장면을 유지했지만, 털 의류의 질감과 옷깃 일부가 다시 그려졌다. 강한 보존 문장을 붙여도 완전한 보존을 입증하지 못했다. 따라서 검수 기록을 색 정확도나 동일 픽셀 보증으로 표현하지 않는다. 기존 색 편집 프롬프트는 이 표본만으로 교체하지 않는다.
