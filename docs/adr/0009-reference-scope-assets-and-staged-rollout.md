# 생성예시 참고와 장소 세트의 내부 입력을 구분한다

상태: Accepted. 2026-10-15 사용자 승인으로 일반 컷의 옛 참고 범위 선택을 폐지했다.
이 문서는 이전 범위 선택 및 파일럿 공개 규칙을 대체한다. 과거 시행 기록은 Git 이력에 보존한다.

## 현재 계약

일반 컷은 선택한 완성 생성예시를 참고한다. 참고 범위 선택 기능은 제공하지 않는다. 스타일링 장소 세트만 내부적으로 공통 장소와 컷별 자세 자산을 나눠 쓰며, 스튜디오 세트는 완성 예시를 직접 참고한다. 이 내부 구조는 사용자가 고르는 모드가 아니다.

- 일반 컷은 `exampleId`에 대응하는 완성 사진(`all`)을 입력으로 사용한다. 선택 썸네일을 수집 원본으로 바꿔 넣는 변경은 하지 않는다.
- `refScope`는 사용자 선택이 아니다. 일반 컷과 스튜디오 세트는 `all`, 스타일링 장소 세트만 `pose`로 도출한다.
- 옛 저장값이나 요청이 일반 컷으로 들어오면 완성 생성예시 참고로 정규화한다. 선택한 예시와 기존 출력 이미지는 보존하며 자동 재생성하지 않는다.
- 일반 배경 전용 편집·재시도, 일반 자세 전용 리타게팅·후처리, 관련 공개 플래그를 제거한다.
- 현재 PRD, API 문서와 LLM 지시에서 폐지된 모드를 제공 기능이나 재도입 예정 기능으로 설명하지 않는다.

## 보존하는 장소 세트

이번 변경은 기존 세트 실행 경로의 보존이며, 공통 장소+자세 분리 방식의 품질 우월성이나 오너의 재승인을 뜻하지 않는다. 완성 예시 또는 수집 원본을 컷별로 직접 참고하는 대안과의 비교는 별도 검증·결정 사항이다.

- `spaceGroupId=ssg1__<setId>__<instanceId>`가 있는 발행 스타일링 세트만 내부 자세 자산과 공통 장소를 사용한다. 사용자 입력값 하나로 세트 권한을 만들 수 없으며 서버 카탈로그가 ID, 상품 적용성, 성별, 멤버·자산을 검증한다.
- 세트에서 떼어낸 개별 컷은 해당 멤버의 완성 예시를 사용한다. 이전 자세 자산이나 장소 권한을 이어받지 않는다.
- 스튜디오 세트의 완성 예시 직접 참고, 배경색 정책과 원본 상품·모델 정본은 유지한다.
- 세트의 공통 장소 검사와 재시도는 유지한다. 필요한 자산이 없으면 실패시키며 다른 입력으로 몰래 바꾸지 않는다.
- 세트 카탈로그, 원격 이미지, 사용자 생성 이미지와 과거 생성 이력은 삭제하지 않는다.

## 검증 경계

프론트의 저장본 읽기·예시 선택·세트 이탈·재시도와 서버의 저장 정규화·입력 선택·프롬프트·QC를 함께 확인한다. 일반 컷은 완성 예시, 스타일링 세트는 기존 장소 및 자세 입력을 받는지 검사한다. 현재 작업 폴더와 운영 배포 상태는 구분한다.
