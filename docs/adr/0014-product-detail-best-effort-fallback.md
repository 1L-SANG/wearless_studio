# 두 번 실패한 제품 디테일컷은 원본 기반 최종 후보를 만들고 가장 나은 컷을 발행한다

상태: Accepted (사용자 결정 2026-09-27)

## 맥락

ADR-0012의 제품 디테일 경로는 최초 생성과 교정 생성이 모두 독립 QC에 실패하면 빈 슬롯으로 끝난다. 복잡한 무늬나 반복 패턴의 재구성이 특히 어려운 상품에서는, 셀러 원본의 보이는 모양을 가볍게 정리한 디테일 사진이라도 보여주는 편이 낫다는 사용자 결정이 있었다. 2026-09-25의 4상품 A/B 결과는 이 촬영 방향을 보여주지만, 실제 두 번 실패한 상품에서의 성공률을 증명하지는 않는다.

## 결정

- 범위는 `product/detail`의 콘티 생성과 에디터 생성·방향 수정에 한정한다. 원본·색상·대상 부위 검증, 미세 패턴의 동일 색상 Detail 원본 통과, 다른 컷 계열은 유지한다.
- 최초 생성과 교정 생성의 독립 QC가 **둘 다 명확한 `FAIL`**일 때만 마지막 생성 1회를 허용한다. 첫째·둘째 판정이 `UNKNOWN`이면 생성 호출을 늘리지 않는다. 세 번째 이후 자동 생성은 없다.
- 마지막 생성은 같은 Sunburst 모델에 셀러 원본과 그 원본에서 자른 대상 영역을 입력한다. 대상 크롭이 있으면 이를 첫 이미지이자 구도 출발점으로 둔다. 크롭이 없으면 같은 방향의 `Detail`/`BackDetail` 원본을 구도 첫 이미지로 두고, 다른 색상의 근접 사진을 쓰는 경우 목표 색상의 전체 사진만 색상 정본으로 둔다. 앞의 실패한 AI 이미지와 다른 상품의 촬영 예시는 넣지 않는다. 촬영 구김과 놓임만 가볍게 정돈하고, 실제 재단·무늬·원단·봉제·부자재·영구 문자를 지킨다. 근거 없는 미세 조직이나 문자를 고해상도라고 새로 그리지 않는다.
- 세 번째 컷도 같은 독립 QC를 거친다. 통과하면 그대로 발행한다. 실패·판정 불가이면 판정 불가 후보를 이미 판정된 후보보다 뒤에 두고, 구조·색·무늬 → 영구 표식 → 임시 물체 → 대상 범위 → 사진 마감 순으로 비교한다. 동률이면 뒤의 후보를 고른다. 마지막 생성 호출 자체가 실패하거나 도중에 중단되면, 이미 저장되고 판정된 앞의 두 후보 중에서 같은 기준으로 고른다.
- QC를 통과하지 못한 채 고른 컷은 `publishedBestEffort=true`, `passed=false`, `selectedAttempt`와 세부 판정을 기록한다. `PASS`로 위장하지 않는다. 선택 후보의 바이트와 판정은 같은 작업의 비공개 체크포인트에 보존하고, 중단 복구와 동일 지문 작업 재시도에서 같은 컷을 쓴다. 중단된 모델 호출이나 판정을 다시 제출하지 않는다. 후보 파일이 읽히지 않거나 원본 근거 자체가 없으면 기존 실패 슬롯을 유지한다.
- 세 번째 생성과 QC의 추가 제공자 비용은 두 번 실패한 컷에서만 발생한다. 셀러 크레딧은 기존과 같이 실제 발행된 컷에 대해 한 번만 차감한다.

이 결정은 ADR-0012와 PRD의 제품 디테일 전용 **두 번 시도 후 무조건 미발행** 규칙을 대체한다. 다른 컷의 QC 정책은 바꾸지 않는다. 최선 후보 발행은 상품 사실의 완전 인증이나 복잡한 패턴의 생성 성공률 보증을 뜻하지 않는다.
