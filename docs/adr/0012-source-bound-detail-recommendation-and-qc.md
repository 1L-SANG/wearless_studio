# 디테일은 구매 정보로 추천하고, 원본 검수 통과 후에만 발행한다

상태: Accepted (사용자 결정 2026-09-25; 배포 검증은 PR 체크에 기록)

## 추천

분석의 강조 특징은 사진 한 장씩 만들라는 지시가 아니다. 기존 AG-08 분석 호출에서 상품 사진에 실제로 보이는 후보 부위를 함께 관찰한다. 구조 설명, 소재 정보, 마감 품질, 판독 가능한 라벨처럼 별도 사진에서 얻는 정보가 있어야 자동 추천한다. 장식의 존재만 다시 보여주는 `appearance_only` 후보는 문맥 안에 포함하고 자동 단독컷으로 배치하지 않는다. 레이스 전체를 금지하거나 면적으로 중요도를 판단하지 않는다.

최초 콘티 진입 시 기본형 최대 2컷, 확장형 최대 3컷이다. 원단도 이 한도 안의 후보이며, 유용하고 분명한 후보가 적으면 적게 배치한다. 유사한 정보를 반복하는 후보는 한 장으로 묶는다. 셀러 강조 특징은 후보 우선순위에 반영하지만 미확인 부위를 발명하지 않는다. 수동 추가는 제한하지 않고 편집·삭제한 콘티를 자동으로 채우지 않는다.

`detailRecommendations`는 원본 바이트 해시·슬롯에 묶인 서버 소유 분석 자료다. 공개 분석은 서명한 handoff를 로그인 후 업로드 원본과 확인해 승격한다. handoff의 서명·유효기간 검증이 실패하면 추천만 저장하지 않고 확정은 계속한다. 추천이 없는 상품과 같은 경로로 이어진다(사용자 결정 2026-09-26). 원본 불일치, 저장 충돌, 일시 오류는 확정을 막는다. 상품 증거 승격은 이 결정과 별개이며, 실패하면 확정을 막는다. 클라이언트는 `detailTargetId`만 선택하며 임의 사실·좌표를 생성 근거로 보낼 수 없다. EXIF 방향을 반영한 좌표로 원본 픽셀 크롭을 만든다. 분석 대상이 아닌 추가 사진은 선택 부위의 근거로 섞지 않는다.

인스펙터는 내 상품 앞/뒷면 전체 원본과 촬영 대상 이름을 일관되게 보여준다. 해당 전체 사진이 없으면 선택 부위의 원본 사진 전체를 표시한다. 잘린 부위 크롭은 생성·검수용 입력이며 별도 복잡한 크롭 편집기를 제공하지 않는다. 기존 생성예시는 선택적인 촬영 연출 참고로만 쓰고 상품 사실·촬영 대상·방향을 덮어쓰지 않는다.

## 생성과 검수

`product/detail` 전용 Sunburst 분기를 둔다. 다른 제품 전체컷·호리존·스타일링·마네킹 모델은 변경하지 않는다. 원본 전체와 선택 영역의 픽셀 크롭을 함께 입력한다. 촬영으로 생긴 구김과 배치를 정돈할 수 있지만 의도된 플리츠·핀턱·셔링·레이스 조직·부자재·영구 라벨은 보존한다. 확인되지 않는 원단 미세 조직이나 라벨 문자를 새로 만들지 않는다.

독립 검수는 `gpt-5.4-2026-03-05`로 촬영 대상/프레이밍, 구조, 색상/소재, 사진 마감의 4개 축을 먼저 확인한다. 이 검사에 통과하면 별도 호출이 영구 표식과 임시 촬영 부착물을 집중 확인한다. 생성 모델 Sunburst와는 별도 모델이며 두 판정 호출은 서로 다른 검수 책임을 가진다. 보정 표본에서 일반 판정기가 놓친 판매 태그와 잘못 거절한 영구 라벨을 전문 판정기가 구분했고, 실제 생성물에서는 Gemini가 원본에 존재하는 봉제선을 새 구조라고 오인한 것을 전용 GPT 구조 판정기가 바로잡았기 때문이다. 다른 분석 기능의 모델은 변경하지 않는다. 범위 밖 라벨을 삭제로 단정하지 않으며 존재와 글자 판독성을 구별한다. 영구 요소의 존재는 허용된 원본 전체에서 확인하고, 대상 크롭 하나에 없다는 이유로 새로 생긴 요소라고 판단하지 않는다.

명확한 1차 실패는 전문 판정을 생략해 불필요한 비용을 줄이지만, 완전 통과에는 두 검사가 모두 필요하다. 미검증 모델로 조용히 폴백하지 않는다. 불완전한 응답, 예외, 모순과 판독 불가는 `UNKNOWN`이다. 전문 판정의 보정 표본 지연은 약 33~54초였으며 90초 상한을 둔다. 이는 일반 분석 페이지의 12초 부가 분석 예산과 별개다.

생성은 최초 1회와 교정 최대 1회다. 교정은 원본과 1차 결과를 함께 보고, 전체 검수를 다시 통과해야 한다. 실패 축이 줄었다는 이유만으로 실패 사진을 발행하지 않는다. `FAIL`/`UNKNOWN`은 기존 실패 슬롯·미차감 경로로 종료하며 다른 성공 컷은 유지한다. `cut_done` 미리보기와 자산 저장도 통과 후에만 실행한다.

시도와 검수 상태는 작업 메타데이터에 리스 검증 후 기록하고 외부 요청 전에 커밋한다. 에디터 작업 재큐 시 소비된 호출을 반복하지 않는다. 중단된 요청/검수를 성공으로 추측하거나 같은 사진을 반복 판정해 통과를 얻지 않는다. 기존 범용 base/final 캐시는 이 분기에서 사용하지 않는다. 별도 디테일 지문(원본·대상·모델·정책·블록·사용자·프로젝트)이 같고 완전 통과가 확인된 최종본만 실패한 페이지 작업의 재시도에서 이어 써 이미 지불한 생성 비용을 아낀다. 미검수 베이스와 보류 결과는 이어 쓰지 않는다. 새 검수 완료 디테일 자산에는 서버 생성 레시피를 기록해 에디터 방향 수정에도 같은 원본 검수를 적용한다. 셀러가 명시적으로 다시 시도한 새 작업은 별도 요청이다.

분석이 `sourceMirrored === true`로 판정한 원본은 업로드 해시를 검증한 뒤 좌우 반전 보정과 대상 좌표 반사를 함께 적용한다. 생성과 검수는 동일한 보정 원본을 보며, 원래 추천 계약을 변경하지 않는다.

구형 미세 패턴의 원본 사진 그대로 사용하기는 유지한다. 새 대상 ID를 선택한 컷에는 선택 영역 검증을 적용한다. 타색 디테일을 구조 근거로 쓰는 기존 경로는 목표 색상 사진과 구조 사진의 권한을 분리한다. 보이지 않는 반대편을 추정하지 않는다.

## 검증과 한계

기존 연구 사례는 보정 자료로만 쓴다. 다른 상품의 정상/오류 대조군을 분리해 오수락·오거절·판단 불가를 각각 기록한다. 평가 표본·해시·판정기·프롬프트를 고정하고 사람이 본 의미 있는 오류와 비교한다. 소수 대조군 통과를 전체 상품의 정확도나 무오류 보증으로 주장하지 않는다. 추천 유용성도 셀러의 최종 선택을 대체하지 않는다.

이 결정은 ADR-0008/0010과 PRD에 남은 디테일 고정 장수·생성 후 실패 결과 보존 규칙에 대한 제품 디테일 전용 예외다. 다른 컷의 QC 정책은 바꾸지 않는다.

## 2026-09-26 후속 결정

위의 "다른 성공 컷은 유지"는 상세페이지 최종 출고 정책에서 대체됐다. 이제 AI 컷이 한 장이라도 미완성이면 전체 페이지를 실패 처리하고 예약 크레딧을 전액 해제한다. 디테일 컷의 품질 후보는 여전히 최초 1장과 교정 1장까지다. 다만 프로바이더가 생성하지 않았음이 확인되는 일시 오류는 작업 원장의 생성 시도 3회 한도 안에서 다시 시도하며, 응답이 불확실하거나 이미 과금됐을 수 있는 오류는 재시도하지 않는다. 확정 거절된 HTTP 요청의 안전한 내부 전송 재시도는 생성 후보 수에 포함하지 않는다.

## 2026-09-27 후속 결정

ADR-0014가 위의 두 번 생성 상한, 미세 패턴 원본 사진 직행, 최종 QC 실패 시 무조건 미출력 규칙을 대체한다. 체크·스트라이프도 새 이미지를 생성하고 원본과 같은 픽셀 결과는 제외한다. 두 번의 명확한 QC 실패 뒤 세 번째 원본 모양 기반 후보를 만들 수 있으며, 끝내 통과하지 못해도 저장된 생성 후보 중 상품 사실 오류가 가장 덜 중대한 컷을 QC 미통과로 표시해 발행하고 정상 차감한다. 명확한 핵심 실패에서도 로고·영구 표식을 검사해 후보 비교에 반영한다. 생성 후보가 없으면 상세페이지 전체 실패·예약 전액 해제다. 원본은 생성·검수의 근거이지 최종 이미지 대체물이 아니다.

## 2026-10-11 후속 결정, 디테일샷 생성 화질

오너 결정. `product/detail` 생성 호출만 OpenAI 이미지 요청의 화질을 `high`로 보낸다. 운영 설정 `PRODUCT_DETAIL_IMAGE_QUALITY=high`(api, detail-worker)로 켜며 코드 기본값은 `medium`이다. 최초, 교정, 원본 모양 기반 세 번째 후보에 모두 적용하고 결과 기록에 실제 화질을 남긴다. 해상도는 기존 2K(1536×2304)를 유지한다.

근거는 같은 입력과 프롬프트에서 화질만 바꾼 비교다(니트 단추 여밈, 체크 셔츠 칼라, 슬랙스 허리 여밈 각 1장). 세 상품 모두 `high`에서 니트 코, 체크 실선, 능직 원단 결이 또렷했고 기본 내려받기 폭 860px에서도 차이가 남았다. 장당 생성 비용은 약 $0.07에서 $0.12로 늘고 시간은 5~17초 늘었다. 같은 비교에서 호리존과 고스트샷은 860px에서 차이가 거의 없어 `medium`을 유지한다. 스타일링의 확정 프로필 `medium`도 바꾸지 않는다.

재시도 체크포인트 지문에는 화질을 넣지 않는다. 배포 시점에 진행 중인 디테일컷이 지문 불일치로 실패하지 않게 하기 위해서이며, 같은 작업의 후보 사이에 화질이 섞여도 생성과 검수 계약은 바뀌지 않는다.
