# 제품컷 세 촬영 방식 구현과 비교 계획

사용자 요청은 업로드 의류로 고스트컷, 평면컷, 자연광컷을 만들고 Nano Banana 2.1, Nano Banana Pro, GPT Image 2.5 Flare와 Sunburst를 비교하는 것이다. 세 방식은 ADR-0024의 선택 필드로 구현한다. 기존 작업이 많은 현재 체크아웃을 사용하며, 다른 작업의 변경은 보존한다. 커밋과 배포는 수행하지 않는다.

## 구현

1. 원본 보존 계약과 세 촬영 프롬프트를 분리한다. 명시한 방식이 예시와 충돌할 때의 우선권을 생성과 검수에 동일하게 전달한다.
2. 콘티와 에디터 새 이미지 UI에 기존 선택 버튼 패턴으로 촬영 방식을 추가한다. 데이터 정규화, HTTP 요청, 자산 레시피, 재시도와 중복 판정에서 값을 유지한다.
3. 동일 원본, 촬영 방식, 공통 프롬프트를 네 모델에 전달하는 비교 스크립트를 만든다. 기본 실행은 계획과 프롬프트만 기록한다. 라이브 실행은 별도 승인과 호출 수, 비용 제한을 요구한다.
4. 현재 요구사항과 데이터 계약을 갱신하고, 테스트 및 빌드 결과를 보고한다. 유료 API 실측은 승인 전 실행하지 않는다.

## 검증 초점

- 기존 값이 없는 제품컷은 프롬프트와 저장 의미가 바뀌지 않아야 한다.
- 방식이 다른 컷을 한 장으로 합치거나 자동 초기화하지 않아야 한다.
- 디테일과 착용컷으로 바꾸면 제품 전체 촬영 방식은 제거되어야 한다.
- 원본 앞뒷면과 색상은 생성예시 때문에 바뀌지 않아야 한다.
- 페이지 생성, 에디터 새 이미지, 재시도와 자산 기록이 동일한 방식을 전달해야 한다.
- 검수에서 임의 문자열을 지시로 사용하지 않고 고정된 방식만 읽어야 한다.
- 비교 계획 실행은 네트워크를 사용하지 않아야 하며, 승인 계획과 원본이 바뀌면 라이브 실행을 거절해야 한다.

## 화면 기준

주 기준은 기존 `DESIGN.md`와 제품 원본 선택 UI다. 인접한 샷 선택과 동일한 흑백 버튼, 서체, 간격, 접근성 규칙을 사용한다. Frame은 생성할 사진의 촬영 기준으로만 참고한다. 새 레이아웃이나 시각 테마는 도입하지 않는다.

## 실측과 제한

사용자는 2026-11-01 이 대화에서 총 API 비용 15달러와 GPT 사용량을 Gemini의 두 배까지 승인했다. 사용량은 생성 호출 수로 해석해 알렸다. 상의, 하의, 아우터, 원피스 각 하나씩, 촬영 방식 셋으로 비교한다. Gemini 두 모델은 조건별 한 번씩 총 24회, GPT 두 모델은 공통 지시와 모델별 지시를 각 한 번씩 총 48회다. 총 72회이며 재시도와 자동 AI 심사는 포함하지 않는다.

Gemini는 1K, GPT는 medium 품질로 비교하며 실제 출력 크기를 결과에 남긴다. 공통 프롬프트 비교와 모델별 지시 실험은 구분한다. 카테고리별 실행은 18회, 예산 3.75달러로 나눠 합계 15달러 이내로 관리한다. 실제 사용량 누락이나 요청당 보수적 예약액 초과가 발생하면 그 실행을 멈춘다. API는 처리 중인 한 건의 정확한 청구액 상한을 제공하지 않으므로 요청 전에 여유분을 남긴다.

정확한 실행값은 dry-run 산출물로 고정한다. 카테고리당 상품 한 벌의 시험은 연결과 초기 결함을 찾는 용도이며, 모든 소재와 세부 품목의 품질 보장은 대표 표본을 늘린 별도 검증이 필요하다.

## 실행 결과

첫 72회 뒤 실제 결함을 근거로 프롬프트를 보강하고 같은 72조건을 다시 비교했다. 총 144회, Gemini 48회와 GPT 96회이며 사용량 환산액은 7.142901달러다. 두 번째 실행의 네 카테고리 한도는 각각 2.75달러였고, 첫 실행 비용과 합친 최대 계획액은 14.5349415달러였다. 자동 재시도와 유료 AI 심사 호출은 없었다.

서버 전체 9,727개 통과, 106개 건너뜀. 프론트 전체는 3,666개 통과와 기존 요청 헤더 모의 테스트 7개 실패다. 빌드와 독립 코드 재검토를 완료했다. 최종 관찰과 남은 품질 한계는 `documents/research/2026-11-01-product-photography-results.md`에 기록했다. 99% 품질 목표는 달성 또는 인증한 것으로 처리하지 않는다.

## 2026-11-02 PR 통합 검증

최신 main의 거울컷 제거와 참고 범위 정리를 유지한 별도 브랜치에 제품컷 변경만 옮겼다. 계약 번호는 ADR-0024다. 원본 기반 제품컷 카드의 잘못된 예시 누락 경고를 추가로 수정했다. 서버 전체 11,349개 통과, 218개 건너뜀. 프론트 전체 4,505개 통과, 빌드 통과. 이 통합 검증 중 유료 API 호출은 없었다.
