# 일반 단건결제 심사 전용 경로

## 목적

일반결제 MID `wearlen6s9`의 카드사 심사를 위해 1회성 추가구매 크레딧과 토스 일반결제창을 확인할 수 있는 독립 URL을 제공한다. 진행 중인 정기결제 카드사 심사의 URL, 상품, 테스트계정은 변경하지 않는다.

## 결정

- 새 URL은 `https://pay.wearless.kr`로 한다.
- `toss.wearless.kr`은 정기결제 심사 전용 상태로 유지한다.
- `pay.wearless.kr`은 100 크레딧 5,500원, 500 크레딧 26,000원 상품만 표시한다.
- 구독 상품과 수동 계좌이체는 `pay.wearless.kr`에서 숨긴다.
- 루트 접속은 단건결제 상품 화면으로 이동한다.
- 결제 버튼은 기존 `requestPayment` 일반결제 흐름과 `VITE_TOSS_CLIENT_KEY`를 사용한다.
- 상품 설명은 1회 결제, 결제 완료 즉시 계정 지급, 구매일부터 12개월 사용, 현금 전환·양도 불가 기준을 명확히 표시한다.
- 휴대폰결제는 이번 계약에서 신청하지 않는다.

## 제약

- 일반결제 시크릿 키가 계약 전 운영 서버에 없을 수 있다. 이 경우 `pay.wearless.kr`에서만 고정 상품 정보로 테스트 결제창을 열 수 있다. 성공 복귀의 승인 API와 크레딧 지급은 기존 서버 가드가 계속 막는다. 계약 키 발급 후 서버 주문과 실제 승인 경로를 다시 검증한다.
- `pay.wearless.kr`을 API CORS 허용 목록에 추가한다.
- 심사 중에는 `pay.wearless.kr`의 상품, 테스트계정, URL을 변경하지 않는다.
- 테스트 로그인 계정은 기존 PG 확인용 계정을 재사용한다.
- 신규 추가구매 크레딧은 구매일부터 12개월 후 남은 수량을 소멸한다. 기존 무기한 구매는 소급 변경하지 않는다.

## 검토한 대안

1. `toss.wearless.kr` 재사용: 정기결제 카드사 심사 중 수정 금지 조건과 충돌해 제외한다.
2. `ai.wearless.kr` 재사용: 실제 운영 상품과 계좌이체 흐름을 바꿔야 하고 심사 중 동결하기 어려워 제외한다.
3. `pay.wearless.kr` 분리: 기존 운영과 정기결제 심사를 보호하면서 일반결제 화면만 고정할 수 있어 채택한다.

## 검증 기준

- `pay.wearless.kr` 루트에서 단건결제 상품 두 개만 보인다.
- 정기구독 카드와 계좌이체 문구가 보이지 않는다.
- 로그인 후 충전 버튼이 토스 일반 카드결제창을 연다.
- 기존 `toss.wearless.kr` 정기결제 화면과 `ai.wearless.kr` 계좌이체 화면은 그대로다.
- 푸터 사업자정보와 환불정책 링크가 유지된다.
