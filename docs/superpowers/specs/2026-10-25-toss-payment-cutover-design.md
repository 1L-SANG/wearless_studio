# 토스 결제 전환 설계

## 목적

정기결제 계약이 완료된 상태에서 `ai.wearless.kr`의 신규 구독을 토스 카드 자동결제로 열고, 별도 일반결제 MID 심사는 `pay.wearless.kr`에서 계속 진행한다. 정기결제 심사용 `toss.wearless.kr`과 일반결제 심사용 `pay.wearless.kr`을 카드사 심사가 끝날 때까지 그대로 유지해 심사 중 홈페이지 변경으로 반송되는 일을 막는다.

## 현재 상태

- 정기결제 MID는 `bill_wearlau5j`다. 계약은 완료됐고 카드사 심사가 진행 중이다.
- 정기결제 심사 등록 URL은 `https://toss.wearless.kr`이다. 이 호스트는 월간 구독 3종과 토스 카드 등록창만 보여준다.
- 운영 앱 `https://ai.wearless.kr/pricing`은 아직 수동 계좌이체 구독과 수동 크레딧 충전을 보여준다.
- 일반결제 MID는 `wearlen6s9`다. `https://pay.wearless.kr`에서 100 크레딧 5,500원과 500 크레딧 26,000원만 심사한다.
- 프런트에는 자동결제 MID의 라이브 클라이언트 키와 일반결제 MID의 테스트 클라이언트 키가 각각 들어 있다.
- 서버는 자동결제 라우트와 청구 워커가 켜져 있으며, 자동결제 시크릿 키, 빌링키 암호화 키와 웹훅 경로 시크릿을 참조한다.
- `GET /v1/subscriptions/me`가 운영에서 200으로 응답한다.

## 선택한 전환 방식

### 선택: 운영 앱의 구독만 먼저 토스 카드로 전환

`ai.wearless.kr`에서 수동 계좌이체 신규 신청과 추가구매 크레딧을 숨기고 월간 카드 자동결제만 연다. 심사용 두 호스트는 그대로 둔다. 카드사 심사가 끝나면 정기결제 MID의 홈페이지 URL을 `https://ai.wearless.kr/pricing`으로 변경 신청하고, 승인 확인 후 `toss.wearless.kr`을 내린다.

이 방식은 이미 완료된 정기결제 계약을 사용하면서도 일반결제 미승인 상태와 상품을 섞지 않는다. `toss.wearless.kr`의 상품, 가격, 푸터, 로그인과 URL을 변경하지 않으므로 진행 중인 카드사 심사의 고정 항목을 보존한다.

단, 카드사 심사가 끝나기 전에 등록 URL과 다른 `ai.wearless.kr`에서 승인된 카드사를 이용해 판매해도 되는지는 토스 안내문에 명확히 적혀 있지 않다. 배포 전 계약팀 또는 고객센터에서 이를 확인한다. 허용되지 않으면 `toss.wearless.kr`에서만 실결제를 받거나 전 카드사 승인까지 오픈을 미룬다.

## 검토한 다른 방식

1. 모든 카드사 승인 뒤 한 번에 전환한다. 심사 위험은 가장 낮지만 구독 오픈이 늦어진다.
2. 정기결제와 일반결제를 동시에 `ai.wearless.kr`에서 연다. 일반결제 계약과 라이브 키가 아직 준비되지 않았고 추가구매 정책 시행일도 2026년 11월 23일이라 현재는 사용할 수 없다.

## 호스트와 MID의 최종 역할

| 단계 | `ai.wearless.kr` | `toss.wearless.kr` | `pay.wearless.kr` |
|---|---|---|---|
| 지금 | 수동 계좌이체 구독과 충전 | 정기결제 카드 심사 | 일반결제 충전 심사 |
| 1차 전환 | 월간 카드 자동결제만 판매 | 변경 없이 정기결제 심사 유지 | 변경 없이 일반결제 심사 유지 |
| 정기결제 심사 완료 | 월간 카드 자동결제 | URL 변경 승인 뒤 종료 | 일반결제 심사 유지 |
| 일반결제 심사 완료 | 월간 구독과 추가구매 크레딧 | 종료 | URL 변경 승인 뒤 종료 |

## 수동 계좌이체의 처리

- 신규 신청만 중단한다.
- 이미 생성된 신청은 조회, 취소와 관리자 확인을 계속 지원한다.
- `requested` 신청이 남아 있으면 입금 계좌를 계속 확인할 수 있게 하고, 신청이 모두 지급·취소·만료된 뒤 서버의 계좌정보 제공을 끈다.
- 이미 지급된 수동 1개월 이용권은 종료일까지 유지한다.
- 활성 수동 이용권이 있는 계정에는 토스 정기결제를 중복 시작하지 못하게 하는 기존 서버 제약을 유지한다.
- 계좌이체 코드와 DB 테이블은 삭제하지 않는다. 운영 장애 시 되돌릴 수 있는 비상 경로로 남긴다.

## 심사용 이메일 로그인

이메일 로그인은 `toss.wearless.kr`과 `pay.wearless.kr`에서만 노출한다. `ai.wearless.kr`은 구글과 카카오 로그인만 보여준다. 정기결제 심사가 끝나도 일반결제 심사가 남아 있으므로 테스트계정은 일반결제 심사가 끝날 때까지 유지한다.

## 토스 관리자 URL 변경

- 카드사 심사 중에는 등록 URL과 심사 화면을 변경하지 않는다.
- 정기결제 카드사 심사가 모두 끝난 뒤 `bill_wearlau5j`의 홈페이지 정보를 `https://ai.wearless.kr/pricing`으로 변경 신청한다.
- 변경 승인 전에는 `toss.wearless.kr`의 DNS, Vercel 도메인과 API CORS를 유지한다.
- 일반결제 카드사 심사가 끝난 뒤 `wearlen6s9`도 같은 운영 요금제 URL로 변경 신청한다.
- 각 MID의 URL 변경 승인을 확인한 뒤에만 해당 심사 도메인을 제거한다.

## 일반결제 심사 보완 확인

정기결제 심사에서 지적받았던 항목은 일반결제 심사 화면에서 다음과 같이 분리됐다.

- 크레딧 이월 혼동: 일반결제 상품은 구독 크레딧이 아니라 추가구매 크레딧이며 결제일부터 12개월로 표시한다.
- 연간결제 금지: `pay.wearless.kr`에는 정기결제와 연간결제가 모두 없다.
- 푸터 상세주소: 상호명, 대표자, 사업자등록번호, 연락처와 `3층 A-4호 스타트업스테이션`까지 표시한다.
- 카드 결제창: 일반결제 테스트 키로 토스 결제수단 선택창과 신용·체크카드 화면을 열고 PPT에 포함했다.
- 테스트계정: 이메일과 비밀번호 로그인이 실제로 성공한다.
- 상품과 금액: 고정 상품 2개만 노출하고 최고가는 26,000원이다.
- 환불과 제공기간: 미사용 결제의 7일 이내 전액 환불과 최대 12개월 제공기간을 공개 문서에 표시한다.

일반결제 메일에는 Seller 5%, Pro 10%의 조건부 충전 보너스를 함께 설명하고, 실제 일반결제 판매 시작일이 정책 시행일인 2026년 11월 23일보다 빠르지 않다고 명시한다.
현재 일반결제 화면은 카드와 간편결제만 열고 계좌이체를 호출하지 않는다. 신청서에 계좌이체가 포함돼 있으므로 회신 메일에서 계좌이체를 사용하지 않는다고 알리고 계약 결제수단에서 제외할 수 있는지 요청한다.

## 성공 기준

- `ai.wearless.kr/pricing`에서 구독 3종은 `구매하기`를 표시하고 추가구매 크레딧과 수동 계좌이체 버튼은 표시하지 않는다.
- `toss.wearless.kr/pricing`과 `pay.wearless.kr/pricing?tab=topup`의 심사 화면은 기존과 동일하다.
- 수동 계좌이체 신규 신청은 서버에서 503으로 거절하지만 기존 신청 조회, 취소, 관리자 확인과 수동 이용권 조회는 계속 동작한다.
- 자동결제 카드 등록, 첫 결제, 구독 관리, 해지, 결제 실패 유예와 정기 청구가 운영 MID로 동작한다.
- 카드사 심사가 진행 중이면 승인 완료된 카드사만 사용할 수 있음을 운영자가 인지하고, 미승인 카드사 실패를 장애로 오판하지 않는다.
- 각 심사 도메인은 해당 MID의 홈페이지 URL 변경 승인이 끝난 뒤에만 제거한다.
