# 생성 전 한 장 요약 검증

실사용 모델은 gpt-6.1-sol, effort는 xhigh다.

## 확인한 동작

마네킹의 진행 버튼은 생성 요청 대신 확인 창을 연다. 최종 확인은 기존 잔액 검사와 생성 경로를 쓴다. 분석 수정은 같은 프로젝트를 유지하고 저장이 끝나면 콘티로 돌아간다. 새 핏과 사진 그대로인 핏은 재생성 입력까지 보존한다.

새 Node 테스트 27개와 전체 프론트 테스트 2,904개가 통과했다. 실제 생성 스토어의 API 경계를 목으로 바꿔, 확인 전 요청 0건과 두 번 확인 및 라우트 중복 진입에서 요청 1건을 확인했다. pnpm build도 통과했다.

글자마다 Range 위치를 재어 공백 없는 글자 사이의 줄 전환을 찾고, 요소의 가로 크기와 페이지 넘침을 검사했다. 긴 카테고리와 여러 특징을 넣은 Chromium 추가 검사도 다섯 폭에서 모두 0건이었다. WebKit은 실제 Safari에서 같은 폭의 프레임을 렌더해 검사하고 캡처했다.

스크린샷은 실제 GenerationSummary 컴포넌트에 목 데이터를 props로 전달한 화면이다. 앱의 기존 모바일 PC 전용 제한을 유지하면서 재사용 화면의 좁은 폭을 검증했다. 데스크톱은 1280×900, 폰 화면은 각 폭×900이다. 현재 저장소 카탈로그의 모델 및 매칭 의류 사진을 사용했다.

소재 고치기에서 분석으로 이동하고 수정 후 같은 콘티로 돌아가는 동작도 로컬 목 앱에서 직접 확인했다. 운영 쓰기와 실제 유료 생성 호출은 실행하지 않았다.
