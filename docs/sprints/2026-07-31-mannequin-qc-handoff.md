## 3. 검증된 것 (전부 실 생성물)

**거울 반전 수정** — 같은 입력에서 신호만 껐다 켬
`OFF: fidelity 55, "mirrored orientation with reversed numbers"` → `ON: fidelity 80, pass`.
육안으로 `302` 가 정방향으로 복원되고 가슴 프린트 위치도 반대쪽으로 이동(비대칭 요소까지).

**QC 정확도** — 플래그된 컷 3건 육안 대조, **오탐 0/3**
`garment shape broken` 판정 컷은 실제로 앞섬이 몸을 뚫고 함몰돼 있었다. 로고 케이스에서는
첫 글자만 뭉개지고 나머지가 멀쩡해 **사람이 놓치기 쉬운 결함을 QC 가 잡았다**.

**D축 변별력** — 합성 변형으로 눈금 확인
대조군 95 → 밝기 −25% 20 · 배경 색온도 15 · 복합 15. **격차 80.** 사유도 정확히 지목한다.
실 생성물이 95~100 인 것은 판정이 후해서가 아니라 실제로 일관되기 때문이다.

**배선 완결** — 워커 → DB → repo → 라우트 → response_model → `qcScores` 실 DB 확인.

## 5. 결정이 필요한 것

1. **`IMAGE_QC: shadow` 배포** — manifest 에 넣었으나 미배포. main 머지 시 CD 가 자동 배포한다.
   shadow 는 게이팅이 없어 안전하고(최악 입력에서도 재생성 0 을 테스트로 고정), 켜야 실

2. **enforce 승격** — 아직 이르다. 근거: 정확도 표본이 육안 3건뿐이고, 신규 분포도 16건이다.
   shadow 로 프로덕션 데이터를 모은 뒤 판단할 것.
3. **Phase 4(검수 UI)·5(N-best)** — 이번 범위 밖. Phase 5 는 크레딧 단가 결정이 선행돼야 한다.

## 6. 알아둘 것

- **표본은 반드시 생성 시점으로 층화할 것.** 뭉뚱그렸다가 "로고 재현 55% 실패" 라는 잘못된
  결론을 냈다. 07-24 구컷(중앙 56.5)과 07-31 신규(80.0)가 섞여 있었다. 캘리브 스크립트가
  이제 `created_at` 을 기록하고 층화 리포트를 자동 출력한다.
- **bust 2패스가 마네킹 가슴 형태를 어색하게 만드는 사례가 있다.** `physical_naturalness` 가
  이걸 잡고 있으므로 2패스 튜닝의 계측 지표로 쓸 수 있다.
- 레터링 프롬프트 규칙은 측정 후 **기각**했다(OFF 80.8 / ON 80.0, 노이즈).
- 로컬 54322 기준으로 작업했다. prod DB 는 손대지 않았다.
