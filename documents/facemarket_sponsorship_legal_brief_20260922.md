## 1. 제품 사실 (문서의 근거, 바꾸지 말 것)
- 협찬 = 셀러가 모델에게 **옷을 증정**하고, 모델은 옷을 받은 뒤 **3일 이내 본인 인스타그램 피드에 착용 게시물 1회** 게시, **30일 유지**. 현금 없음, 반납 없음, 릴스·영상 없음, 브랜드 채널 납품 없음.
- 모델은 등록 위저드 사용 조건 단계에서 **"의류 협찬 받기" 토글(기본 꺼짐)**을 켠다. 켜 두면 셀러가 바로 요청할 수 있고, 옷을 받으면 게시한다. **건별 수락 없음.** 언제든 끌 수 있고(마이페이지), 켜 둔 동안 온 요청만 진행. 협찬 품목은 기존 허용 품목 설정을 그대로 따른다.
- 켤 때 입력: 인스타 계정, 팔로워 수(본인 입력, 기준일 기록), 상의·하의 사이즈. 배송지는 요청 시점에 받는다.
- 협찬은 **초상 라이선스 증서(VC)에 넣지 않는다.** 착용컷 생성·정산과 별개의 거래다.
- 협찬 게시물의 2차 활용(셀러가 자기 몰·광고에 인용)은 기본 불가, 별도 합의.
- 1차 배포는 화면과 저장 필드만. 요청·발송·게시 확인 흐름은 2차.

## 2. 1차 기획: 무엇을 바꿔야 하나 (Claude 판단)

### 2-1. 새 동의 항목 1개 (필수 아님, 토글이 곧 동의 행위)
- 이름(가안): **"의류 협찬 참여 동의"**. 위치: 04 동의서 E절(사용 조건 → 라이선스 발급) 아래 새 항목 **E-2**. 성격: 선택, 토글 on이 동의 행위, off가 철회. 사전 체크 금지.
- 동의문에 담을 것: 무엇을 받는가(옷, 증정, 반납 없음, 현금 없음), 무엇을 하는가(3일 이내 본인 피드 1회, 30일 유지), 누가 요청하는가(켜 둔 동안 셀러가 바로), 어떻게 그만두는가(언제든 끔, 켜 둔 동안 온 요청은 진행), 품목 한계(허용 품목 안에서만), 게시물 권리(모델 소유, 셀러 2차 활용 불가), 광고 표시 의무 안내(옷만 받아도 「추천·보증 심사지침」상 경제적 이해관계 표시 대상, 캡션 문구는 회사가 제공), 개인정보(인스타 계정·팔로워 수·사이즈·배송지의 수집 목적과 셀러 제공 범위).
- 기록: 일시·문서 버전·계정·IP·화면. 토글 on/off 이력이 곧 동의·철회 기록.

### 2-2. 개인정보 수집 항목 추가 (03 처리방침, 04 A-3 또는 별도 항목)
- 새 항목: 인스타그램 계정, 팔로워 수와 기준일, 상의·하의 사이즈, (2차) 배송지·연락처. 수집 근거는 협찬 참여 동의(선택). 보유 기간: 토글 off 또는 탈퇴 시 파기(배송지는 발송 완료 후 N일, 조건표에 둔다).
- **제3자 제공 항목 신설**: 협찬 요청 셀러에게 배송지·연락처·사이즈·인스타 계정을 제공한다. 제공받는 자(요청 셀러), 목적(의류 발송), 항목, 보유 기간을 처리방침 제3자 제공 표에 적는다. 이건 처리위탁이 아니라 **제3자 제공**이라 별도 동의 대상(개인정보위 선례 기준, 9/11 메모). 동의는 E-2 안에 분리된 체크로 둘지 E-2 본문에 포함할지는 Codex가 판단하고 근거를 적는다.

### 2-3. 초상 라이선스 계약 02 (v1 + v2 델타 위에 얹는 v3 델타)
- 제3조 이용허락 범위에 **"협찬 게시물은 이 계약의 이용허락 범위 밖이며, 모델 본인이 촬영·게시하는 모델 소유 콘텐츠"**라는 한 줄을 넣어 착용컷 라이선스와 분리한다.
- 제14조 우회 거래: 협찬으로 연결된 셀러와 모델이 플랫폼 밖에서 직접 유료 촬영·광고 계약을 맺는 것을 우회 거래에 포함할지 결정하고 근거를 적는다(Claude 의견: 12개월 우회 제한은 착용컷 라이선스에만, 협찬은 제외. 협찬은 무상이고 모델의 SNS 활동을 회사가 묶으면 약관규제법 §11 위험).
- 제12조 철회 효과: 라이선스 철회 시 협찬 토글도 자동 off, 진행 중 협찬(옷 발송됨)은 게시 의무 유지 여부를 정한다(Claude 의견: 이미 받은 옷은 게시하거나 반송, 모델 선택).

### 2-4. 셀러 라이선스 이용조건 05 (v1 + v2 델타 위 v3 델타)
- 새 조: **협찬 요청 조건**. 요청 전 확인 사항(모델 허용 품목 안의 옷, 새 상품, 발송 기한 N일), 배송지·연락처의 목적 외 사용 금지와 파기, 게시물 2차 활용 금지(별도 합의 시 예외), 모델 미게시 시 회사의 조치(협찬 off 처리, 셀러 재요청 차단 등은 2차 흐름에서 확정이므로 "회사 정책에 따른다"로), 현금·추가 대가 요구 금지, '광고' 표시 의무는 게시자(모델)에게 있으나 셀러는 표시 삭제를 요구할 수 없다.
- I절 셀러 동의(04 I-1)에 "협찬 요청 조건" 확인 항목 추가.

### 2-5. 모델 약관 01, 법적 FAQ 06, 공개 FAQ
- 01: 서비스 정의에 협찬 중개 한 줄, 회사 역할(중개, 옷의 품질·배송 책임은 셀러), 분쟁 시 회사 역할.
- 06 FAQ: "협찬은 꼭 해야 하나요", "옷만 받으면 광고 표시 안 해도 되나요"(아니요, 해야 함), "받은 옷은 돌려주나요", "내 게시물을 셀러가 써도 되나요".

### 2-6. 조건표 (00 부록 C) 추가 행
- 협찬 게시 기한 3일, 유지 30일, 반납 없음, 현금 없음, 배송지 보유 기간 N일(제안: 발송 완료 후 30일), 셀러 발송 기한(제안: 요청 후 7일).

### 2-7. 코드 접점 (문서와 같이 가야 하는 것)
- 동의 유형 등록: 서버의 동의 유형·버전 상수(`facemarket_enrollment.py`의 CONSENT 관련 상수, `legal_versions.py`)에 협찬 동의 유형과 버전을 추가하고, 토글 on/off를 동의 기록 테이블에 남기는 방식을 설계한다(구현은 화면 지시서 트랙과 충돌하지 않게 **설계와 마이그레이션 초안까지만**, 실제 배선은 화면 트랙에서).
- 처리방침·동의서 버전을 올리면 기존 등록 모델에게 재동의가 뜨는지 확인하고, **협찬 동의는 신규 선택 항목이라 기존 모델 재동의를 강제하지 않는** 경로를 설계한다.

## 3. Codex에게 맡기는 2차 기획 (판단하고 근거를 적을 것)
1. 새 동의를 04 E-2 하나로 둘지, "협찬 참여"와 "배송지 제3자 제공"을 두 체크로 나눌지.
2. 옷 증정이 소득세법상 기타소득·증여 이슈가 있는지, 있다면 H절(정산·세무)에 한 줄 필요한지. 확신 없으면 변호사 검토 포인트로만 남긴다.
3. 광고 표시 문구의 정확한 형태(「추천·보증 등에 관한 표시·광고 심사지침」 2026 개정 기준, 인스타 피드 게시물 첫 줄 표기). 근거 조문 인용.
4. 미성년·에이전시 소속 배제 진술(B-6)이 협찬에도 자동 적용되는지, 별도 문장이 필요한지.
5. 위 2-3, 2-4의 Claude 의견에 동의하지 않으면 반박하고 대안을 적는다.
