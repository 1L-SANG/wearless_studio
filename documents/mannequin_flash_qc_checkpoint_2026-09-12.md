# Flash 기반 마네킹 검사, 로컬 구현 체크포인트

최신 보정 정책은 [9월 14일 첫 컷 보존 정책](mannequin_preservation_v2_2026-09-14.md)을 따른다. 아래는 Flash 검사 실험 당시의 기록이며, 당시의 미탐과 과탐이 해결됐다는 뜻은 아니다.

마네킹 역할 분담 검사의 기본 모델을 Gemini 3.8 Flash로 변경했다. 형태, 디테일, 원단 담당은 독립 3회 동시 호출하며 low thinking, 최대 출력 2048, 기본 25초 응답 제한을 사용한다. Astra를 설정해도 OpenAI로 호출하거나 폴백하지 않는다. 검사 전체 기본 모드는 off다.

각 역할에 필요한 원본만 전달하고 중복 확대와 매칭 전용 사진을 줄였다. 현재 사진에 묶인 AG-01 계약이 있으면 hardFacts와 uncertainties, 면별 설명을 재사용한다. 사진 근거는 여전히 우선이며, 불명확한 소매 명칭을 강제로 맞추라고 하지 않는다. 응답 종료 상태와 근거 사진 번호, 영역, 원본·생성본 구분을 서버에서 검증한다.

생성 전의 별도 Astra 구조 분석은 제거했다. 저장된 AG-01 계약의 해시와 원본 바이트 및 순서가 일치할 때만 첫 생성에 넘긴다. 기록이 없거나 오래됐으면 해당 기록을 사용하지 않고 원본 사진 경로를 유지하며 별도 분석 AI를 호출하지 않는다. 첫 생성 기본 모델은 최신 합의대로 Sunburst 2K다. 이 설정을 운영에 배포한 것은 아니다.

동일 5개 후보 기준 과거 Astra 구성 평균 $0.399048, 58.159초였고, 새 Flash와 AG-01 재사용 구성은 $0.016661, 10.488초였다. 모델·입력·지시 구성 전체의 실험 수치이며 운영 SLA가 아니다. 원본 특징이 있는 경우 세로선 누락을 잡았고 정상 3종을 허용했으나 중복 가슴선은 놓쳤다. 후보를 먼저 제시한 추가 실험 한 번에서는 중복선을 잡았다. 그 변형은 아직 일반화 검증 전이라 기본 코드에 넣지 않았다.

단추 6개 결과를 불합격시키기는 했지만 단추를 5개라고 잘못 읽고 다른 선을 이유로 지적했다. 이를 단추 검출 성공으로 계산하지 않는다. 검사를 켜면 완벽하게 출고 품질을 보장한다고 주장할 수 없으므로 enforce 활성화는 보류한다.
