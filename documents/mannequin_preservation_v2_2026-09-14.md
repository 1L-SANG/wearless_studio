# 마네킹 첫 컷 보존 정책

2026년 9월 14일에 승인하고 9월 15일에 보완한 방향을 구현한다. 첫 생성은 Sunburst 네이티브 1K medium이며, 판매자 화면에는 같은 바이트를 LANCZOS로 2배 확대한 별도 표시본을 쓴다. 후속 AI 입력과 편집은 네이티브 원본을 계속 사용한다. 기존 AG-01의 저장된 hardFacts와 원본 사진 및 크롭을 재사용한다. 정확한 위치는 cm 좌표가 아니라 옷의 곡선, 단추, 밑단 같은 상대적인 기준과 사진 근거로 표현한다.

## 정책

- 기본 여성 체형은 입력 마네킹을 유지한다. 임의 C컵, 돌출 1.3배, 허리 조이기, 단추 벌어짐이나 개수 추가를 요구하지 않는다. 미용 목적 가슴 보정과 무늬라는 이유만으로 하는 원단 보정은 기본 off다.
- 기본 첫 생성은 1회다. 확인된 중요 오류가 있을 때만 현재 컷과 원본 및 관련 크롭을 받는 Sunburst 보정을 허용한다. 숨은 뒷면, 안쪽 라벨, 가벼운 주름은 수정 사유가 아니다.
- 빼입기 보정은 tucked를 기존 확신 임계 0.85 이상으로 확인했을 때만 실행한다. untucked, adequate, 불확실, 불완전 응답, 검사 실패, 검사 off는 보정 명령이 아니다. 새 임계 0.7 등은 도입하지 않는다.
- 유지 사항은 현재 컷의 색, 원단 결, 비수정 부위, 체형, 포즈, 매칭이다. 고칠 디자인의 근거는 실제 업로드 사진이다. 중간 변형본만 단독으로 전달하지 않는다.
- 보정 후 기존 상품 QC 재검사에 보정 전 이미지와 수정 목표도 같이 제공한다. 목표 해결과 보존 사항의 유지를 모두 확인해야 보정을 채택한다. 점수가 같거나 조금 높아졌다는 것만으로 채택하지 않는다. 확인 불가, 미해결, 회귀이면 보정 전의 좋은 컷과 그 컷의 점수를 같이 유지한다.
- 원래부터 중요 결함이 확인된 신규 컷은 실패 보정 뒤에 정상 합격으로 출고하지 않는다. 기존 사용자 컷은 덮어쓰지 않으며, 미해결 상태를 숨기지 않는다.
- 여러 후보 중 이전 사진을 다시 선택할 때는 그 사진의 검사 결과도 함께 가져온다. 다른 후보가 통과했다는 이유로 선택한 사진의 기장이나 포즈 결함을 지우지 않는다.
- 새 3담당 Flash 전문 QC는 off를 유지한다. 기존 공통 QC, 선택한 핏과 기장 검사, 매칭 보존, 원본 출처 검사, 캐노니컬 보조 및 매칭 전처리는 유지한다. 새 원본 분석 AI나 사용자 필수 마스크 작업은 추가하지 않는다.
- 기장이나 핏처럼 사용자가 명시한 수정은 그 축에서 허용하되 다른 부분의 임의 미용을 허용하지 않는다.
- 새 AG-01 결과는 `hem_shape`, `cuff`, `button_count_visible`, `pattern_structure`, `surface_texture`, `seam_lines` 여섯 관찰을 사진 번호와 함께 고정해 저장한다. 보이지 않으면 `unknown`이고, `none`은 보이는 적용 부위에 해당 특징이 분명히 없을 때만 쓴다. 예전 저장 계약과 해시 및 서명은 그대로 검증하며, 빠진 여섯 값은 생성 프롬프트에서만 `unknown`으로 읽는다.
- 첫 생성에는 여섯 관찰과 겹치지 않는 기존 hardFacts를 짧은 사진 근거 블록으로 넣는다. 앞면 생성에는 뒷면 사진만 뒷받침하는 디자인 사실을 넣지 않는다. `visibleSurfacePlan`은 서버가 정한 앞면 및 뒷면 라우팅 문장만 담고, 모델의 자유 디자인 설명은 받지 않는다.
- 무늬와 원단의 중대 위험은 QC 결과와 후보 비교에 남기되 재생성이나 유료 보정의 근거로 쓰지 않고 `needs_review`로 표시한다. 구조나 글자 오류와 함께 발견돼도 보정 목표에는 확인된 구조나 글자만 넣고 기존 무늬, 결, 광택은 그대로 보존한다.

일반 상품 검사 설정인 `IMAGE_QC=off`가 보정본을 확인 없이 채택해도 된다는 뜻은 아니다. 명시적으로 활성화한 편집이 실제로 이미지를 바꾼 경우에는 전후 보존 검사를 수행한다. 이 안전 검사 결과를 일반 QC 점수로 저장하지는 않아 기존 off 모드의 저장 형식은 유지한다. 기본 배포 설정은 `IMAGE_QC=enforce`이며, 보정 자체가 실행되지 않으면 이 추가 검사는 없다.

## 검증 및 권한

새 유료 이미지 호출은 0회다. 소진된 24회 한도는 그대로다. 저장된 판정 사례와 외부 모델을 모킹한 테스트로 호출 조건, 입력 순서, 보존과 원복, 모델 라우팅을 확인한다. 비마네킹 image_qc 기본 스키마는 변경하지 않는다.

이번 PR은 코드 및 연결 검증 결과다. 이전 12장 실험을 완료했거나 실제 시각 품질 문제를 전부 해결했다고 하지 않는다. 새로운 QC 프롬프트의 시각 정확도는 별도 유료 검증이 남는다. PR 업데이트는 승인됐지만 머지, 운영 배포, DB 마이그레이션은 하지 않는다.

UI의 기존 색과 기장 조절은 유지한다. 결과 부위 표시, 마스크 국소 합성, 새 체형 생성 등은 이번 구현의 필수 범위가 아니다. 사용자가 실패를 고쳐주어야 생성이 끝나는 절차를 만들지 않는다.

최신 main과 통합한 최종 로컬 검증: 서버 테스트 5,154개 통과, 78개 건너뜀. DB 쓰기가 필요한 personalization 테스트는 제외했다. 프론트 테스트와 빌드도 통과했다. 독립 코드 리뷰 지적을 수정했고, 마지막 범위 재리뷰와 설정 파일 충돌 해결 검토에서 승인됐다. 이는 코드 검증 결과이며 새 이미지의 시각 품질 검증 결과가 아니다.
