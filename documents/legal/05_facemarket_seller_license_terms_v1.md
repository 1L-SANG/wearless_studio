# FaceMarket 셀러 라이선스 이용조건 (v1 초안)

> **문서 성격**: 셀러(쇼핑몰 사업자)가 FaceMarket에 등록된 실존 모델의 착용컷을 사용할 때 적용되는 이용조건. Wearless 셀러 이용약관의 **부속 약관**으로, 이 조건이 우선한다. 셀러는 사업자이므로 「약관의 규제에 관한 법률」이 적용되며 소비자 청약철회 규정은 적용되지 않는다. 구조와 위반 배상 조항은 Mirror Mirror AI의 브랜드용 라이선스 계약(DILA: 요금 축·위반 배수·C2PA·AI 표시 의무)을 참고했고, 한국법(「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」의 표시 의무, 「부정경쟁방지법」 제2조 제1호 타목, 「성폭력처벌법」 제14조의2)에 맞췄다.
> **작성**: 2026-09-04. 변호사 검토 전 워킹 드래프트. `[대괄호]`는 회사가 채울 값. 가격 모델(건당 vs 기간 정액)이 확정되면 제5조를 교체한다.

---

## 제1조 (적용)

1. 이 조건은 [회사명](이하 "회사")가 운영하는 Wearless 및 FaceMarket에서 셀러가 실존 모델의 착용컷(이하 "착용컷")을 생성·라이선스·사용하는 모든 경우에 적용된다.
2. 셀러는 최초 이용 시 이 조건에 동의하고, 건별 라이선스가 발행될 때마다 라이선스 명세(제4조)를 확인한다.
3. 회사는 모델과의 초상 라이선스 표준계약에 따라 모델의 초상 이용을 재허락할 권한을 가진 **라이선서**로서 셀러와 계약한다. 회사는 모델의 에이전시·대리인이 아니다.

## 제2조 (정의)

| 용어 | 뜻 |
|---|---|
| 모델 | FaceMarket에 초상 라이선스 계약을 체결하고 공개를 승인한 실존 인물 |
| 착용컷 | 회사의 시스템이 모델의 디지털 DNA를 참조하여 생성한, 셀러의 상품을 착용한 AI 생성 이미지 |
| 사용 조건 | 모델이 정한 허용·제외 품목, 대가, 유효기간 |
| 건별 라이선스 | 회사가 특정 상품·특정 착용컷에 대해 셀러에게 발행하는 이용 허락. 라이선스 번호와 명세가 붙는다 |
| 승인 용도 | 이 조건 제3조가 정한, 착용컷을 쓸 수 있는 용도·매체·기간 |
| 출처 정보 | 착용컷에 삽입되는 C2PA 콘텐츠 자격증명과 AI 생성 표시 |
| 허용 변형 | 회사 시스템이 생성 과정에서 가하는 변형: 포즈, 스튜디오·무지 배경, 상품과의 합성, 의상 |

## 제3조 (이용 허락의 범위)

1. 회사는 건별 라이선스 발행 시 셀러에게 해당 착용컷을 **다음 범위 안에서** 사용·복제·게시할 수 있는 **제한적·비독점적·양도 불가·재허락 불가**의 이용권을 허락한다.
   1. 용도: **해당 상품의 온라인 상세페이지**(셀러의 자사몰과 셀러가 해당 상품을 판매하는 오픈마켓 상품 페이지)
   2. 부수 용도: 해당 상품 페이지로 연결되는 셀러의 자체 SNS 계정 게시물과 비유료 뉴스레터 [오너 확정 — 기본 포함 여부]
   3. 기간: 라이선스 명세에 적힌 유효기간(모델이 정한 1년·2년 또는 영구)
   4. 지역: 온라인 게시의 성격상 제한 없음
2. 다음은 이용 허락 범위에 **포함되지 않는다**: 유료 광고(검색·디스플레이·소셜 광고·스폰서 콘텐츠), 옥외·인쇄·매장 사이니지, 방송·영상, 다른 상품 페이지에의 재사용, 착용컷의 편집·합성·재생성, 착용컷을 AI 학습이나 다른 이미지 생성의 입력으로 사용하는 것, 제3자에게 파일을 제공하는 것.
3. 셀러가 제2항의 용도로 사용하려면 회사를 통해 별도 라이선스를 받아야 하며, 회사는 모델의 사용 조건이 허용하는 경우에만 발행한다.
4. 셀러는 착용컷에 크기 조정·크롭·상품 텍스트 오버레이 외의 변형을 가할 수 없다. 얼굴·신체를 변형하거나 배경을 바꾸는 편집은 허용 변형이 아니다.

## 제4조 (건별 라이선스 명세)

1. 회사는 건별 라이선스 발행 시 다음 항목을 담은 명세를 셀러에게 제공하고, 같은 내용을 착용컷의 출처 정보에 삽입한다.
   - 라이선스 번호, 발행 일시
   - 모델 활동명, 모델의 허용 품목
   - 이 건의 상품(셀러 상품 식별자), 품목 분류
   - 승인 용도·기간(만료일 또는 영구)
   - 대가
   - 라이선스 검증 페이지 주소
2. 시스템이 생성한 명세가 이 라이선스의 확정 내용이며, 셀러는 사전 견적·상담 내용과 다르다는 이유로 명세를 다툴 수 없다.
2-2. 회사는 모든 착용컷에 대해 **어느 동의·어느 라이선스로 그 파일이 만들어졌는지**를 권리 원장에 기록하고, 같은 내용을 출처 정보(C2PA)에 삽입한다. 셀러가 게시한 착용컷의 출처 정보가 원장과 일치하지 않으면 회사는 그 파일을 무단 사용으로 본다.
2-3. 모델이 건별 승인 방식을 선택한 경우, 셀러의 요청은 모델의 승인 후에 발행되며 승인 전에는 결제가 확정되지 않는다. 모델이 [48시간] 안에 응답하지 않으면 요청은 자동 취소되고 결제는 청구되지 않는다.
3. 셀러는 라이선스 검증 페이지에서 언제든 라이선스 상태(활성·만료·철회·취소)를 확인할 수 있고, 게시 중인 착용컷의 상태를 정기적으로 확인할 책임이 있다.

## 제5조 (대가와 결제)

1. 대가는 셀러가 모델별로 선택한 다음 방식에 따른다.
   1. **건당**: 모델이 정한 건당 가격으로 착용컷 1건의 건별 라이선스를 받는다.
   2. **월정액**: 건당 가격의 [2.5배]로 해당 모델의 착용컷을 구매일부터 [30일] 동안 제한 없이 발행·라이선스받는다. 월정액은 셀러 1곳에 한하며 양도·공유할 수 없고, 기간 중 발행된 각 착용컷에는 건별 라이선스 명세가 붙는다. 기간이 끝나면 새 발행은 중단되지만 기간 중 발행된 착용컷의 라이선스는 명세의 유효기간 동안 존속한다.
2. 결제는 회사가 지정한 결제 수단(크레딧 또는 결제대행사)으로 하며, 대가가 결제되고 라이선스가 발행된 뒤에만 착용컷을 사용할 수 있다. 결제 전 사용은 제9조의 무단 사용으로 본다.
3. 착용컷 생성 자체(크레딧)와 라이선스 대가는 구분하여 청구될 수 있다.
4. 셀러는 사업자이므로 「전자상거래 등에서의 소비자보호에 관한 법률」의 청약철회 규정이 적용되지 않는다. 이미 발행된 라이선스의 대가는 환불하지 않는다. 다만 회사의 귀책으로 착용컷을 사용할 수 없게 된 경우(제7조 제3항 제1호)에는 잔여 기간에 비례하여 환불하거나 대체 착용컷을 제공한다.

## 제6조 (셀러의 의무)

1. 셀러는 착용컷을 승인 용도 안에서만 사용한다.
2. 셀러는 다음 용도에 착용컷을 사용하지 않는다. 회사는 이를 시스템과 검수로 차단하며, 위반 시 제9조를 적용한다.
   1. 성적 연출, 신체 노출의 강조, 음란·선정적 표현
   2. 정치·종교적 지지나 반대, 선거·정치 캠페인
   3. 의료·다이어트·건강 효능의 암시
   4. 혐오·차별·폭력의 상징이나 표현
   5. 모델이 실제로 상품을 사용·추천한 것처럼 오인하게 하는 표시·광고
   6. 타인·다른 모델과의 합성, 모델이 하지 않은 언동을 한 것처럼 보이게 하는 편집
   7. 모델이 제외한 품목에의 사용
   8. 착용컷의 모델을 특정 유명인·타인과 연결 짓거나 닮은꼴로 홍보하는 표시
   9. 대한민국 법령에 위반되는 용도
   또한 셀러는 등록되지 않은 사람의 얼굴, 특정 인물을 닮은 얼굴, 여러 모델을 섞은 얼굴을 요청할 수 없다. 회사는 서명한 모델의 얼굴만 생성하며 닮은꼴·대체 옵션을 제공하지 않는다.
3. **AI 생성 표시 의무**: 셀러는 착용컷이 AI로 생성된 이미지임을 이용자가 통상의 방법으로 알 수 있도록 표시하고(「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」), 회사가 삽입한 출처 정보와 "정식 라이선스 모델" 표시를 제거·변조·가리지 않는다. 출처 정보의 삽입은 셀러의 표시 의무를 대신하지 않으며, 표시 의무의 이행 책임은 셀러에게 있다. 회사는 착용컷의 픽셀에 육안으로 보이지 않는 워터마크를 함께 삽입하며, 셀러는 이를 제거·훼손하려는 시도(재생성, 필터, 변형 도구의 사용 등)를 하지 않는다.
4. 셀러는 회사가 요청하면 착용컷의 사용 현황(게시 주소·매체)을 5영업일 이내에 제출한다.
5. 셀러는 라이선스가 만료·철회·취소되면 지체 없이(늦어도 7일 이내) 게시를 내리고 사본을 삭제한다. 영구 라이선스는 제7조 제3항의 취소 사유가 없는 한 계속 사용할 수 있다.
6. 셀러는 착용컷의 얼굴을 식별·추출하여 다른 용도로 사용하거나, 모델의 신원을 추적·접촉하는 데 사용하지 않는다.

## 제7조 (모델의 철회와 라이선스의 존속·취소)

1. 모델은 언제든지 초상 라이선스를 철회할 수 있다. 철회 시 새로운 착용컷 생성과 라이선스 발행이 중단된다.
2. **이미 발행된 건별 라이선스는 잔여 기간 동안 존속한다.** 영구 라이선스는 철회 후에도 존속한다. 회사는 라이선스 명세와 검증 페이지에 모델의 철회 사실을 표시하되, 셀러의 사용권에는 영향이 없다.
3. 다음의 경우 회사는 발행된 라이선스를 취소하고 셀러에게 삭제를 요구할 수 있다.
   1. 회사의 귀책으로 착용컷이 모델의 사용 조건 밖에서 발행된 경우 (환불 또는 대체 제공)
   2. 셀러가 제6조를 위반한 경우 (환불 없음, 제9조 적용)
   3. 착용컷이 모델의 명예·인격을 침해하는 것으로 확인되거나 법원의 판결·결정, 법령에 따라 사용이 금지된 경우 (셀러의 귀책이 없으면 잔여 기간 비례 환불)
4. 셀러는 라이선스 취소 통지를 받으면 7일 이내에 게시를 내리고 사본을 삭제하며, 회사의 요청이 있으면 삭제 확인을 제출한다.

## 제8조 (지식재산권)

1. 모델의 초상에 관한 권리는 모델에게 있고, 착용컷의 저작권은 회사에 있다. 셀러는 건별 라이선스가 정한 이용권만 가지며, 착용컷에 대해 소유권·저작인격권·독점권을 주장할 수 없다.
2. 셀러가 제공한 상품 이미지·텍스트에 관한 권리는 셀러에게 있고, 셀러는 회사가 착용컷 생성과 라이선스 관리에 필요한 범위에서 이를 사용하는 것을 허락한다.
3. 셀러는 자신이 제공한 상품 이미지가 제3자의 권리를 침해하지 않음을 보증한다.

## 제9조 (위반에 대한 배상)

1. 셀러가 라이선스 범위를 벗어나 착용컷을 사용한 경우, 셀러는 해당 건 대가를 기준으로 다음 배수를 합산한 금액을 **위약벌**로 회사에 지급한다. 이는 회사와 모델이 입을 손해의 합리적 예정이며, 회사는 이를 초과하는 손해를 별도로 청구할 수 있다.

| 위반 유형 | 배수 |
|---|---|
| 승인 용도 밖 사용(유료 광고·인쇄·영상·다른 상품 등) | 해당 건 대가의 **10배** |
| 기간 만료·취소 후 계속 사용 | **5배** |
| 제외 품목·금지 용도(제6조 제2항) 사용 | **10배** |
| 출처 정보·AI 표시 제거·변조 | **5배** |
| 얼굴·신체 변형, 합성, 재생성 | **10배** |

2. 라이선스 없이 착용컷을 취득·사용한 경우(스크린샷, 개발자 도구, 미리보기 저장, 결제 전 사용 등 방법을 불문한다) 셀러는 **이미지당 [500만원]**을 위약벌로 지급하고, 회사는 이용을 즉시 정지한다.
3. 회사는 위약벌 중 모델의 초상 침해에 해당하는 부분을 모델과의 계약에 따라 모델에게 배분한다.
4. 회사는 출처 정보와 사용 기록으로 착용컷의 발행 경로를 역추적할 수 있으며, 위반 조사에 필요한 범위에서 셀러에게 자료 제출을 요구할 수 있다.
5. 위반의 정도에 따라 회사는 ① 시정 요구(5영업일) ② 해당 상품 라이선스 취소 ③ FaceMarket 이용 정지 ④ Wearless 계정 해지의 단계로 조치하며, 긴급한 침해(성적·정치적 사용, 딥페이크)는 즉시 정지한다.

## 제10조 (진술·보증과 면책)

1. 회사는 착용컷에 사용된 모델이 실존 인물로서 초상 라이선스 계약을 체결하고 본인확인을 마쳤으며, 착용컷이 모델의 사용 조건 안에서 발행되었음을 보증한다.
2. 셀러는 사업자로서 이 조건에 동의할 권한이 있고, 착용컷을 관련 법령(표시·광고법, AI 기본법 등)에 따라 사용할 것을 보증한다.
3. 셀러가 이 조건을 위반하여 모델·제3자·회사에 손해를 입힌 경우 셀러는 이를 배상하고 회사를 면책한다.
4. 회사의 셀러에 대한 배상 책임은 고의·중과실이 있는 경우를 제외하고 해당 라이선스 대가를 상한으로 한다.

## 제11조 (우회 거래의 제한)

셀러는 FaceMarket을 통해 알게 된 모델과 이용 기간 중 및 종료 후 12개월 동안 회사의 시스템을 거치지 않고 AI 초상 거래를 하지 않는다. 실물 촬영·오프라인 모델 활동은 제한하지 않는다.

## 제12조 (개인정보)

1. 셀러는 착용컷·라이선스 명세로 알게 된 모델의 정보(활동명·신체 정보 등)를 라이선스 목적 밖으로 이용하거나 제3자에게 제공하지 않는다.
2. 회사가 셀러에게 제공하는 모델 정보의 범위와 목적은 개인정보 처리방침 제4조에 따른다.

## 제13조 (조건의 변경·해지)

1. 회사는 이 조건을 개정할 수 있으며 적용일 7일 전(셀러에게 불리한 개정은 30일 전)에 공지한다. 셀러가 적용일까지 거부 의사를 밝히지 않으면 동의한 것으로 본다. 이미 발행된 라이선스에는 발행 당시의 조건이 적용된다.
2. 셀러는 언제든 FaceMarket 이용을 중단할 수 있다. 이미 발행된 라이선스는 잔여 기간 동안 유효하며, 대가는 환불하지 않는다.

## 제14조 (준거법·관할)

이 조건은 대한민국 법에 따르며, 분쟁은 [서울중앙지방법원]을 제1심 관할 법원으로 한다. 셀러가 「약관의 규제에 관한 법률」상 보호를 받는 경우 그 법이 정한 바에 따른다.

## 부칙

이 조건은 [시행일]부터 적용한다.

## 셀러 화면에 표시하는 요지 (최초 동의 시 5줄)

1. 착용컷은 **그 상품의 상세페이지에만** 쓸 수 있어요. 광고·인쇄·영상은 별도 라이선스.
2. 모델이 정한 품목 밖, 성적·정치·종교·의료 효능·혐오 연출은 어떤 경우에도 안 돼요.
3. 이미지에 붙은 AI 생성 표시와 출처 정보를 지우면 안 돼요. AI 생성물이라는 표시는 셀러 책임이에요.
4. 모델이 라이선스를 철회해도 이미 산 건은 기간 동안 그대로 쓸 수 있어요. 영구로 산 건은 계속.
5. 범위를 벗어나면 대가의 5~10배 위약벌, 라이선스 없이 쓰면 이미지당 [500만원]이에요.

## 변호사 검토 요청 포인트

1. 제9조 위약벌 배수와 정액의 「약관규제법」 제8조(과중한 손해배상 예정) 적합성. Mirror Mirror는 "loss estimate, not penalty"로 구성했다. 한국법상 위약벌은 감액이 제한되므로 손해배상 예정으로 구성할지 판단 필요.
2. 제3조 제1항 제2호 SNS·뉴스레터 부수 용도를 기본 포함할지.
3. 제5조 가격 모델 확정 후 문구 교체.
4. 오픈마켓(네이버·쿠팡 등) 상품 페이지 게시가 오픈마켓 약관상 AI 이미지 정책과 충돌하지 않는지.
5. 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 시행령의 표시 방법 세부 기준에 맞춘 표시 문구·위치 가이드 제공.
