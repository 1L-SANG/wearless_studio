> **협찬 개정**: 2026-09-22, v1.6-draft. 시행일은 [협찬 개정 시행일]이며 검토·공지·동의 배선 전에는 이 개정안을 적용하지 않아요. 요청·배송·게시 확인은 후속 배포 대상이에요.
> **문서 성격**: 서비스 각 화면에서 정보주체(모델)와 셀러에게 받는 **모든 동의·확인의 문안 전문**. 체크박스 문안은 화면에 그대로 쓰고, 설명문은 체크박스 아래 회색 글씨로 붙인다. 각 동의는 「개인정보 보호법」 제22조(동의를 받는 방법)에 따라 **다른 동의와 구분하여 개별적으로** 받고, 사전 체크를 두지 않으며, 필수·선택을 명확히 표시한다.
> **작성**: 2026-09-04. 변호사 검토 전 워킹 드래프트. `[대괄호]`는 회사가 채울 값. 어느 화면에서 어떤 순서로 받는지는 [법적 고지·동의 체계 총괄](00_facemarket_legal_notice_map_v1.md).

## 공통 규칙 (모든 동의에 적용)

1. **개별 동의**: "전체 동의" 버튼은 편의 장치로만 두고, 눌렀을 때 각 항목의 체크가 개별적으로 표시되어야 하며 선택 항목은 전체 동의에 포함하지 않는다.
2. **사전 체크 금지**: 어떤 항목도 미리 체크된 상태로 보여 주지 않는다.
3. **전문 열람 보장**: 민감정보·계약 요지 등 전문이 긴 동의와 국외 이전 안내는 본문 전체를 화면에서 읽고 저장할 수 있게 제공한다(스크롤 강제는 보조 장치이며 접근성 문제가 있으면 두지 않는다).
4. **기록**: 동의마다 동의 일시(UTC), 문서 버전, 계정 ID, IP, 화면 식별자를 저장한다. **처리 범위가 바뀌는 개정**이면 버전을 올리고 재동의를 받으며, 오탈자·연락처 등 단순 정정은 변경 이력으로만 관리한다.
5. **철회 경로 고지**: 동의 문안 끝에 철회 방법(화면 위치 또는 이메일)을 적는다.
6. **본인 원칙**: 생체정보·초상 라이선스에 관한 동의는 본인만 할 수 있고, 소속사·가족·대리인의 대리 동의를 받지 않는다.
7. **어투**: 법적 효력을 갖는 문장(체크박스 문안)은 "~합니다/~에 동의합니다"로 쓰고, 설명문은 "~해요"로 쓴다.

**☐ 올린 사진은 내 사진이고, 최근 모습이며, 보정·필터·AI 생성이 아니고, 내가 제출할 권리(직접 촬영 또는 촬영자 허락)를 가진 사진임을 확인합니다.**

|---|---|

### B-1. 생체정보(얼굴) 수집·이용 동의 [필수·법정 — 민감정보 별도 동의]

**☐ 위 내용을 읽고 이해했으며, 나의 얼굴 정보를 아래와 같이 수집·생성·이용하는 것에 동의합니다.**

> **얼굴 정보 처리에 대한 동의 (일반 개인정보 동의와 별개입니다)**
>
> 얼굴은 「개인정보 보호법」이 민감정보로 특별히 보호하는 정보예요. 그래서 무엇을, 왜, 언제까지 처리하는지 따로 설명하고 따로 동의를 받아요. **이 동의는 본인만 할 수 있고, 소속사·가족·대리인이 대신할 수 없어요.**
>
> **1. 수집·생성하는 것**
> - 내가 올리는 등록 사진 18장: 그늘에서 9장, 햇빛에서 방향을 바꾸며 3장씩 총 9장. 얼굴·옆모습·뒷모습을 포함해요. 이 중 12장으로 학습 가중치를 만들고, 나머지는 같은 사람인지 확인하는 기준과 옆모습·뒷모습 참조로 써요.
> - 그 사진으로 만드는 **얼굴 참조 자산**: 정리한 등록 사진(각도별 참조 자산)과, **FaceMarket이 내 사진으로 직접 학습하는 나만을 위한 학습 가중치(LoRA)**. 학습은 FaceMarket이 직접 운영하는 장비에서 하고, 외부 AI 회사에 학습을 맡기거나 내 사진을 학습용으로 넘기지 않아요.
> - **얼굴 특징정보**: 사진을 숫자로 바꾼 대조용 데이터. 등록 사진끼리 같은 사람인지, 생성된 착용컷이 나와 같은 얼굴인지 확인할 때 써요. 신분증 사진을 직접 찍어 낸 경우(간편인증)에는 담당자가 확인할 때 참고하는 점수 계산에도 쓰고, 판정은 사람이 해요.
>
> **2. 이용 목적**  ① 같은 사람인지 확인 ② 얼굴 참조 자산 제작 ③ 내가 정한 사용 조건 안에서 쇼핑몰 착용컷 생성 ④ 생성 결과의 품질 검사. **이 네 가지 외에는 쓰지 않아요.** 특히 내 얼굴을 다른 사람을 만드는 AI나 범용 AI의 학습에 쓰지 않아요.
>
> **3. 사진 확인**  올린 사진은 학습 전에 FaceMarket 담당자가 품질 확인을 위해 열람하며, 열람 기록이 남아요.
>
> **4. 얼굴 참조 자산을 쓰기 시작하는 때**  만든 얼굴 참조 자산은 내가 테스트컷을 확인·승인한 뒤부터 착용컷 생성에 쓰여요.
>
> **5. 보관과 유출 방지**  원본 사진·학습 가중치·특징정보는 공개 주소가 없는 비공개 저장소에 두고, 권한이 확인된 담당자만 열 수 있어요. 학습에 쓰는 사진 사본과 학습 가중치는 FaceMarket이 운영하는 장비와 GPU 서버에만 두고, 공유 링크나 메신저로 밖에 보내지 않아요. 쇼핑몰이나 외부에 원본·가중치를 주는 일은 없어요.
>
> **6. 보유 기간**  라이선스가 유지되는 동안. 철회하거나 탈퇴하면 **30일 안에 원본 사진·특징정보·얼굴 참조 자산(학습 사본과 GPU 서버에 올린 가중치 포함)·테스트 컷을 우리 시스템과 위탁 업체 시스템에서 모두 파기**하고, 백업에서도 90일 안에 완전히 지우며, 파기가 끝나면 알려 드려요. 남는 것은 딱 세 가지예요. 이미 발행된 착용컷과 그 라이선스 명세(그 건이 끝날 때까지), 법이 보관하라고 정한 기록(정산·동의 기록), 진행 중인 분쟁의 증빙.
>
> **7. 제3자 제공**  쇼핑몰에는 **완성된 착용컷만** 전달돼요. 원본 사진·특징정보·얼굴 참조 자산은 어떤 쇼핑몰이나 외부에도 주지 않고, FaceMarket 처리 과정 밖으로 나가지 않아요.
>
> **8. 처리 위탁**  저장과 연산을 위해 클라우드 서비스(Amazon Web Services, Cloudflare)에 암호화해 맡겨요. 착용컷을 만들 때는 이미지 생성 서비스(Google, OpenAI)에 얼굴 참조 이미지를 보내요. 그 서비스는 학습에는 쓰지 않지만 **나쁜 사용을 감시하려고 최대 55일 동안 보관한 뒤 삭제**해요. 착용컷의 얼굴 부분은 FaceMarket이 GPU 서버(RunPod)를 빌려 직접 운영하는 서버에서 내 학습 가중치로 그려요. 국외 이전은 아래 B-2에서 따로 안내해요.
>
> **9. 동의하지 않을 권리**  동의하지 않을 수 있어요. 다만 이 동의 없이는 등록을 진행할 수 없어요. 동의한 뒤에도 언제든 [마이페이지의 그만두기]에서 철회할 수 있고, 철회의 효과는 위 6번과 같아요.
>
> 끝까지 읽으셨습니다.

### B-2. 얼굴 정보의 국외 이전 안내 (동의 아님, 고지)

> 얼굴 정보는 착용컷을 만들고 보관하기 위해 미국에 있는 서버와 저장소, 이미지 생성 서비스, 얼굴 부분을 그리는 GPU 서버로 전송돼요. 이 전송은 모델과 맺은 계약을 이행하기 위한 처리 위탁·보관이라 「개인정보 보호법」 제28조의8 제1항 제3호에 따라 별도 동의 없이 아래 내용을 알려 드려요. 전체 내용은 개인정보 처리방침 제6조에 있어요.

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Amazon Web Services, Inc. · Cloudflare, Inc. · Google LLC · OpenAI, L.L.C. · RunPod, Inc. (연락처는 처리방침 제6조) |
| 이전 국가 | 미국 |
| 이전 일시·방법 | 사진을 올릴 때(저장), 착용컷을 만들 때마다(생성) 암호화된 통신으로 전송 |
| 이전 항목 | 등록 사진(얼굴·옆모습·뒷모습), 얼굴 특징정보, 얼굴 참조 자산(모델별 학습 가중치 포함), 착용컷 |
| 이용 목적 | 저장, 이미지 생성의 참조 입력, 얼굴 부분 생성 |
| 보유·이용 기간 | 저장: 라이선스 유지 기간(철회 시 30일 내 파기) / 생성: 사업자가 남용 감시 목적으로 최대 55일 보관 후 삭제(학습 미사용) / 얼굴 부분 생성: 요청 처리 즉시 결과 반환, 서버 종료 시 삭제 |
| 거부 방법과 효과 | 처리방침 제6조의 연락처로 거부 의사를 밝힐 수 있어요. 다만 서버와 저장소, 생성 엔진이 국외에 있어 거부하면 등록을 진행할 수 없어요 |

체크박스를 두지 않는다. 같은 화면에 표를 보여 주고 "국외 이전 안내 전문 보기" 링크를 단다. 본인의 얼굴을 다른 사업자에게 그 사업자의 목적으로 제공하는 일(예: 해외 쇼핑몰의 라이선스 사용)이 생기면 그때 그 상대를 특정해 제28조의8 제1항 제1호의 별도 동의를 받는다. 개인정보위 의결 제2024-013-192호가 가입 단계의 포괄 동의 대신 실제 제공 시점의 동의를 요구한 선례다.

### B-3. 신분증 얼굴 대조 안내 (동의 아님, 고지)

> 모바일 신분증 확인 과정에서 받은 **얼굴 부분만** 등록 사진과 같은 사람인지 자동으로 대조하고, **대조가 끝나면 바로 메모리에서 지워요. 저장하지 않아요.** 신분증 원본 이미지와 신분증 번호도 받지 않아요. 이름은 성만 남기고 가려서 저장해요. 남는 기록은 "확인 완료(일시·결과)"뿐이에요.

off와 라이선스 철회·탈퇴 때 참여·프로필 정보 수집 철회 이력을 각각 남기고, 신규 요청 차단과 프로필 비노출을 같은 저장 작업으로 처리해요. 진행 중 요청의 배송 동의 철회는 요청별 기록으로 구분해요. 동의 증빙은 {{sponsorship_evidence_retention}} 보관하며 기본 프로필과 섞지 않아요.

협찬 처리 범위가 바뀌면 해당 항목 버전을 올리고 참여자에게 다시 동의를 받아요. 동의 전에는 새 범위 처리와 새 요청만 막으며, 비참여 기존 모델에게 협찬 동의를 필수로 요구하지 않아요. 처리방침은 확인·고지하고, 개인정보 처리 동의를 대신하지 않아요.
