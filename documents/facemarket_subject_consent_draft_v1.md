# FaceMarket 실험 참여 동의서 (초안 v1, 2026-09-05)

> 법률 검토 전 실무 초안입니다. 실제 사용 전 변호사/개인정보 담당 검토를 받으세요.
> 근거: 개인정보보호법상 얼굴 특징정보는 민감정보(별도 동의), 국외·외부 서버 처리 시 위탁·이전 고지 필요.

## 1. 수집 항목
- 얼굴이 포함된 사진 10~15장 (클로즈업·상반신·전신), 채점용 사진 4~5장
- 촬영 일시, 사용 기기 정보(해상도)는 파일 메타데이터로 함께 수집됨

## 2. 이용 목적
- AI 이미지 편집 모델로 참여자의 모습을 유지한 의류 착용 이미지를 생성하는 **기술 검증 실험**
- 생성 결과의 유사도 측정(얼굴 인식 알고리즘 SFace) 및 품질 평가

## 3. 처리 방식과 위탁
- 사진은 회사 장비(맥·윈도우 PC)와 **외부 GPU 클라우드(RunPod, 미국 사업자)**에 일시 업로드되어 처리됩니다.
- 외부 서버의 데이터는 실험 종료 즉시 삭제(파드 Terminate)합니다.
- AI 모델을 참여자 사진으로 **학습(파인튜닝)하지 않습니다.** 사진은 생성 시 참조 입력으로만 사용됩니다.
  (학습을 하게 될 경우 별도 동의를 다시 받습니다.)

## 4. 보관 및 파기
- 원본 사진과 생성 결과: 실험 종료 후 **30일 이내 파기**. 파기 시 참여자에게 통지.
- 채점 수치 등 개인 식별이 불가능한 통계는 보존 가능.

## 5. 공개 범위
- 생성 결과는 **내부 검토용**이며 외부 공개·마케팅·판매에 사용하지 않습니다.
- 보고서에 포함할 경우 얼굴을 흐림 처리하거나 참여자 서면 동의를 별도로 받습니다.

## 6. 참여자 권리
- 언제든 동의를 철회할 수 있으며, 철회 시 보유 중인 사진·결과를 즉시 파기합니다.
- 본인 사진의 처리 내역·보관 위치를 요청 시 열람할 수 있습니다.
- 동의하지 않아도 불이익이 없습니다.
