# 실제 모델 호리존컷의 목선 보정

2026년 9월 17일 사용자 요청에 따라, GPT 착용컷 생성과 Qwen 얼굴 교체가 끝난 최종 채택본의 목선을 Sunburst 이미지 편집 API로 한 번 보정한다.

## 적용 조건과 실행 순서

- 상세페이지 콘티 생성과 에디터의 새 컷 생성에 적용한다.
- 실제 모델의 UUID, REAL 아이덴티티 자산 첨부, GPT 이미지 생성 모델, `cutType=horizon`, 채택본의 `face_pass=applied`를 모두 확인한다.
- 후보 선택과 기존 Stage2 보정 뒤, 저장 전에 실행한다. 후보마다 보정하지 않는다. 같은 생성 계약의 복제 컷은 보정된 자산을 공유한다.
- 스타일링, 거울, 제품, 가상모델, 얼굴 패스 미적용, 에디터 변형, 시그니처 경로는 적용하지 않는다.

## API 계약

- `POST /v1/images/edits`, 모델 `gpt-image-2.5-sunburst`.
- 전체 Qwen 결과 한 장의 원본 바이트와 MIME을 그대로 전달한다.
- 품질 `high`, 출력 크기 `auto`, 출력 형식 PNG, 결과 한 장.
- 프롬프트는 `server/prompts/real_horizon_neck_repair_v1.txt`다. 실제 실험의 전체 사진 보존 지시에 목선과 옷깃의 일반 보정 지시를 적용한다. 기존 상품 문자와 로고는 보존한다.
- 크롭, 입력 리사이즈, 마스크, 합성, 출력 재인코딩, 추가 Qwen 얼굴 교체는 하지 않는다.
- 한 번의 HTTP 요청만 보낸다. 429, 타임아웃, 실패 응답, 비정상 출력에 자동 재시도하지 않는다.

## 채택과 저장

출력 PNG가 정상적으로 열리고, 입력과 출력 비율의 차이가 1% 이내이며, 기존 SFace 동일인 문턱 0.45 이상일 때 API 결과 바이트를 그대로 저장한다. 승인된 기준 임베딩을 우선 사용하고, 기준셋이 없으면 이미 Qwen이 교체한 입력 얼굴을 비교 기준으로 쓴다. 얼굴 미검출, 동일인 검사 불능, 이미지 파싱 실패, API 오류, 비율 변경에는 기존 Qwen 이미지를 보존한다.

목 이외 픽셀의 완전한 동일성을 보장하는 계약은 아니다. Sunburst가 사진 전체를 반환하므로 피부와 옷감의 세부 질감, 출력 해상도가 달라질 수 있다. 의류와 공간에 대한 기존 QC 기록은 Sunburst 전 채택본의 검사이며, 목선 보정 결과에는 별도의 로컬 얼굴 검사와 비율 검사만 적용한다.

자산 메타데이터의 `neck_repair`에 모델, 프롬프트 버전, 입력과 출력 해시, 적용 여부, 크기, 얼굴 점수 또는 실패 사유를 기록한다. 기존 Qwen 얼굴 패스 메타는 보존한다. 공급자 실비는 기존 이미지 사용량 원장에 `real_horizon_neck_repair` 단계로 기록한다.

REAL 출력의 비공개 캐시 정책, 저장 전 라이선스 재검증과 개인정보 권한 펜스, 기존 소비자 과금은 유지한다. 추가 Sunburst 비용은 공급자 실비에만 포함되며, 성공 컷당 소비자 차감액은 바꾸지 않는다.

## 활성화

`REAL_HORIZON_NECK_REPAIR_ENABLED=true`가 코드 기본값이다. `false`로 설정하면 목선 보정만 끄고 기존 GPT 및 Qwen 경로를 유지한다. 새 API 키나 DB 마이그레이션은 필요하지 않으며 기존 `OPENAI_API_KEY`를 사용한다.
