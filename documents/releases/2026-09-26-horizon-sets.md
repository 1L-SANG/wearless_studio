# 호리존 세트·배경 옵션 통합 발행

## 범위

- 신규 8세트 42컷: S02/S05/S08/S11/S14/S18/S20/S21.
- 리넨 수정 버전: 측면 하반신 복원·완전 후면 2컷과 기존 3컷을 같은 새 버전으로 발행.
- 선택 목록: 호리존 **19세트·92컷**. 구 리넨 세트는 새 선택 목록에서 제외하지만 저장 프로젝트의 ID·자산 조회는 유지한다.
- 호리존은 완성 `all` 예시를 직접 참고한다. pose 자산 제작이나 크롭은 하지 않는다. 중간샷 예시를 전신으로 바꾸지 않고, 풀샷은 머리부터 발끝까지 담아 발, 굽, 밑단을 자르지 않는다. 같은 예시를 다른 색상으로 반복한 낱장 컷은 두 번째 색부터 미세 포즈 변주를 받는다. 명시적 방향·샷 변경이 우선이며 기존 생성 모델·보정·재시도 흐름을 유지한다.
- `옷 색에 맞춤`은 검증한 사진색으로 벽색만 바꾸는 옵션이다. 사진색은 상품 분석 때가 아니라 콘티보드에서 마네킹컷으로 넘어갈 때, 이 옵션을 고른 경우에만 잰다. 미선택·근거 부족·지원 외 세트는 기본 배경이다.

## 자산 발행

릴리스 `space-sets-20260926-horizon-all-v1`의 새 불변 R2 prefix에 **all 47 + thumb 47 = 94개**를 올렸다. pose는 0개다. 원본은 확대/재압축하지 않았고 썸네일만 기존 도구로 파생했다. 원격 94개 전부를 내려받아 봉인 스테이징 SHA-256과 일치함을 확인했다. 구 객체는 덮어쓰거나 삭제하지 않았다.

프런트·서버 카탈로그를 동시에 갱신했다. 기존 회전형의 `setApplicableClothingTypes`를 릴리스 도구가 누락해 최초 적용은 쓰기 전에 중단됐다. 기존 런타임과 같은 유효성 검사를 추가한 뒤, 업로드된 전체 key 집합과 바이트를 다시 검증하고 원래 업로드 영수증을 복구해 적용했다. 재업로드 없음. 이는 이번 실패 복구 기록이며, 봉인·업로드 증거 없이 적용하는 새 경로를 제품에 추가하지 않았다.

## 품질·계보

Mac V2 42장의 기존 생성 영수증·프롬프트·최종 해시를 사용했다. 리넨 수정 2장의 실제 image_gen 호출 프롬프트를 해당 작업 기록에서 복구했고, 기존 3장의 원래 릴리스 계보도 보존했다. 내장 생성기의 세부 모델명이 노출되지 않은 자산은 `codex-built-in-imagegen-model-not-exposed`로 기록했다.

원본/최종 47쌍을 통합 담당과 독립 시각 검토자가 확인했다. 공간, 원본 촬영 성격, 자연스러운 자세, 광원 통합, 모델·의류 일관성의 다섯 게이트가 통과했다. AI 시각 검토이며 사람 검수나 미세 픽셀 무결점 보증은 아니다. 모델·옷 교체와 허용된 작은 자세 차이는 의도된 변경이다.

로컬 원본과 검증 영수증은 `reference/horizon-release/2026-09-26/` 및 D 드라이브 전용 스테이징에 보존했다. 연구 비교 사진과 모델 시트는 코드 저장소에 포함하지 않는다.

## UI 보존

기존 중앙 섹션과 개별컷 인스펙터 본문을 유지한다. 승인된 세트 썸네일, 고정 호버, 개별컷 보기/적용, 세트·낱장 드래그, 스크롤 보조와 세트 배경 버튼만 보강한다. 성별·의류종류 재선택이나 새 상세 화면은 추가하지 않는다.

기존 디테일 PR #410 및 후속 #417 위에 적용한다. Flare 실험을 전체 생성 모델/검수 교체로 가져오지 않는다. 소프트웨어 운영 반영은 PR 병합·배포 절차를 따른다.
