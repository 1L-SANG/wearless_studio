# 기존 검사와 부위 근거를 연결한 검사의 비교 준비

실사용 작업 모델은 gpt-6.1-sol, effort는 xhigh다. 오너는 기존 QC에 추가하는 것인지 교체하는 것인지 설명하고 해결안의 실제 개선 여부를 비교해 달라고 요청했다. 이번 범위는 로컬 실험용 어댑터이며 운영 코드와 저장 계약을 바꾸지 않는다.

## 기존 방식과 수정안

| 단계 | 기존 방식 | 수정안 |
| --- | --- | --- |
| 상품 구조 자료 | 전체 밑단 형태 한 값과 소매 이름 같은 확정 사실을 사용한다. | 앞 밑단과 뒤 밑단, 양팔 가장자리와 부착 경계, 실제 가슴 절개를 사진 부위별로 구분한다. |
| 생성 | 기존 구조 요약을 원본 사진과 함께 전달한다. | 같은 원본과 비구조 특징을 유지하면서 구조 요약 부분만 부위 관찰로 교체한다. |
| 의류 QC | 기존 Pro 모델이 원본과 생성본을 비교한다. | 같은 Pro 모델과 기존 판정 스키마, 임계와 보정 결정을 유지하고 부위 자료 및 원본·결과 확대 입력을 보강한다. |
| 보정 뒤 | 같은 기존 검사로 재판정한다. | 보정에도 같은 부위 자료를 전달하고 기존 검사에서 다시 대조한다. |

추가 QC 모델을 붙이거나 기존 검사 체계를 전부 교체하는 안이 아니다. 분석 자료의 표현과 생성·검사에 전달하는 근거를 고치는 안이다. 미래 제품 구현에서는 부위 질문을 기존 AG-01 한 번에 통합하는 것을 우선한다. 입력 자료가 늘면 토큰과 시간이 늘 수 있으므로 비용이 같다고 보장하지 않는다.

## 표본과 통제

흰 셔츠와 핑크 골지 헨리넥의 같은 원본으로 기존 조건과 수정 조건을 한 번씩 새로 생성한다. 정돈 단계는 이번에 사용하지 않는다. 앞선 생성 사진을 기존 조건의 새 결과로 재사용하지 않는다.

기존 원본 분석의 분류와 성별, 비구조 특징, 원본 사진, 베이스와 매칭, 자동 핏, Sunburst native 1K와 medium, 기존 QC 설정은 고정한다. 기존 조건은 저장된 분석 그대로다. 수정 조건은 원본에서 새로 관찰한 실험용 부위 자료로 구조 요약의 표현을 바꾼다. 사람이 앞 직선이나 소매 형태를 새 AI 관찰에 주입하지 않는다.

흰 셔츠는 앞 직선·뒤 곡선을 분리하는지, 핑크는 넓은 어깨와 팔구멍 바인딩을 별도 소매 부착선으로 잘못 만드는지 본다. 흰 셔츠의 실제 긴 소매와 솔기는 유지해야 하므로 선 일괄 삭제의 반례도 된다. 핑크의 실제 가슴 곡선 절개와 다섯 장식 단추도 보존해야 한다.

원본 해시와 EXIF를 적용한 정규화 좌표계에 부위 관찰을 연결한다. 관찰은 원본에서 확인한 형태와 사진 번호, 좌표와 설명을 갖는다. unknown을 확인된 부재로 바꾸지 않는다. 원본은 저장 계약의 기준으로 남고, 기존 서명이나 해시를 고쳐 새 관찰인 것처럼 꾸미지 않는다.

## 실험용 구현 경계

새 부위 관찰은 비교용 sidecar로 별도 저장한다. 이를 위한 Flash 관찰은 상품당 한 번씩, 총 두 번 새로 실행한다. 기존 저장 분석을 다시 작성하지 않는다. 이는 제품에서 두 분석을 상시 실행하는 구현이 아니며 추후 AG-01 통합 전에 구조 자료 전달의 효과를 확인하는 준비다.

기존 worker의 후보 생성부터 활성 QC와 필요한 수정, 최종 저장까지 실행한다. 저장과 이벤트는 로컬로 바꾸고 새 프로젝트의 시리즈 참조는 빈 목록이다. 운영 DB와 R2, AWS에 접근하지 않는다. 베이스 QC와 검수 임계, 보정 상한은 바꾸지 않는다. specialist는 운영처럼 off를 유지한다.

수정 조건의 생성 지시에는 옛 구조 관련 요약이 중복되지 않도록 실험용 presentation을 바꾼다. 원본 사진과 비구조 자료는 유지한다. 새 부위 자료를 기존 데이터 버전에 몰래 끼워 넣지 않는다. 실제 제품 반영에는 두 사실 투영 소비자와 구 계약 호환성, 모든 선언 핏 편집 경로 등의 별도 구현이 필요하다. 이번 실험만으로 그 제품 구현이 완료됐다고 하지 않는다.

수정 조건의 동일 QC 요청에 원본에서 잘라낸 최대 여섯 부위 사진과 생성본 상체 확대를 함께 넣는다. 전체 생성 사진을 함께 제공하고 프레임과 전체 품질은 전체 사진으로만 검사하도록 지정한다. 생성 부위 확대를 원본 상품 사진으로 취급하지 않는다. QC의 이미지 해시는 실제 전체 생성 사진 기준으로 유지한다. 원본과 생성의 같은 좌표나 같은 물리 배율을 가정하지 않는다.

QC 자체의 차이를 따로 확인하기 위해 각 조건의 첫 생성 사진을 다른 방식의 QC로도 검사한다. 기존 사진은 수정 QC로, 수정 사진은 기존 QC로 보는 추가 측정이 두 품목에서 네 번이다. 이 교차 검사는 같은 사진의 판단 차이를 확인하는 실험 비용이며, 제품에 QC를 두 번 붙이는 제안이 아니다. 교차 검사 결과로 자동 보정을 추가 실행하지 않는다.

## 결과 판정

부위 분석이 실제 앞뒤 차이와 팔 연결을 올바르게 관찰했는지 먼저 기록한다. 생성 사진의 앞뒤 밑단, 팔 부착선과 바인딩, 실제 절개선과 단추를 원본과 비교한다. 검사 판정과 사람 관찰이 다르면 구분해 적는다. 수정으로 실제 솔기나 절개가 사라졌다면 개선 성공으로 세지 않는다. 최종 채택 실패도 기록하고 보기 좋은 사진만 고르지 않는다.

각 조건 한 번인 첫 탐색이다. 개선 신호가 있어도 전 상품의 성공률이나 안정성을 보장하지 않는다. 생성 변동과 분석 및 QC 입력 변경이 함께 있으므로 개별 문장 하나의 효과라고 주장하지 않는다. 같은 사진의 교차 QC는 생성 변동을 제외한 검사 차이의 참고다.

## 요청 상한과 비용

최종 비교 조건은 네 개다. 현재 최초 생성 상한 1회와 필요한 untuck 1회, 최종 수정 1회로 이미지 최대 12회다. 부위 관찰 두 번과 기존 및 교차 검사, 후속 검사 전체의 텍스트 상한은 40회다. 실제 POST 전체는 최대 52회이며 응답 usage 추정이 $3에 도달하면 다음 호출을 중단한다.

같은 원본을 Google Gemini API `generativelanguage.googleapis.com`과 OpenAI 이미지 API `api.openai.com`에 전송한다. Flash는 부위 관찰, Pro preview는 QC, Sunburst는 착장과 필요한 수정에만 사용한다. NB 정돈과 다른 모델 전환은 사용하지 않는다. 모델별 원장은 실제 전송 직전에 상한을 적용한다. 기존 연구 승인 한도는 이 새 조건의 승인이 아니므로 새 비용 승인을 받기 전 실제 요청은 0회다.

현재 공식 단가와 앞선 실제 usage를 참고한 예상은 입력과 thinking, 교차 QC까지 약 $1.50이다. 실제 보정 발화와 추가 부위 사진 토큰에 따라 달라진다. $3은 응답 뒤 계산한 다음 호출 중단 기준이며 실제 청구액의 엄격한 상한이 아니다. 통신 실패와 사용량 미확인은 중단하고 상태를 기록한다. 재개할 경우에도 완료된 이미지를 다시 생성하지 않으며 최초 승인 총량 안에서 누락된 검사만 별도 기록해 이어야 한다.

## 무료 검증

무료 재현 테스트 13개가 통과했다. 앞뒤 형태 분리와 원본 바인딩, 잘못된 좌표와 미확인 구조의 확정 거절, 실제 소매 솔기 보존, 옛 구조 요약 누출 방지와 저장 계약 불변, 같은 픽셀 크롭과 원본 출처를 확인했다. 기존 QC가 한 번 호출되고 원본 사진을 유지하는지, 생성 부위가 원본으로 취급되지 않으며 QC 해시가 전체 사진을 가리키는지도 확인했다. 독립 검토가 찾은 원본·베이스 경로 매핑의 동결 누락은 실패를 재현한 뒤 부모 입력 레지스트리 해시도 동결해 수정했다.

같은 원본과 기존 분석, 설정과 실행 코드를 동결했고 무료 계획 검사가 통과했다. 제품 코드 변경이 없어 전체 서버와 프론트 검사 및 빌드는 이 준비 단계에서 재실행하지 않았다. 새 Before/After 결과는 아직 생성하지 않았다. 실제 결과와 모바일 비교 화면 검증은 실행 이후의 작업이다.

로컬 준비 폴더는 `.scratch/bg-removal-3min/view-region-ab-20261009`다. 사진과 API 인증값은 커밋하지 않는다.

## 승인 후 실행 기록

오너가 최대 52회와 두 API 사진 전송을 승인했다. 실제 30회 모두 정상 응답했으며 원본 두 종류의 Before/After와 같은 사진 교차 QC를 확인했다. 첫 어댑터가 지운 유효한 어깨 위치 정보를 복원해 같은 승인 안에서 흰 셔츠 수정 조건을 추가 확인했다. 결과와 실패 관찰을 [실행 결과](2026-10-09-region-qc-before-after-results.md)에 기록했다. 위 실행 전 0회와 준비 상태 문장은 당시 기록이다.

## 준비 당시 쉬운 설명

검사 AI를 새로 붙이는 것이 아니라, 기존 분석과 검사에 옷의 앞뒤와 부위를 구분한 자료를 준다. 두 옷으로 실제로 더 정확해지는지 보고, 같은 사진을 검사하는 판단도 좋아지는지 따로 비교한다. 아직은 무료 준비와 검증을 끝낸 상태다.
