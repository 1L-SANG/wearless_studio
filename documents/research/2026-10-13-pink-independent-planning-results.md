# 핑크 소매의 독립 기획과 반복 생성 결과

2026년 10월 13일. 주 작업의 실사용 모델은 gpt-6.1-sol, effort max다. 최신 작업 세션의 설정 기록에서 확인했다. 독립 사진 검토는 gpt-6.1-sol, xhigh다. 이 문서는 실험 근거이며 제품 요구사항이나 운영 생성 정책을 바꾸지 않는다.

## 판단

Astra와 Fable이 독립적으로 제안한 지시문은 각각 첫 결과의 긴 소매 안쪽 선을 약하게 만들었지만, 두 번째 결과에는 긴 선이 다시 보였다. 두 반복 모두 기존 지시문보다 좋아져야 한다는 사전 기준을 통과하지 못했다. 이번 지시문은 채택하지 않고 승인한 여섯 장에서 실험을 마친다. 새로운 유료 요청과 운영 변경은 없다.

소매 선을 없앤 결과는 없었다. 단추 다섯 개가 모두 보인다는 관찰도 단추의 작은 장식과 반투명도까지 정확하다는 판정으로 확대하지 않는다. 원본은 옷걸이 사진이므로 실제 착장 길이와 핏의 정답도 없다.

## 독립 기획의 이용 방식

Astra 기획은 Codex 내장 gpt-6-astra, xhigh로 진행했고 해당 세션에서 모델과 effort를 확인했다. 이번 독립 기획의 직접 Astra API 요청은 0회다. 과거 이 세션의 실험에는 직접 Astra API 요청이 있으며 이번 이용 방식과 구분한다.

Fable 기획은 Claude Code 2.1.296에서 Claude Max 구독 로그인으로 진행했다. 요청 모델은 claude-fable-5-1, effort max이며 실제 응답 모델도 동일했다. 시작 전에 authMethod=claude.ai, apiKeySource=null, subscriptionType=max를 확인했다. 자식 프로세스의 API 인증 환경값을 제거하고 구독 로그인을 강제했다. 도구와 MCP 및 브라우저는 사용하지 않았다. 실행 기록의 isUsingOverage=false와 overageEnabled=false도 확인했다.

CLI에 표시된 $2.694516은 명목 토큰 비용이며 이번 직접 API 원장에 추가하지 않았다. Claude 구독 사용량은 소모했다. 이번 구독 기획과 이후 여섯 장 비교에서 직접 Claude API 요청은 0회다. 앞선 API 실험 기록은 별도로 유지한다.

## 무엇을 비교했나

기존 실제 마네킹 생성 워커에서 저장한 핑크 C0 요청을 출발점으로 삼았다. 입력은 베이스, 원본 Front와 Back 및 Detail, 원본 Front의 상단과 중단 및 하단 crop, 매칭 바지의 여덟 장이다. 이미지를 교체하거나 가벼운 정돈본을 더하지 않았다. 앞선 형식 오류를 피하려고 세 원본의 전송 형식을 원래 RGB와 ICC를 유지한 PNG로 통일했고 모든 조건에 같은 전송 이미지를 사용했다.

| 조건 | 지시문 변경 |
| --- | --- |
| C, 기존 | 저장된 C0 지시문을 그대로 사용한다. |
| A, Astra | AG-01 원본 관찰 블록을 눈에 보이는 연속 면, 외곽 바인딩, 가슴 절개와 다섯 단추 중심으로 교체한다. 나머지 지시문은 유지한다. |
| F, Fable | 어깨 설명, AG-01 관찰 값 두 개와 대응 핵심 규칙 한 개를 함께 바꾼다. 연속된 짧은 어깨 덮임을 강조하고 별도 접합선과 좁은 능선을 억제한다. 나머지 지시문은 유지한다. |

F는 여러 문구를 함께 바꾼 묶음이며 특정 단어 하나의 인과 효과를 증명하지 않는다. 원본에서 숨은 봉제가 없다고 물리적으로 확정한 것도 아니다. 그러한 구조 설명은 검증 대상 가설로 취급한다.

세 조건을 각각 두 번, C1, A1, F1, F2, A2, C2 순서로 생성했다. 요청 모델은 gpt-image-2.5-sunburst, medium, 1536×2304, 요청당 이미지 한 장이다. 응답은 모델명을 따로 돌려주지 않아 요청 모델명과 구분한다. seed는 통제하지 않았다. 유료 QC와 보정 호출은 없으므로 전체 운영 QC 및 재생성 흐름의 최종 품질 비교라고 부르지 않는다.

실행 전 계획의 SHA-256은 `78a47dfa8219de2aa2168506c49a9bf3cf5b5f3f837a0efbff727273f22ca1e3`다. 사용자의 직접 승인에 이 계획, 최대 6회, 최대 $0.84를 연결했다. 승인 뒤 재실행 없이 한 번만 실행했다.

## 사진으로 확인한 결과

독립 검토자는 원본 세 장과 조건명이 감춰진 후보 여섯 장을 전체 사진 및 원픽셀 crop으로 확인했다. 조건 배정과 지시문, 두 모델의 계획, 이전 QC 답안을 보지 않았다. 판정 보고서의 해시를 고정한 뒤 조건을 연결했다. 주 작업자도 원본 및 후보를 직접 보고 같은 결론을 확인했다.

강도 0은 별도 내부 아치가 보이지 않음, 1은 짧거나 옅은 선이 남음, 2는 긴 경로가 읽히거나 별도 선이 뚜렷함이다. 이 값은 선의 미관 관찰이고 실제 봉제 진위를 인증하지 않는다.

| 조건 | 첫 결과 | 두 번째 결과 | 함께 확인한 변화 |
| --- | --- | --- | --- |
| 기존 C | 2, 긴 선이 보임 | 2, 긴 선이 보임 | 두 결과의 몸판 길이와 핏도 서로 다르다. |
| Astra A | 1, 옅은 상단 선이 남음 | 2, 대비가 약해도 긴 경로가 보임 | A2에는 실제 가슴 절개와 교차하는 추가 사선이 있고 소매 덮임이 작아 보인다. |
| Fable F | 1, 짧은 상단 선이 남음 | 2, 긴 선이 다시 보임 | F1은 소매 덮임이 짧아 보이고 바인딩 끝이 조금 들려 있다. |

여섯 장 모두 단추 다섯 개, 목과 팔의 실제 외곽 바인딩, 양쪽 가슴 곡선 절개, 골지와 핑크 계열은 보인다. 작은 단추 장식, 정확한 구멍 형태와 반투명도는 미확인이다. 후보의 추가 사선이나 내부 아치가 실제 봉제인지 주름인지도 확정하지 않는다. 원본에 같은 경로가 입증되지 않고 상품 구조를 다르게 읽게 할 수 있다는 관찰이다.

표본은 개발용 의류 한 벌과 조건당 두 결과다. 새로운 독립 의류, 실제 착용 정답, 뒷면 착장과 매칭 바지 전체의 보존을 평가하지 않았다. 이 결과를 일반 의류의 성공률로 계산하지 않는다.

추가 HTTP POST는 6회, 전부 HTTP 200이며 자동 재시도는 0회다. 추가 추정 합계는 $0.502978로 예상 $0.51과 예약 상한 $0.84 안이다. 별도 $15 승인 원장의 누적 추정액은 $14.591001, 전체 POST 89회와 이미지 POST 34회다. 미확인 비용, 실행 중 요청과 예약 잔액은 모두 0이다. 누적에는 앞선 기획 API 요청 및 실패 뒤 실제 usage가 나온 요청의 비용도 포함된다. 계정 청구서를 확인한 금액은 아니다. 이전 $8과 $5 승인 원장은 유지했다.

준비 단계 무료 pytest는 `test_six_image_study.py`와 `test_prompt_transform.py`의 9개가 통과했다. 생성 뒤에는 고정 파일 19개의 해시, 실제 요청 여섯 건의 같은 여덟 이미지 해시 및 MIME, 모델과 크기 및 품질, 동일 조건 두 번의 요청 본문 일치, 결과 이미지 해시와 요청별 비용을 확인했다. 블라인드 사본 여섯 장의 해시도 원본 결과와 같았다. 비교용 원픽셀 crop 12개는 저장된 crop의 RGB와 원본 영역 RGB가 정확히 같았다.

독립 검토 보고서 SHA-256은 `beef0ea142c8bbcfa21bc6ed7f1995f3b39143a48b02dde6e1d9103091fa1404`다. 로컬 결과는 `.scratch/bg-removal-3min/qc-goal-15usd-20261011/independent-planning-20261012/six-image-study-20261013/`에 보관했다. 원본과 생성 사진, 원시 응답과 인증값은 커밋하지 않는다.

제품 코드 변경은 없다. 이전 검수 구현 커밋 `8001233212123cd98d831a47cce22e3e7f6df2d5`에서 확인한 전체 서버 8,702 통과와 108 건너뜀, 프론트 3,276 통과 및 build 성공 결과를 이번 문서 변경 때문에 반복하지 않았다. 서버 건너뜀 108개의 개별 사유는 당시 보관 로그에서 확인할 수 없다. 새 실험을 서버 및 프론트 전체 테스트의 재실행으로 보고하지 않는다. 화면 변경도 없어 모바일 스크린샷 및 WebKit 검사는 이번에 수행하지 않았다.

## 반영 상태와 남은 일

기존 검수 보강은 [PR 514](https://github.com/1L-SANG/wearless_studio/pull/514)의 머지 커밋 `06805eddf57cc1f0933ea49eaa47ecb177addab8`과 성공한 [자동 배포](https://github.com/1L-SANG/wearless_studio/actions/runs/38116420496)에 반영돼 있다. 이번 독립 기획 지시문과 실험 모델을 추가로 적용하지 않았다.

[PR 482](https://github.com/1L-SANG/wearless_studio/pull/482)는 10월 13일 확인 시 열린 초안이다. 실제 셀러 경로에서 누끼 대기 및 실패 안내가 연결되는 문제와 가벼운 정돈의 안정성은 별도 미완료 항목이다. 165초는 재시도 대기의 합계이고 작업 전체의 엄격한 180초 제한은 아니다. 이번 소매 실험으로 최초 누끼 작업 전체가 끝났다고 보고하지 않는다.

앞선 소매 crop 추가 실험도 일관된 개선을 보이지 않았고 이번 구조 설명 수정도 반복 안정성을 입증하지 못했다. 가까이 촬영하는 것을 필수로 만들 근거는 없다. 실제 봉제가 흐려 판단할 수 없는 경우에는 선명한 근접 사진이 새 정보를 줄 수 있지만, 옷걸이 사진을 디지털로 자르는 것과 구분한다. 현재 근거만으로 기획 문구를 더 늘리거나 모델을 바꾸며 유료 생성을 계속하지 않는다.

## 쉬운 설명

두 모델이 각자 소매 문제를 풀 방법을 만들고 같은 사진으로 두 번씩 시험했다. 첫 장에서 선이 약해져도 다음 장에서 다시 생겨 해결로 볼 수 없었다. 거슬리는 선을 줄이는 동안 소매 모양이나 가슴 선도 달라질 수 있어 이번 방법은 채택하지 않는다. 승인한 비교를 여기서 마치고 기존 검수 보강과 이번에 확인한 한계를 유지한다.
