# 부위 사진 검수 재개와 마네킹 생성 비용

실사용 작업 모델은 gpt-6.1-sol, effort xhigh다. 10월 11일 사용자가 OpenAI와 Anthropic으로 진단 부위 사진을 전송하는 것을 허용했다. 운영 QC 교체가 낫다는지와 마네킹 비용을 질문한 것이며, 이번에 운영 설정을 변경하거나 배포하지 않았다.

## 운영 QC 추천의 범위

Sol 6.1은 이번 상품의 중요한 구조와 장식 검수 후보로 추천한다. 앞선 두 핑크 사진의 어깨 재발과 마지막 일반 단추 회귀를 잡았다. 하지만 알려진 두 의류의 개발 사례라 정상 사진 오탐률과 다른 상품, 반복 안정성은 미측정이다. 운영의 모든 검사 모델을 동시에 바꾸겠다는 추천이 아니다.

마네킹 상품 동일성 검사와 상세페이지 최종 호리존의 17항목 검사는 서로 다른 호출과 계약이다. 지금의 Sol 비용과 성능은 후자의 강화 검사에서 측정했다. 실제 마네킹 상품 QC 스키마에서 같은 정확도와 지연, 보정 및 보존 판단을 검증한 뒤 전용 경로로 적용해야 한다. Gemini 우선 순서와 공용 text 모델 설정만 바꾸면 분석, 핏, 베이스 검사까지 함께 영향을 받거나 Sol이 실제 호출되지 않을 수 있다.

기존 공유 vision 호출은 analysis_timeout_seconds를 사용하며 코드 기본은 30초다. 이번 Sol high 전신 검수는 71~100초였고 연구 요청은 별도 긴 상한을 사용했다. 운영 전환에는 검수 전용 모델과 시간 예산, 응답 완결과 폴백의 추가 비용을 함께 다뤄야 한다. Sol은 Astra보다 저렴한 후보지만 현재 Gemini 검사보다 항상 저렴하다는 뜻은 아니다.

## 승인된 부위 사진 검수

원본 상품 사진과 전체 생성 사진은 그대로 두고, 같은 생성 사진에서 native 픽셀을 자른 부위를 추가했다. 새로운 그림, 선명화나 보간은 없다. 사진 역할을 지정해 전체 구도와 인체는 전체 후보에서, 작은 디테일은 같은 후보의 부위에서 읽게 했다. crop을 상품의 새 원본으로 사용하지 않는다.

계획은 Sol high 검수 최대 두 번, 핑크와 흰 셔츠 각 한 번이다. 새 이미지 생성과 운영 접근은 없고 기존 $8 안에서만 실행한다. 먼저 누적 확인 추정 $6.66747175와 과거 미확인 예약 $1.05를 포함했다. 남은 공간은 $0.28252825여서 세 모델의 추가 비교를 약속하지 않았다. 각 $0.18 예약이 가능할 때만 호출하며 두 번째는 첫 응답 비용을 확인한 뒤 결정한다. 원래 실행 코드와 계획, 중단 기록을 덮어쓰지 않고 별도 재개 계획과 해시를 남겼다.

핑크의 전체 사진만 본 Sol은 다섯 단추를 확인하고 장식은 미확인으로 남겼다. 같은 전체 사진과 부위를 같이 준 재개 요청은 원본 입체 장식을 읽고 후보의 평범한 단추에서 장식 누락을 FAIL했다. 개수와 원형 바탕은 PASS, 광학적 인상과 구멍은 미확인으로 유지했다. 앞선 약해진 어깨는 PASS였다. 실제 추가 비용은 $0.068906, API 시간은 약 87.9초다.

흰 셔츠도 원본 Front의 짧은 앞단과 더 긴 Rear 층을 분리했다. 하지만 원본 구김과 후보 착용 드레이프 때문에 실제 재단의 직선 여부를 확신할 수 없어 앞단을 미확인으로 유지했다. 명시 포즈의 kinematics가 실험 계약에 없다는 별도 구도 보류도 기록됐다. 전체 경로는 HOLD_STAGE1이며 부위 확대만으로 밑단 검수가 해결됐다는 결론은 아니다. 비용은 $0.082376, 약 103.8초다.

재개 POST 두 번 모두 200, gpt-6.1-sol 반환 모델과 정상 종료, 파싱 및 usage를 확인했다. 추가 $0.151282를 합쳐 누적 확인 추정은 $6.81875375, 과거 보류 $1.05 포함 $7.86875375다. 새 미확인 비용은 없다. 총 연구의 POST는 24회로 검수 20회와 생성 4회이며 이번 새 생성은 없다. 남은 예약 공간은 약 $0.13이고 확인 추정 $6.80 중단선도 넘어 새 호출을 더 진행하지 않는다. 최초 두 번 계획 모두 기존 $8 안에서 실행했다.

무료 재현 테스트는 13 통과, 실패 0이다. 원본 crop 픽셀과 참조 권한, 필수 하위 검사와 순서, 비용 미확인 및 누적 예산 방어를 확인했다. 이번에 앱 코드나 화면을 바꾸지 않아 서버 전체 테스트, 프론트 전체 테스트, 빌드를 재실행하지 않았다. DB 접속이 필요한 테스트도 이번에는 없다. 운영 QC 교체, 실제 저장과 다운로드 및 정상 사진 오탐 평가는 하지 않았다.

이는 부위 자료를 함께 보여 주는 조건의 개선 신호다. 동일 자료를 여러 번 비교한 안정성 검증이나 crop만의 인과 확정은 아니다. 추가 사진과 역할 안내가 함께 바뀌었고 정상 장식형 착용 사진에 대한 대조군은 없다. 새 QC가 실제 보정을 자동 실행하거나 정확한 장식 사진을 생성했다고 말하지 않는다.

## 마네킹컷과 최종 착장 사진의 비용 구분

10월 9일 남성 베이스 교체 범위에서 승인받아 저장한 task definition과 현재 작업 코드는 마네킹 선택용 컷을 Sunburst, native 1K, medium으로 생성한다. 현재 운영의 새 실효 설정을 조회하지 않았다. 최근 비교의 최종 사람 착장 호리존은 별도로 Sunburst 2K, medium이었다. 해상도와 입력 역할, 참조 수가 달라 두 비용을 같은 마네킹 생성 단가라고 합치지 않는다.

아래는 [기존 전체 마네킹 비교](2026-10-09-full-workflow-tidy-comparison-results.md)의 원본 방식 실제 요청과 usage다. 검수는 저장된 당시 설정의 Gemini 3.1 Pro였다. 원본 방식은 정돈 전처리를 넣지 않는다.

| 원본 상품 | Sunburst 1K 이미지 생성 | 기존 Gemini 검사 합계 | 생성 및 검사 구간 합계 |
| --- | ---: | ---: | ---: |
| 흰 셔츠 | $0.103291 | $0.031568, 3회 | $0.134859 |

각 원본 후보에서 관찰한 생성 및 검사 구간 비용이며 저장 성공과 상품 보존 합격을 뜻하지 않는다. 해당 결과들은 검수 필요 상태였다. 상품 분석, 새 매칭 의류 전처리, 정돈, 큐와 서버, R2 비용은 이 표 밖이다. 앞선 다른 실행의 시간 초과와 미확인 비용은 총 연구 예산의 보류로 별도 유지하며 위 완료 요청의 합계에 추측해서 넣지 않는다.

### Sol로 상품 검사 한 번을 교체하는 예상

기존 마네킹의 주상품 QC는 흰 셔츠 $0.019314, 핑크 $0.021562, 검정 청바지 $0.018994였고 나머지 핏과 베이스 등 검사 비용은 따로 남는다. 그 상품 검사 한 번만 최근 강화 Sol 검수의 관찰 범위 $0.060382~$0.082376로 바꿔 계산하면 다음과 같다.

| 상품 | 기존 합계에서 주상품 검사만 Sol로 바꾼 산술 예상 |
| --- | ---: |
| 흰 셔츠 | $0.175927~$0.197921 |
| 핑크 헨리넥 | $0.149470~$0.171464 |
| 검정 청바지 | $0.180481~$0.202475 |

따라서 첫 마네킹 한 장은 약 $0.15~$0.20을 예산으로 볼 수 있다. 이것은 실제 Sol 마네킹 워커 전환의 실측이 아니다. 두 QC의 프롬프트와 스키마가 달라 정확한 치환 단가가 보장되지 않는다. 기존 검사에 Sol 한 번을 추가하는 안이면 약 $0.17~$0.22가 된다. 모든 QC를 Sol로 바꾸면 호출 수만큼 더 들 수 있으므로 한 회 비용을 전체 검사 비용처럼 설명하지 않는다.

한 번 더 이미지 수정과 검사를 해야 하면 그 호출 비용이 추가된다. 생성과 Sol 검사 한 쌍을 두 번 사는 단순 예산은 약 $0.30~$0.40이지만, 실제 보정 입력 수와 검사 경로에 따라 달라진다. 기본 최초 생성 상한 1회가 모든 후속 편집 비용을 0으로 만든다는 뜻도 아니다.

최근 [2K 최종 착장 비교](2026-10-10-affordable-qc-and-image-repair.md)의 이미지 네 장은 생성 $0.050559~$0.068356, Sol 전신 검사 한 회는 당시 $0.060382~$0.077898이었다. 추가 부위 검수까지 포함하면 최대 $0.082376다. 생성 한 번과 검사 한 번을 합치면 약 $0.11~$0.15다. 입력 수와 내용이 다른 실험이라 2K가 1K보다 저렴하다는 뜻은 아니다. 상품 정돈을 붙이면 정돈 생성과 사전 검수 비용이 다시 추가된다.

[OpenAI 가격표](https://developers.openai.com/api/docs/pricing)의 Sunburst는 텍스트 입력 백만 토큰당 $5, 이미지 입력 $8, 이미지 출력 $30이고 Sol은 짧은 컨텍스트 입력 $2, 출력 $10이다. 공개 단가를 기록된 usage에 적용한 추정이며 실제 청구서와 운영 전체 평균은 확인하지 않았다.

## 쉬운 설명

솔은 옷 사진을 그리는 모델이 아니라 잘못 그린 부분을 검사하는 모델이다. 이번에는 작은 단추를 같이 보여 주니 잘못된 장식을 잡았다. 실제 마네킹 한 장의 생성과 검사는 기존 약 $0.11~$0.14였고, 상품 검사 한 번을 솔로 바꾸면 약 $0.15~$0.20으로 예상한다. 품질 때문에 교체를 추천하는 것이며 현재 Gemini보다 무조건 비용이 줄어드는 선택은 아니다.
