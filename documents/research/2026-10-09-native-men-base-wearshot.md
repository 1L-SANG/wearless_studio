# 추천 남성 베이스로 만든 실제 착장 미리보기

실사용 작업 모델은 gpt-6.1-sol, effort는 xhigh다. 사용자가 추천한 체형을 기존 마네킹 흐름에 넣었을 때의 모습을 요청하고, 추가 유료 생성 최대 한 번을 승인했다.

## 실행 조건

내장 Codex로 만든 남성 베이스 후보를 작업 브랜치의 기존 마네킹 최초 생성 요청에 넣었다. 생성 모델은 `gpt-image-2.5-sunburst`, quality는 medium, 출력은 PNG `1024x1536` 한 장이다. 베이스를 만든 내장 도구와 옷을 입히는 기존 생성 모델을 구분한다.

앞선 네이비 체크셔츠 원본 조건과 같은 지시문, 같은 Front와 Back, Detail, 같은 매칭 바지를 썼다. 이 네 의류 참고 사진의 해시와 지시문 바이트가 같음을 확인했다. 남성 베이스 입력 한 장만 바꿨다. 기존 베이스의 착장 결과는 2026-10-08 결과를 재사용했다. 새 베이스 원본 해시는 `fd984e5e2b798831098a07feb1d1feae47968ba8793d04ed51f41b2267f691f2`다.

이 비교는 기존 생성 모델과 지시를 사용한 첫 생성 미리보기다. 전체 worker, AG-01 계약과 Front crop, 유료 QC와 자동 보정은 포함하지 않았다. 배포 실효 모델과 운영 베이스 동일성을 조회하지 않았다. 문서의 Flare 2K 설명과 작업 브랜치의 Sunburst 1K 설정 차이는 앞선 연구에서 기록했으며, 이번에도 코드 설정으로 고정했다. 운영 화면의 완전한 흐름을 실행한 결과로 설명하지 않는다.

## 실제 반환과 관찰

승인한 HTTP POST 한 번만 실행했다. HTTP 200과 PNG 한 장을 확인했다. 응답 시간은 20.553초, 사용량 추정은 $0.061752다. 원시 응답과 usage를 로컬에 보관했다. 청구서에서 확인한 금액은 아니다. 직접 `images/edits`에는 캐시 입력 할인을 적용하지 않았다. OpenAI 응답에 모델명 필드가 없으므로 요청 모델 확인과 서버 모델 버전 확인을 구분한다.

직접 검수와 독립 검수에서 새 컷은 가슴과 어깨 부풀림이 덜하고 셔츠 몸통이 조금 더 곧게 떨어지는 인상이다. 머리와 팔, 손발의 큰 배치, 전신 프레임은 대체로 유지됐다. 기본적인 모델 체형의 첫 착장 후보로 내장 베이스 추천을 유지한다.

상품 보존 전체를 통과했다고 판단하지는 않는다. 새 셔츠 하단 플래킷은 단추 간격 한 칸이 비어 보인다. 칼라 주변의 작은 단추와 반사가 혼동돼 정확한 전체 단추 수는 보류지만, 단추 위치까지 보존 통과라고 쓸 수 없다. 원본의 미세 체크 선 순서도 정확한 재현은 보류다.

바지는 새 컷에서 종아리 여유와 밑단 구김이 늘고 기장이 더 길게 읽힌다. 매칭 원본의 국소 노란 워싱도 약해졌다. 결과가 깔끔해 보이는 것만으로 같은 바지를 더 잘 재현했다고 판단하지 않는다. 한 번의 생성이고 기존 비교 사진은 앞선 시점의 결과라, 모든 차이를 베이스 체형의 효과로 단정하지 않는다.

## 검증과 적용 상태

실행 전 요청 한 번 제한과 입력 변조 거절, 승인 전 및 재실행 시 키 접근 차단의 무료 재현 검사 두 개가 통과했다. 실행 후 HTTP 한 번, 정상 응답과 이미지 크기, 원본 해시와 지시 유지, usage 기록을 확인했다. API 정상 반환과 상품 보존 판정은 별개다.

제품 코드와 운영 설정은 바꾸지 않았다. 새 베이스를 운영에 등록하거나 연결하지 않았고 기존 생성컷도 교체하지 않았다. 실제 운영 교체에는 별도 승인과 상품 보존 검증이 필요하다. 같은 제품 코드의 앞선 전체 검사 결과는 서버 7698 통과와 104 조건부 건너뜀, 프론트 2806 통과, 빌드 통과다. 이번 연구 때문에 다시 실행하지 않았다. 104개는 선택 의존성과 가중치, 샘플 및 시험 환경 때문에 건너뛰었다.

새 비교 HTML의 모바일 320, 360, 375, 390, 414px과 WebKit 화면 검사는 브라우저 연결 및 로컬 파일 접근 제한으로 수행하지 못했다. 이미지는 직접 열어 확인했다. 이것을 브라우저 검사라고 설명하지 않는다.

## 쉬운 설명

추천한 남성 몸에 기존 방식으로 같은 체크셔츠와 바지를 실제로 입혀 봤다. 상체가 덜 부풀고 차분하게 떨어지는 인상이라 체형 후보 추천은 유지한다. 하지만 단추와 바지 핏에도 차이가 생겨, 보기 좋은 예시 한 장을 운영 품질 통과로 취급하지 않는다. 운영 베이스는 아직 바꾸지 않았다.
