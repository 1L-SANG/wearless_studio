# 에디터 배경 투명도·빈 프레임·MVP 라이브러리 조사

- 작성일: 2026-08-12
- 범위: Wearless Studio 상세페이지 에디터
- 결론 수준: 공식 편집기 문서에서 반복되는 기능을 근거로 한 제품 제안

## 1. 결론

가장 무난하고 반복 사용 가능성이 높은 첫 구성은 **빈 사진 프레임 6종 + 정보 전달 오브젝트 5종**이다. 장식 스티커를 많이 모으기보다, 상세페이지에서 계속 반복되는 `사진 배치 → 크롭 → 설명 강조 → 구분` 작업을 먼저 짧게 만드는 것이 좋다.

투명도는 특정 오브젝트만의 기능이 아니라 선택한 대상에 공통으로 붙이는 속성으로 제공한다. 다만 **블록 전체에 CSS `opacity`를 주면 사진과 글자까지 함께 흐려지므로**, 배경색·배경 이미지 오버레이·개별 요소의 투명도를 서로 분리해야 한다.

공개된 실제 사용률 데이터는 확인하지 못했다. 아래 우선순위는 Canva, Adobe Express, 미리캔버스, 망고보드, 카페24 에디봇의 공식 기능 문서에 반복 등장하는 기능과 Wearless의 의류 상세페이지 작업을 결합한 추정이다.

## 2. 공식 사례에서 반복되는 패턴

### 투명도

- Canva는 선택한 배경·텍스트·요소·사진 등에 Transparency를 적용하고 슬라이더로 값을 조절하게 한다. [Canva 투명도 도움말](https://www.canva.com/help/transparency/)
- Adobe Express도 사진을 선택한 뒤 속성 패널에서 opacity를 슬라이더로 조절한다. [Adobe Express 사진 효과](https://www.adobe.com/learn/express/web/photo-effects-express)
- 망고보드는 선택 요소의 `불투명도`를 슬라이더와 숫자로 조절한다. [망고보드 제작 가이드](https://www.mangoboard.net/document/%EB%A7%9D%EA%B3%A0%EB%B3%B4%EB%93%9C_%EC%A0%9C%EC%9E%91%EA%B0%80%EC%9D%B4%EB%93%9C.pdf)
- 카페24 에디봇도 프레임 이미지의 크기·회전·투명도·비율을 같은 편집 문맥에서 제공한다. [카페24 에디봇 프레임 가이드](https://support.cafe24.com/hc/ko/articles/8461844989849)

따라서 Wearless도 사용자가 대상을 선택하면 같은 위치에서 `불투명도 0~100`을 조절하는 방식이 학습 비용이 가장 낮다.

### 빈 프레임과 이미지 채우기

- Canva는 사진이 준비되기 전에 프레임으로 레이아웃을 먼저 만들고 나중에 사진을 넣을 수 있다고 설명한다. 사진은 프레임에 맞춰 자동 리사이즈·크롭된다. [Canva 사진 프레임](https://www.canva.com/features/photo-frame-effect/)
- Canva Grid는 사진을 칸에 끌어 넣으면 자동으로 맞추고, Crop에서 다시 확대·축소·위치를 조절한다. [Canva 디자인 그리드](https://www.canva.com/features/design-grid/)
- 미리캔버스도 프레임에 사진을 끌어 넣고 더블클릭해 위치와 확대 비율을 바꾸는 흐름을 제공한다. [미리캔버스 사진·프레임 도움말](https://help.miricanvas.com/hc/ko/articles/360021771772)
- 망고보드는 프레임에 다른 사진을 넣어 교체하고 더블클릭 후 확대·축소·이동할 수 있게 한다. [망고보드 프레임 가이드](https://www.mangoboard.net/guide/169)
- 카페24 에디봇은 1·2·3단 기본 프레임, 디자인 프레임, 스티커, 구분선, 상품 정보 항목을 제공한다. [카페24 에디봇](https://support.cafe24.com/hc/ko/articles/25214194458777)

공통 동작은 다음과 같다.

1. 프레임만 먼저 배치할 수 있다.
2. 업로드·보유 이미지 모두 끌어 넣을 수 있다.
3. 사진을 놓으면 `cover` 방식으로 자동 맞춤한다.
4. 채워진 프레임에 새 사진을 놓으면 교체한다.
5. 더블클릭 또는 `자르기`로 프레임 안 사진만 이동·확대한다.
6. `교체 / 자르기 / 초기화 / 빼내기`를 제공한다.

## 3. 권장 투명도 UX

### 공통 컨트롤

- 표시명: `불투명도`
- 범위: `0~100`, 내부 저장은 기존처럼 `0~1`
- 기본값: `100`
- UI: 슬라이더 + 직접 입력 가능한 숫자 + `%`
- 키보드: 방향키 1단위, Shift+방향키 10단위
- 초기화: 더블클릭 또는 초기화 버튼으로 `100`
- 적용 대상: 이미지, 도형, 선, 텍스트, 배경색, 배경 오버레이

빠른 프리셋을 넣는다면 `100 / 80 / 60 / 40 / 20` 정도만 제공한다. 처음부터 별도의 복잡한 blending mode는 필요 없다.

### 배경은 세 종류로 분리

| 대상 | 저장값 | 의미 |
|---|---|---|
| 개별 이미지·도형 | `element.opacity` | 대상 자체가 흐려짐 |
| 블록 배경색 | `block.bgOpacity` | 자식 요소는 유지하고 배경색만 흐려짐 |
| 배경 사진 위 가독성 막 | `overlayColor`, `overlayOpacity` | 사진은 유지하고 검정·흰색 막만 조절 |

구현할 때 `CanvasBlock` 컨테이너에 `opacity`를 적용하면 안 된다. `block.bg` 색상만 alpha가 포함된 색으로 렌더하거나 배경 전용 레이어를 하나 둬야 한다.

```js
{
  bg: '#0e0d14',
  bgOpacity: 0.92,
  backgroundSrc: null,
  overlayColor: '#000000',
  overlayOpacity: 0.32
}
```

위 기본값은 강제 규칙이 아니라 시작점이다.

- 단색 카드·말풍선: `92~100%`
- 사진 위 검정·흰색 오버레이: `25~40%`
- 장식용 배경 사진 자체: `15~30%`

텍스트가 올라간 경우에는 투명도보다 가독성이 우선이다. WCAG 2.2 기준으로 일반 텍스트는 배경과 최소 `4.5:1`, 큰 텍스트는 `3:1` 대비가 필요하므로, 값 변경 시 대비가 낮으면 경고만 보여주고 사용자의 조절 자체를 막지는 않는 방식이 적절하다. [W3C WCAG 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## 4. 가장 먼저 제공할 프레임 6종

| 우선 | 프레임 | 용도 | 현재 상태 |
|---|---|---|---|
| 1 | 1컷 풀폭 | 메인컷, 착용컷, 디테일컷 | 신규 |
| 2 | 2분할 동일 비율 | 앞·뒤, 모델·제품 비교 | 있음 |
| 3 | 3분할 동일 비율 | 디테일 3장, 컬러 3종 | 있음 |
| 4 | 2×2 그리드 | 디테일·컬러를 한 화면에 정리 | 신규 |
| 5 | 큰 사진 + 작은 사진 2장 | 메인 이미지와 세부컷 동시 강조 | 신규 |
| 6 | 컬러 비교 3칸 | 의류 색상 비교 | 있음 |

공통 프레임 속성:

- 프레임 간격(gap)
- 둥근 모서리(radius)
- 프레임 배경색과 불투명도
- 슬롯별 이미지 교체·자르기·초기화·빼내기
- 비어 있는 슬롯의 명확한 drop 안내

원형 프레임은 유용하지만 의류 상세페이지의 기본 사진 배치보다 범용성이 낮아 2차로 둔다. 기존 `Before / After` 프레임도 삭제할 필요는 없지만 첫 화면의 추천 항목에서는 뒤로 내리는 편이 좋다.

## 5. 가장 먼저 제공할 오브젝트 5종

| 우선 | 오브젝트 | 구성 |
|---|---|---|
| 1 | 반투명 텍스트 배경 박스 | 사각형 + 텍스트, 배경 불투명도 92% 기본 |
| 2 | Q&A 말풍선 세트 | 질문 말풍선 + 답변 말풍선 + 텍스트 |
| 3 | 구분선 | 실선·점선, 색·두께·불투명도 |
| 4 | 화살표 콜아웃 | 좌·우 화살표, 색·두께·회전 |
| 5 | 라벨 배지 | `POINT / CHECK / NEW / BEST`, 문구 수정 가능 |

별·하트·육각형 같은 일반 도형은 현재처럼 `기본 도형` 아래에 유지하되 추천 영역을 차지하게 하지 않는다. 스티커 수백 개보다 이 다섯 종류가 상세페이지의 정보 전달 작업을 더 직접 줄여준다.

## 6. 빈 프레임의 권장 상호작용

### 비어 있을 때

- 회색 또는 체크 패턴의 슬롯 윤곽
- 중앙 문구: `사진을 끌어 놓거나 클릭하세요`
- 클릭 시 `의류함 / 업로드` 선택 화면
- drag-over 시 슬롯 전체를 브랜드 포인트 색으로 강조

### 사진이 들어 있을 때

- 새 사진 drop: 즉시 교체하되 undo 가능
- 더블클릭: inner crop 모드
- 툴바: `교체 / 자르기 / 초기화 / 빼내기`
- `빼내기`: 프레임 스타일은 유지하고 다시 빈 슬롯으로 복귀
- 프레임 크기 변경: 사진은 현재 초점 위치를 최대한 유지하면서 cover 재계산

### 기본값

- fit: `cover`
- 초점: 중앙
- gap: 12~16px 상당
- radius: 0 또는 12px 두 가지 빠른 선택
- 프레임 배경: `#f5f5f5`, 불투명도 100%

## 7. 현재 코드와의 차이

Wearless에는 이미 핵심 기반이 있다.

- `Element.opacity` 계약과 이미지·도형·텍스트 불투명도 UI가 있다.
- `src: null` 이미지 element를 빈 슬롯으로 렌더하고 의류함 이미지로 채우는 흐름이 있다.
- 프레임 안 이미지의 crop·이동·확대 기능이 있다.
- 2분할, 3컷, Before/After, 컬러 비교 프레임이 있다.

따라서 새 엔진보다 다음 보강이 핵심이다.

1. `block.bgOpacity`와 사진 배경용 `overlayOpacity`를 추가한다.
2. 1컷, 2×2, 큰 사진+작은 사진 2장 프레임 정의를 추가한다.
3. 모든 빈 슬롯에 drop·replace·remove 상태를 일관되게 적용한다.
4. 반투명 박스, Q&A 말풍선, 라벨 배지를 묶음 오브젝트로 추가한다.
5. 프레임과 오브젝트를 `추천 / 프레임 / 정보 전달 / 기본 도형`으로 재분류한다.

## 8. 출시 순서

### 1차

- 불투명도 공통 컨트롤 정리
- 블록 배경 불투명도
- 1컷·2분할·3분할·2×2·큰사진+2장·컬러비교 프레임
- 빈 슬롯 drop/replace/crop/reset/remove
- 반투명 텍스트 박스, 구분선, 화살표

### 1.5차

- Q&A 말풍선 세트
- `POINT / CHECK / NEW / BEST` 배지
- FAQ 카드형·대화형 구조화 블록

### 사용 데이터 확인 후

- 원형·폴라로이드 등 디자인 프레임
- 최근 사용·즐겨찾기
- 프레임 잠금·삽입 방지
- 스티커 팩 확장

측정 이벤트는 최소한 `library_item_added`, `frame_image_filled`, `frame_image_replaced`, `opacity_changed`, `library_search_no_result`를 남긴다. 실제 사용률이 쌓인 뒤 추천 순서와 항목 수를 조정한다.

## 9. 최종 권고

첫 릴리스의 핵심은 “오브젝트를 많이 제공하는 것”이 아니라 다음 한 문장으로 정리된다.

> 사용자는 빈 프레임을 먼저 놓고 사진을 끌어 넣은 뒤, 자동 맞춤된 사진을 더블클릭해 자르고, 반투명 박스·말풍선·구분선으로 설명을 완성한다.

이 흐름은 현재 Wearless의 데이터 모델과 편집 기능을 대부분 재사용할 수 있고, 상세페이지 제작에서 가장 반복되는 작업을 직접 줄인다.
