# 가벼운 정돈 입력의 표기와 남성 베이스 후보 준비

실사용 작업 모델은 gpt-6.1-sol, effort는 xhigh다. 입력 사진과 최종 생성 해상도의 혼동을 풀고 새로운 남성 베이스 후보를 준비하는 연구 기록이다. 제품 요구사항을 바꾸는 문서가 아니다.

## 표기에서 생긴 혼동

2026-10-08 비교 HTML은 제품 사진에는 “2.1 가벼운 정돈 2K”, 마네킹에는 “정돈 2K로 생성”을 썼다. 같은 입력을 다른 방식처럼 읽게 만드는 잘못된 축약이었다.

실제 저장된 요청에서 갈색 면바지, 네이비 체크셔츠, 그린 니트의 마네킹 Front가 각 의류의 `gentle-2K.jpg` 파일이며 해시도 일치함을 다시 확인했다. 세 의류 모두 같은 **가벼운 정돈 2K 제품 사진을 그대로 넣어서** 마네킹을 생성했다. 별도의 두 번째 정돈이나 강한 정돈은 없었다.

2K는 입력 제품 사진의 해상도다. 마네킹은 이 실험에서 Sunburst의 native `1024x1536`, 즉 1K로 출력했다. 마네킹 자체를 “정돈 2K”라는 방식으로 만든 것이 아니다. “가벼운 정돈 2K로 마네킹을 만들면 어떤가”는 이미 이 조건에서 시험했다.

HTML의 표기는 원본 사진 입력, 가벼운 정돈본 1K 입력, 가벼운 정돈본 2K 입력, 원본과 가벼운 정돈본 입력으로 고쳤다. 기존 1K라는 표현도 이전 실험의 가벼운 정돈 1K로 바꾸고 운영의 기존 전처리라는 뜻이 아니라고 표시했다. 유료 입력과 결과, 품질 등급은 바꾸지 않았다.

사용자는 제품컷에서는 가벼운 정돈이 가장 낫고, 주름 부분 지정은 옷이 달라져 보인다고 판단했다. 이 선호를 남긴다. 기존 검수에서 확인한 라벨과 단추 등의 보존 문제도 유지한다. 제품컷의 배경과 배치 가독성 개선을 모든 상품 보존 성공이나 마네킹의 추가 개선으로 확대하지 않는다.

## 남성 베이스에서 확인한 것

실험에 사용한 로컬 남성 베이스는 가슴, 어깨와 팔의 볼륨이 뚜렷하다. SHA256은 `ccc90f1bf940d9a394c37a0c7e3c4a7a25148c7f4009e261d98c944ddcc3d187`이며 원본은 `server/ab_out/provider_material_body_20260804/inputs/base-men-2K.png`다. 현재 운영 R2 베이스와 같은지는 조회하지 않아 미확인이다.

현행 작업 브랜치 코드는 선택된 성별에 따라 설정된 남성 베이스 asset id를 읽고, 그 베이스의 몸과 포즈를 유지하며 옷을 입힌다. 체형을 바꾸려면 새 로컬 베이스 후보를 먼저 비교하고 선택한 에셋을 연결하는 과정이 필요하다. 운영 asset 조회와 업로드, 설정 변경은 이번 준비에서 하지 않았다.

사용자가 원하는 방향은 근육 강조를 줄인 기본적이고 슬림한 모델 체형이다. 후보는 두 장으로 준비했다. 첫 후보는 어깨 폭과 가슴, 허리를 중립적으로 맞춘 기본 모델 체형이다. 두 번째는 가슴과 팔 부피를 조금 더 줄인 슬림한 모델 체형이다. 두 후보 모두 같은 머리 방향과 서 있는 포즈, 손가락과 발 위치, 카메라와 배경을 고정한다. 옷이 자연스럽게 걸릴 몸의 입체감은 남긴다.

## 추가 비용 경계

로컬 `.scratch/bg-removal-3min/men-base-20261009`에 원본 사본, 두 요청 지시와 입력 해시를 준비했다. 아직 새 이미지 생성은 0회다. Nano Banana 2.1로 2K, 세로 2:3, thinking medium의 편집 요청 최대 2회를 제안한다. 이번 단계는 베이스 후보만 만들며 새 착장 생성과 유료 QC는 포함하지 않는다. 실패 재시도와 모델 전환은 없다.

[Google 공식 이미지 편집 문서](https://ai.google.dev/gemini-api/docs/image-generation)는 원본 사진과 변경 지시를 함께 입력하는 편집을 지원한다. [공식 가격표](https://ai.google.dev/gemini-api/docs/pricing)의 2K 이미지 출력은 장당 $0.0504다. 두 장의 출력 예상액은 $0.1008이며 입력과 thinking을 포함한 예상액은 약 $0.13이다. 응답 사용량에 따라 달라질 수 있고 실제 청구서 금액은 아니다.

이전 승인 한도는 모두 사용했으므로 새 두 번의 유료 호출은 추가 승인 뒤 실행한다. 후보 생성은 운영 교체 승인이 아니다. 실제 운영 베이스를 올리거나 연결할 단계에서는 별도 승인이 필요하다.

## 승인 후 후보 생성 결과

사용자가 두 후보 생성을 승인하면서 내장 Codex로도 만들어 보라고 요청했다. Nano Banana 2.1 편집은 최대 2회 그대로 실행했고, 내장 `image_gen` 도구 호출 한 번을 추가했다. 내장 후보는 imagegen 스킬의 기존 이미지 편집 절차를 사용했다. 로컬 원본을 직접 본 뒤 편집 대상으로 전달했고, 결과는 원본을 덮어쓰지 않고 프로젝트 폴더에 복사했다.

| 후보 | 실제 반환 | 응답 시간 | 사용량 추정 |
| --- | --- | --- | --- |
| 2.1 기본 모델 체형 | JPEG 1696×2528 한 장 | 25.1초 | $0.060060 |
| 2.1 슬림 모델 체형 | JPEG 1696×2528 한 장 | 19.0초 | $0.055998 |
| 내장 Codex 후보 | PNG 1024×1536 한 장 | 별도 측정하지 않음 | 도구 결과에 사용량과 비용이 없음 |

두 Google 응답의 모델 버전은 `gemini-nano-banana-2.1`이며 사용량 추정 합계는 $0.116058다. 내장 도구는 이미지 모델 식별정보를 반환하지 않으므로 작업 에이전트 gpt-6.1-sol과 이미지 생성 모델을 같은 모델이라고 설명하지 않는다. 청구서 실비는 확인하지 않았다. Google 요청 두 번과 내장 생성 한 번은 서로 구분해 기록한다.

세 후보 모두 기존의 큰 포즈와 흰 마네킹, 촬영 구도를 대체로 이어받았다. 2.1 두 후보는 복근 음영이 약해졌지만 가슴과 어깨 볼륨이 상당히 남았고, 두 후보 사이의 체형 차이는 작다. 내장 후보는 팔, 복부와 허벅지의 근육 구분이 더 부드럽게 읽혀 우선 착장 검증할 후보로 추천한다. 가슴 윤곽은 일부 남는다. 독립 검수에서도 같은 후보를 추천했고, 눈에 띄는 손발 구조 오류와 머리 및 발 잘림은 발견하지 못했다. 미세한 형상과 랜드마크의 동일성, 새 체형의 상품 핏 재현을 인증한 것은 아니다.

후보 파일은 로컬 폴더의 `neutral-model.jpg`, `slender-model.jpg`, `codex-native.png`다. `source-men-base.png`와 함께 `body-comparison.png`, `comparison.html`에서 비교한다. 요청 지시는 두 `*-prompt.txt`와 `codex-native-prompt.txt`에 저장했다. 내장 도구 원본은 `/Users/daily/.codex/generated_images/01a11679-c7fd-7f43-95cd-93213f6d33ff/exec-9b13c848-183a-4ed8-9924-f03b7e946664.png`에 남아 있으며 프로젝트용 사본을 만들었다. 사진은 커밋하지 않는다.

## 기존 마네킹 흐름의 교체 방향

기존 포즈를 계승하는 남성 고정 베이스를 새 후보로 바꾸는 방향을 검토한다. 매번 체형 보정 지시를 추가하는 방식보다, 옷을 입힐 기준 사진 자체를 하나로 고정하는 방식이 현재 구조와 맞는다. 선택한 후보를 새 asset id로 등록하고 남성 베이스 선택에 연결해야 한다. 기존 에셋의 바이트를 같은 id 아래 덮어쓰지 않는다. 생성 캐시의 입력 해시는 `baseAssetId`를 포함하므로 새 id가 기존 몸을 사용한 캐시와 구분하는 기준이다.

운영 등록과 연결은 아직 하지 않았다. 새 후보에 같은 체크셔츠 원본과 같은 매칭 의류를 입혀 색과 체크, 기장과 핏, 손과 포즈를 확인하는 검증이 다음 단계다. 후보만 보기 좋다고 실제 상품 착장도 좋아졌다고 확정하지 않는다. 운영 교체와 새 유료 착장 테스트는 별도 승인 범위다.

## 확인한 것과 남은 일

기존 마네킹 세 의류의 입력 해시 일치와 가벼운 정돈 모델을 확인했다. 준비 단계는 키와 네트워크를 사용하지 않았다. 승인 후 새 후보 세 장은 실제로 생성하고 직접 보았다. 두 후보 제한, 원본 입력 변조 거절, 승인 전 키 접근 차단의 무료 재현 검사 3개가 통과했다. 제품 코드와 화면은 바꾸지 않았다. 새 체형에 실제 옷을 입힌 결과는 미검증이다.

비교 HTML의 사진 참조와 새 표기를 로컬에서 확인한다. 브라우저 연결 및 로컬 파일 URL 제한으로 모바일 다섯 폭과 WebKit 화면 검사는 새로 수행하지 못했다.

## 쉬운 설명

표기 때문에 헷갈렸지만 갈색 바지와 체크셔츠도 이미 가벼운 정돈 2K 사진으로 마네킹을 만들었다. 2K는 제품 사진의 크기였고 마네킹 출력은 1K였다. 남성 베이스는 2.1 두 장과 내장 Codex 한 장을 만들었다. 내장 후보를 먼저 실제 옷으로 검증하는 방향을 추천하며, 운영 베이스 교체는 아직 하지 않았다.
