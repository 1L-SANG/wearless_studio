# 2.1 정돈과 마네킹 생성의 실제 비교 결과

실사용 작업 모델은 gpt-6.1-sol, effort는 xhigh다. 2026-10-08에 사용자가 추가 최대 20회 유료 검증을 승인했다. 빨간 가디건은 새 표본과 이번 판단에서 제외했다. 이 문서는 연구 결과이며 제품 요구사항을 바꾸는 결정문이 아니다.

## 결론

이번 표본에서는 주상품 사진을 2.1로 먼저 정돈하는 단계를 마네킹 기본 흐름에 추가할 근거가 부족하다. 원본을 바로 넣은 마네킹도 보관 구김을 이미 자연스럽게 정리했다. 추가 정돈이 일관되게 더 좋은 상품 사진을 만들지 않았고, 평면 정돈에서 라벨과 단추가 바뀐 사례가 있었다. 제품의 마네킹 흐름과 모델, manifest는 이번 단계에서 바꾸지 않았다.

매칭 의류 카드에 쓸 사진을 배경과 지지물 없이 정리하는 이득과, 주상품을 마네킹에 입히기 전에 추가 전처리하는 이득은 별도로 판단해야 한다. 이번 검증은 주상품 Front를 정돈본으로 바꾸거나 생성 참고 자료로 추가하는 경우다. 매칭 의류만 바꾼 전체 착장 검증으로 확대하지 않는다.

## 실행한 것

승인한 Google 정돈 6회와 OpenAI 마네킹 14회, 총 20회 HTTP POST를 실행했다. 20회 모두 HTTP 200이며 이미지 한 장씩 해독됐다. 재시도와 다른 모델 전환은 0회다. 원본 해시와 사진 역할을 유지했고, 생성 결과는 로컬에만 저장했다. 운영 DB와 R2, AWS에는 접근하지 않았다.

정돈은 `gemini-nano-banana-2.1`, 2K 정사각형, thinking medium이다. 응답의 모델 버전도 6회 모두 같은 코드다. 마네킹은 현재 작업 브랜치 코드의 `gpt-image-2.5-sunburst`, medium, native `1024x1536` 요청이다. OpenAI 직접 이미지 응답에는 모델명이 없으므로 요청 코드 확인과 응답 모델 버전 확인을 구분한다. 배포의 실효 설정은 조회하지 않았다.

기존 셔츠의 gentle 1K 이미지는 이전 결과를 재사용했다. 같은 셔츠에 원본, 기존 1K, 새 2K, 원본과 새 2K 함께 넣기를 각각 두 번 비교했다. 그린 포인텔 니트, 네이비 체크셔츠, 갈색 면바지는 원본과 새 2K를 조건당 한 번 비교했다. 데님은 같은 2K에서 기존 gentle와 국소 구김 설명을 추가한 지시를 조건당 한 번 비교했다.

## 바지 주름이 잘 안 펴졌던 이유

기존 gentle와 catalog 지시는 워싱과 수염 자국을 보존하고, 보관 구김 그림자와 구분하기 어려운 곳은 유지하라고 요청했다. 이번 같은 모델의 국소 구김 지시에서 큰 접힘이 줄어, 지시가 결과에 영향을 줄 수 있다는 관찰은 얻었다. 하지만 조건당 한 번이므로 지시 효과와 생성 변동을 완전히 분리하지 못한다. 모델이 바지를 정돈할 능력이 없다고 단정할 수 없으며, 내부 판단의 원인을 확인한 것도 아니다.

워싱 없는 면바지도 기본 gentle에서 큰 구김이 남았다. 따라서 워싱 보호만이 모든 바지의 원인이라는 설명도 충분하지 않다. 강한 주름 제거는 주머니와 잠금장치, 워싱을 다시 그릴 위험을 함께 드러냈다. 더 매끈한 사진을 만드는 것만을 성공 기준으로 두면 다른 상품처럼 보이는 결과를 선택할 수 있다.

## 확인한 것과 못 한 것

실험 실행 전 무료 재현 테스트 14개가 통과했다. 실행 후 20개 요청의 실제 개수와 순서, 단일 이미지, 크기, 원본 해시, 원시 사용량 기록을 추가로 확인했다. 모든 정돈은 `2048x2048`, 마네킹은 `1024x1536`이다. 비교 HTML의 이미지 참조 34개도 모두 로컬 파일이 존재하고 정상 이미지로 읽혔다. 이것은 브라우저 렌더링 검사와 다르다.

제품 코드와 화면은 이번 단계에서 바꾸지 않았다. 전체 검사 결과는 앞선 동일 제품 코드의 서버 pytest 7698 통과, 104 조건부 건너뜀, 프론트 2806 통과, 빌드 통과다. 이번 문서와 로컬 연구 산출물 때문에 다시 실행하지 않았다. 104개는 별도 시험 DB, 선택 라이브러리, 가중치와 샘플, 환경 조건 때문에 건너뛰었다. 앞선 최종 검사에서 로컬 DB 접속 실패는 없었다.

새 HTML의 모바일 320, 360, 375, 390, 414px 스크린샷과 자동 줄바꿈 및 넘침 검사, WebKit 확인은 수행하지 못했다. 앞선 브라우저 연결 시간 초과와 로컬 파일 URL 정책 차단이 해결됐다고 주장하지 않는다. 브라우저를 다른 경로로 띄워 차단을 우회하지 않았다. 사진은 직접 열어 검수했다.

모든 마네킹 조건은 AG-01 계약과 Front crop이 없는 지원 분기로 통제했다. 유효 AG-01 분석 결과를 정돈본에 다시 연결하는 검사, 유료 QC와 자동 보정, 전체 worker, 현재 운영 베이스와의 동일성은 검증하지 않았다. 원본과 정돈본 함께 넣기의 권한 구분도 실험용이며 기존 제품 슬롯 계약이 아니다. 전처리의 약한 신호를 전체 운영 성공률이나 모델의 일반 우열로 확대하지 않는다.
