2026-11-01. 고스트컷, 평면컷, 자연광컷을 네 의류 종류에서 선택하고 생성하는 기능을 구현했다. 실제 생성 비교는 두 차례, 총 144회이며 사용량 환산액은 **7.142901달러**다. 승인 한도 15달러 중 7.857099달러를 사용하지 않았다. 공급자 청구서와 대조한 금액은 아니다. 자동 재시도와 유료 AI 심사 호출은 없었다.

[카테고리별 추천 후보](http://localhost:8765/.scratch/product-photography-20261101/recommendations.html)에서 세 촬영 방식의 후보를 모아 볼 수 있다. [보강 전후 전체 비교](http://localhost:8765/.scratch/product-photography-20261101/)에는 원본, 결과, 요청 프롬프트, 크기, 시간과 비용을 기록했다. 결과를 골라 삭제하지 않고 실패 사례도 함께 남겼다.

## 구현한 동작

- 콘티 인스펙터와 에디터 새 이미지에 촬영 방식 선택을 추가했다. 기존 전체컷의 내부 샷 값은 유지하고 `productPresentation`을 저장한다.
- 상의, 하의, 아우터, 원피스 모두 해당 면의 업로드 원본이 있으면 생성예시 없이 사용할 수 있다.
- 명시한 촬영 방식에서는 예시와 무드가 생성에 영향을 주지 않는다. 화면에서도 해당 갤러리를 숨긴다. 예전 선택으로 되돌릴 때를 위해 저장된 예시는 보존하되 생성과 접수 검증에는 사용하지 않는다.
- 앞뒷면, 색상, 저장, 복제, 재시도, 생성 결과 기록, 인접 칸 자동 채움에 선택값을 연결했다. 촬영 방식이 다르면 별도로 생성하고, 실제로 같은 요청은 한 장으로 계산한다.
- 카테고리별 촬영 지침, 원본 우선권과 방식별 검수 기준을 추가했다. 하의에는 몸통이나 어깨를 만들지 않으며, 원피스는 몸판과 치마의 연결 구조를 보존하도록 구분했다.

현재 모델 라우팅은 기존 설정을 사용한다. 아래 추천은 실험 결과에 따른 후보이며 운영 모델을 자동 변경하거나 배포하지 않았다. 기존 전체컷 검수의 발행 정책도 유지된다. 이 구현은 검수 실패 결과가 항상 차단되는 품질 보증 상품을 뜻하지 않는다.

## 실험 조건과 비용

각 카테고리에서 상품 한 벌씩, 앞면과 같은 면의 상세 원본을 썼다. 두 모델 계열에 EXIF 방향을 반영한 동일 PNG 픽셀을 보냈다. Gemini는 1K, GPT는 medium, 1024×1536 설정이다. Gemini의 실제 출력은 848×1264였다. 입력 해시, 전송 해시, 프롬프트와 실행 계획을 보관했다.

| Nano Banana Pro | 24 | $3.375276 | $0.1406 | 17.7초 |

GPT 96회, Gemini 48회로 호출 수 기준 두 배를 배정했다. 위 비용과 시간은 이 원본과 해상도, 품질 설정에서 얻은 값이다. 모델의 일반적인 비용·속도 우열로 확대하지 않는다. 가격 근거는 [Google 공식 가격](https://ai.google.dev/gemini-api/docs/pricing)과 [OpenAI 공식 가격](https://developers.openai.com/api/docs/pricing)이다.

각 차례에서 먼저 같은 공통 지시로 네 모델을 비교했다. 추가 GPT 호출은 모델별 보조 지시 조건이다. 같은 조건의 반복 표본이 아니므로 보조 지시 한 줄의 효과를 인과적으로 입증하지 않는다. 첫 차례는 $3.5349415, 보강 후는 $3.6079595였다.

## 프롬프트 보강 결과

첫 차례에서 투명 옷걸이가 남는 현상, 단추와 원피스 단 추가, 소매 잘림, 배경 색조가 의류로 번지는 현상을 확인했다. 이에 모든 지지체 제거, 부자재와 절개 개수 유지, 전체 윤곽과 여백, 줄무늬 대비, 화면 밖 광원과 접촉 그림자를 명시했다.

독립 시각 검토에서 보강 후 평면컷 24장 모두 옷걸이와 집게가 보이지 않았다. 원피스 18장 모두 아래 티어 연결선이 원본과 같은 두 개였다. 첫 차례 NB2.1이 세 개로 늘린 두 사례가 이번 표본에서는 개선됐다. 이는 해당 표본의 관찰이며 성공률 보장은 아니다.

남은 오류도 명확하다.

- Flare 셔츠의 일부 고스트·평면 결과는 단추를 원본 6개에서 7개로 늘린다.
- Pro 셔츠 자연광컷과 Sunburst 셔츠 자연광컷 일부는 소매가 프레임 가장자리에 닿거나 잘린다. 보강 전보다 나빠진 사례도 있다.
- Gemini의 셔츠 고스트컷은 원본에서 닫힌 칼라를 열거나 줄무늬 대비를 약화한다.
- Pro의 바지와 원피스 자연광컷에는 제외 지시에도 창틀이 들어간다.
- Flare 바지 자연광 보조 지시 결과에는 임시 사이즈 태그와 근거 없는 라벨이 남는다.
- GPT 고스트컷은 의류 보존이 좋은 편이지만 평면컷과 입체감 차이가 약하다. NB2.1의 하의는 부피가 분명하지만 스티치 대비와 밑단 형태가 달라질 수 있다.

따라서 **99% 유사 품질을 달성했다는 결론은 낼 수 없다.** 같은 상품을 실제 스튜디오에서 촬영한 정답 사진도 없으므로 스튜디오 대비 백분율 유사도를 계산할 근거가 없다.

## 이번 표본의 추천 후보

품질 기준 모델 후보는 Sunburst다. 다만 하나의 모델로 모든 방식과 품목을 고정하는 것은 아직 권하지 않는다. 아래는 보강 후 결과를 원본과 대조한 개별 후보이며 자동 모델 선택 규칙으로 배포하지 않았다.

| 카테고리 | 고스트컷 | 평면컷 | 자연광컷 |
|---|---|---|---|
| 상의, 줄무늬 셔츠 | Sunburst 공통, 단추 보존. 입체감 약함 | Sunburst 공통 | Flare 공통, 소매와 단추 보존 |
| 하의, 스티치 바지 | NB2.1, 부피가 분명함. 스티치와 밑단 검수 필요 | Flare 공통 또는 Sunburst 공통 | Sunburst 보조 지시 |
| 아우터, 크로셰 카디건 | Sunburst 공통 | Flare 공통 또는 보조 지시 | Sunburst 공통 |
| 원피스, 초록색 티어 원피스 | Flare 공통, 원본 구조 보존. 입체감 검수 필요 | Flare 공통 | NB2.1 또는 Sunburst 보조 지시 |

Nano Banana 2.1은 부피 표현의 비교 후보, Flare는 빠른 일반 컷 후보, Sunburst는 상품 보존 기준 후보로 본다. 이번 Pro 결과는 가장 비싸면서 소매 잘림과 자연광 소품 문제가 있어 우선 선택 이유가 약했다. 네 카테고리에서 각각 한 상품만 시험했으므로 두꺼운 코트, 스커트, 검정·흰색, 광택 소재, 큰 로고 등 전체 세부 품목을 검증한 것은 아니다. 실제 이미지 실험은 앞면이며 뒷면 경로는 코드 테스트로 확인했다.

## 검증

- 서버 전체: **9,727 passed, 106 skipped**. 기존 Pillow 경고 390개.
- 프론트 전체: **3,666 passed, 7 failed**. 남은 실패는 기존 FaceMarket API 요청 헤더 모의 테스트 5개와 가입 동의 요청 헤더 모의 테스트 2개다. 이번에 추가한 정규화 함수 때문에 실패한 추출 함수 테스트는 실제 함수를 주입하도록 수정해 통과했다.
- `pnpm build` 통과. 기존 큰 번들 경고는 남는다.
- 독립 코드 검토에서 발견한 불필요한 예시 의존과 불완전 사용량 계산 문제를 수정했고 재검토에서 해결을 확인했다.
- 내장 브라우저에서 콘티 촬영 방식 선택, 카드 라벨 반영, 비활성 예시 숨김과 320px 설정 영역을 확인했다. 다섯 모바일 폭의 렌더링도 확인했으나 Safari 실기기 검증은 수행하지 않았다. 에디터의 실브라우저 확인은 개발 모듈 로드 실패와 빌드 미리보기의 `ERR_BLOCKED_BY_CLIENT`로 완료하지 못했다. 에디터는 빌드, 렌더 및 요청 계약 테스트로 검증한 범위까지다.

최종 코드와 실험 자료는 로컬 작업 상태다. 기존 다른 작업의 변경을 보존했으며 커밋과 배포는 하지 않았다.
