# 의류 검수와 재생성 제어의 추가 검증

2026년 10월 11일. 주 작업과 코드 검증은 gpt-6.1-sol, effort xhigh다. Claude Fable 5.1 max와 GPT-6 Astra xhigh는 승인한 코드와 사진으로 설계 토론 및 독립 사진 검토를 했다. 서로의 판정이 엇갈려 모델 합의를 사진 정답으로 사용하지 않았다.

이 문서는 기존 초안 PR 482에 연결하는 연구 기록이다. 제품 변경은 최신 main에서 분리한 [초안 PR 514](https://github.com/1L-SANG/wearless_studio/pull/514)에 있다. PR 514의 검증을 PR 482의 최신 전체 검증으로 대체하지 않는다. 두 PR을 머지하거나 운영에 배포하지 않았다.

## 코드로 보강한 것

기존 검수 모델과 검사 체계를 유지하면서 세 경계를 보완했다.

1. 고정 검수 정책을 OpenAI developer 메시지와 Gemini systemInstruction으로 전달한다. 서버에서 검증한 사진 역할과 순번만 정책에 연결하고, 셀러 문구와 모델 관찰은 데이터로 둔다.
2. 검수 응답의 정상 완료 여부와 구조를 확인한다. 잘린 응답에 정상처럼 보이는 JSON이 있어도 성공 판정으로 사용하지 않는다. 기존 provider fallback은 유지한다.
3. 같은 상품 종류와 성별, 매칭 의류에서 세 번째 이후 마네킹 조정이 원본 기반 fresh 생성으로 돌아가도 기존 QC에 최신 부모 BEFORE를 연결한다. enforce와 shadow에서 기존 1회 호출의 보존 검사를 유지한다. off는 기존 0회 호출과 추가 BEFORE 조회 없는 동작을 유지한다.

마지막 문제는 마네킹 화면에서 같은 컷을 반복 조정할 때 도달한다. 기존에는 편집 깊이가 2 이상이면 생성 방식이 fresh가 되어 변경 전후 보존 검사가 빠졌다. 이번 수정은 생성 입력을 기존 사진으로 바꾸지 않고 검수 비교를 연결한다. 새로운 QC 호출은 없지만 비교 사진 한 장의 입력 비용은 늘 수 있다.

원본 동일성, 변경 전후 보존, 수정 목표 달성과 영역 밖 픽셀 보존은 별개다. 앞과 뒤의 밑단을 같은 모양으로 가정하지 않고, 원본이 잘리거나 작은 특징을 읽을 수 없으면 미확인으로 남긴다. 전체 QC의 모델 교체, 재시도 확대와 출고 정책 변경은 없다.

## 실제 사진 결과

알려진 개발 의류 6종의 원본 17장과 원래 픽셀의 부위 crop 22개를 사용했다. 빨간 가디건은 제외했다. 새로운 독립 의류 표본이나 정상 착용 정답집은 아니다.

| 확인 대상 | 결과와 한계 |
| --- | --- |
| 실제 줄무늬 최초 생성의 여분 단추 | 원본은 칼라 포함 6개, 결과는 최소 7개다. 기존 템플릿에 공통 자료를 더한 대조는 2번 모두 놓쳤고, 강화 정책의 두 전달 조건은 각각 2번 모두 잡았다. 한 상품의 특정 오류에서 얻은 결과다. |
| 원본 하단이 잘린 네이비 | 보이는 단추와 상품 전체 개수를 구분했다. 부위 진단 두 번은 원본 전체 개수를 미확인으로 남겼다. |
| 의도적 핑크 3단추 통제 | 실제 API mask를 쓴 수정 두 번에서 다섯 개로 복구됐다. 후검사도 개수는 통과했지만 작은 장식과 모든 구조를 인증하지 않았다. 자연 상품 성공률에서 제외한다. |
| 실제 줄무늬의 보정 두 번 | 수정 후에도 칼라 1개와 몸판 6개가 남았다. 후검사도 두 번 모두 실패했다. 자동 채택하지 않았다. |
| 핑크의 내부 소매 능선 | 실제 mask 유무를 각각 두 번 비교했지만 충분한 완화를 확인하지 못했다. 원본 봉제선인지 주름인지도 확정하지 않았다. |
| 흰 셔츠와 NB2.1 대안 | 앞뒤 밑단 전체와 작은 장식은 미확인이다. 생성 모델과 출력 설정 차이가 있어 한 모델의 우세나 자동 분석 개선으로 단정하지 않는다. |

같은 프레임의 국소 수정은 서버가 허용 영역 밖의 기존 RGB를 복사했다. 최종 줄무늬 두 장은 영역 밖 3,519,795픽셀의 변경이 0이었다. API mask만으로는 raw 결과의 영역 밖 픽셀 불변이 보장되지 않았다. 영역 밖 보존과 영역 안의 목표 달성은 다르며, 위 줄무늬는 밖을 지켰어도 단추 개수 목표에 실패했다. 이 합성은 로컬 연구이며 제품에 적용하지 않았다. 새로운 포즈에는 그대로 사용할 수 없다.

## 남은 일과 추천

비싼 모델로 전체 QC를 바꾸기보다 완료 응답 검사와 사진 근거 분리, 반복 조정의 보존 관문을 먼저 리뷰하는 쪽을 추천한다. 부위 진단과 국소 픽셀 고정은 추가 검증 후보이며, 자동 수정 적용을 확대할 근거는 아직 없다. 새로운 정상 의류와 실제 착용 정답, 미세 장식의 반복 정확도, 운영 지연과 비용을 확인해야 한다.

PR 482는 계속 초안이다. 일반 새 상품 흐름에서는 내 옷을 로컬 원본 카드로 먼저 등록하고 콘티 이동 뒤 서버 정리를 시작한다. 분석 카드의 60초와 실패 안내가 실제 정상 경로에서 보이도록 연결하는 일은 남아 있다. SAM 대기 합계 165초도 전체 처리를 엄격히 180초에 끝내는 보장은 아니다. 이번 QC 변경으로 최초 배경 정리 요청 전체가 완료됐다고 보고하지 않는다.

상세 조건과 비용은 [PR 514 연구 문서](https://github.com/1L-SANG/wearless_studio/blob/8001233212123cd98d831a47cce22e3e7f6df2d5/documents/research/qc_fidelity_controls_20261011.md)에 보존했다. 원본 사진과 원시 API 응답, 인증키는 Git에 넣지 않는다.

## 쉬운 설명

검수가 중간에 끝난 답을 정상으로 쓰거나 반복 수정에서 이전 컷과 비교하지 않는 문제를 고쳤다. 일부러 만든 단추 오류는 복구됐지만 실제 줄무늬와 핑크 소매 문제는 남았다. 검사 모델을 전부 바꾸거나 자동 수정 권한을 넓히지 않고, 확인한 코드 보강과 미해결 결과를 각각 기록했다.
