# 밑단과 소매선의 여러 해법 실험 계획과 변경 기록

실사용 작업 모델은 gpt-6.1-sol, effort xhigh다. 앞뒤가 다른 구조의 전달, 검사 오류와 비용 중단을 함께 다루므로 xhigh를 사용했다. 이 문서는 로컬 실험 기록이며 제품 계약이나 운영 적용 승인이 아니다.

## 목표와 오너 결정

오너는 흰 셔츠의 앞이 짧고 직선이며 뒤는 길고 곡선이라고 확인했다. Front 사진 아래에 보이는 긴 곡선 뒷자락을 앞단으로 복사하지 않는다. 확인된 곡선 앞단은 그대로 유지한다. 앞단 판단이 불확실하면 생성에서는 직선을 기본으로 사용한다. 이 기본값은 오너의 생성 정책이며 원본 관찰을 직선으로 고쳐 쓰는 근거가 아니다. 기존 분석 응답과 사진은 보존한다.

핑크 헨리넥은 실제 팔구멍 가장자리 바인딩과 가슴 절개, 다섯 장식 단추를 유지하면서 어깨 안쪽의 확인되지 않은 소매 부착선 같은 선을 줄이는 것이 목표다. 실제 봉제선까지 전부 지우는 방식은 실패다. 다른 상품에서도 원본 구조, 그림자와 주름을 구분해야 한다.

커스텀 매칭에는 최신 정돈이 이미 적용됐는지 제품 코드를 먼저 확인한다. 현재 PR482의 Pro 1K 직접 생성과 새 NB 2.1 2K 정돈 실험을 구분한다. 기존 QC 전체를 교체하거나 운영 specialist를 켜지 않는다.

## 승인과 범위

오너가 새 실험 총 $8을 미리 승인했다. Google Gemini와 OpenAI 이미지 API로 이미 승인한 로컬 원본과 파생 이미지를 처리한다. Claude와 토론하며 사진 전송은 별도 수신처 질문에 대한 오너 승인을 받은 뒤 진행한다. 운영 DB, R2, AWS, 배포, 매니페스트 변경은 이번 실험에 포함하지 않는다.

새 원장은 Claude 실행, 이미지 생성과 검사를 합산한다. 이미지 전 $0.90, 검사 전 $0.15, Claude 실행 전 $0.50을 예약한다. 예약까지 더한 금액이 $8을 넘으면 보내지 않는다. 확인된 추정액 $6.80부터 새 호출을 중단한다. 사용량 비용이 불명확하면 예약을 유지하고 멈춘다. 같은 stage를 자동 재시도하지 않는다. 생성 이미지를 Python으로 의미 있게 수정하거나 주변 픽셀을 합성해 잠그지 않는다.

## 측정의 제한

검사는 앞단, 뒷자락, 팔구멍, 어깨 위치, 가슴 절개, 단추, 기장과 품을 개별 대조한다. 첫 좌표 프로토콜 오류는 무효로 보존하고 통과로 바꾸지 않는다. 이후 원본 ID와 생성 전체 및 확대 ID를 별도 문자열로 지정한다. 마지막 범주형 검사는 좌표 없이 앞판, 뒷판, 내부 연결선, 바인딩, 가슴 절개, 단추 수와 디자인, 기장과 품, 색과 무늬를 질문한다. 자동 수정 허가나 전체 품질 통과 판정은 아니다.

커스텀 제품컷 비교는 모델, 해상도, 여러 원본 뷰와 sRGB 처리를 함께 바꾼 방식 비교다. 모델만의 효과로 해석하지 않는다. 첫 생성의 원본 상세 확대, 짧은 지시와 모델 변경도 각각 따로 기록한다. 같은 조건의 독립 생성 두 번이며 API가 제공하지 않는 고정 seed를 썼다고 주장하지 않는다.

사진은 원본과 생성본을 직접 보고 독립 검수도 받는다. 실제 곡선 반례와 미확인 앞단 정책 준수는 전체 상품 보존과 다르다. 실제 착용 치수와 정확한 기장은 사진 배치와 물리적 치수 없이 확정하지 않는다.

## Claude의 실제 참여

실제 응답 모델은 claude-sonnet-5-5, effort high다. 도구와 MCP, 브라우저와 세션 저장을 끈 읽기 전용 실행이며 새 제품 코드 편집을 맡기지 않았다. 첫 두 번은 텍스트 토론이다. 세 번째는 오너가 허용한 원본 네 장과 최초 생성 여덟 장의 비교 이미지 한 장을 보았다. 이후 부분 수정과 매칭 제품컷, 마지막 반복을 Claude가 보았다고 주장하지 않는다.

Claude가 제시한 관찰도 정답으로 고정하지 않는다. 특히 캡슬리브라는 외형 이름은 별도 소매를 붙인 봉제 경계가 있다는 증거가 아니다. 답변 원문과 비용 사용량은 로컬에 가공 없이 보존한다.

## 쉬운 설명

옷을 더 예쁘게 만들기 전에 실제 앞뒤 모양과 소매 마감을 지키는지 여러 방법으로 비교한다. 잘 모르는 부분을 사실처럼 확정하지 않고, 다른 상품으로 바뀌거나 비용을 확인할 수 없으면 그대로 채택하지 않는다.
