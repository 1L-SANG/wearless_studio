# FaceMarket 사용 품목 분류 제안 (2026-09-08)

오너 질문: "모델 프로필에 카테고리를 저렇게 다 써 놓으면 너무 많다. 자동 승인 카테고리든 자동 금지 카테고리든 어떻게 분류할지 정해야 한다. 다른 서비스도 보면서."

## 1. 지금 코드가 하는 일

- 품목 어휘는 13개다. 허용 후보 11개(상의, 하의, 아우터, 원피스, 니트·스웨터, 데님, 셋업·수트, 스커트, 트레이닝·애슬레저, 잡화·액세서리, 뷰티·화장품)와 금지 후보 2개(속옷·란제리, 수영복·비키니). 출처 `src/lib/brandUseCategories.js`, 서버도 같은 목록으로 검증한다.
- 모델은 라이선스 발급 폼에서 허용 품목을 여러 개 고르고, 금지 품목은 기본으로 두 개가 들어간다.
- 셀러 상품에는 분석 단계에서 정해지는 `brandUseCategory` 한 값이 붙는다. 컷을 만들 때 서버가 그 값이 모델의 허용 목록에 있고 금지 목록에 없는지 확인해 아니면 409로 막는다(`server/app/facemarket.py`의 라이선스 사용 검사).
- 초상 이용허락 계약 제9조에 플랫폼 전면 금지 용도 8항(성적 연출, 정치·종교, 의료·건강 효능, 혐오·폭력, 기만 보증, 딥페이크·합성, 재학습, 위법)이 있다. 이건 품목이 아니라 용도라서 어느 화면에도 선택지로 나오지 않는다.

즉 게이트는 이미 있다. 문제는 "모델이 13개 중에서 고르고, 셀러가 13개 칩을 읽는" 단위가 너무 잘아서 화면과 입력 모두 뭉뚱그려 보인다는 것이다.

## 2. 다른 서비스는 어떻게 나누나

| 서비스 | 나누는 방식 | 우리에게 가져올 것 |
|---|---|---|
| Getty Images | 금지 목록 대신 "민감한 사용"(불쾌하거나 논쟁적인 주제)에는 "모델이 연출한 사진"이라는 고지를 붙이게 한다 | 품목이 아니라 **용도의 민감도**로 선을 긋는다 |
| Shutterstock | 일반 라이선스와 별도로 "Sensitive Use" 라이선스. 건강 상태 암시, 특정 의견·상품 지지 암시, 논쟁적·불쾌한 연관 | 민감 사용은 **별도 동의 + 더 높은 대가**라는 구조 |
| Adobe Stock | 담배 광고, 성인 업소, 정치·의견 운동 지지 암시, 장애 암시, 비하적 사용을 금지 | 전면 금지 목록의 구체 항목(우리 계약 제9조와 거의 같다) |
| LIKN | 항상 금지(정치, 성인, 기만)는 플랫폼이 고정하고, 탤런트는 프로필에서 **산업·경쟁사를 제외**하며, 상업 사용은 건별 승인 | 3층 구조: 플랫폼 고정 금지, 본인이 정하는 제외, 건별 승인 |
| FameFlow | 셀럽이 카테고리 필터와 규칙을 미리 정해 두면 크리에이티브가 자동 승인 | **사전 규칙 + 자동 승인**. 우리 단가(건당 1.5만원)에서는 건별 승인이 불가능하므로 이 방식이 유일 |
| Vermillio | 권리자가 용도별 스위치(팬아트 허용, 상업은 수익화)를 켜고 끈다 | 세부 품목이 아니라 **몇 개의 스위치** |
| Authentic(thatsmyface) | 허용·제한 콘텐츠와 "개인 경계"를 모델이 설정, 이미지당 가격 | 제한 목록이 모델의 문장으로 읽히게 |

공통점 두 가지. 첫째, 어느 곳도 세부 품목 13개를 나열하지 않는다. 몇 개의 큰 스위치와 짧은 금지 목록이다. 둘째, "항상 금지"와 "본인이 정하는 제외"를 층으로 나눈다.

## 3. 제안: 네 층으로 나눈다

### 0층. 플랫폼 전면 금지 (누구도 못 켬)
계약 제9조 8항 그대로. 화면 선택지로 내보내지 않고 약관, 검수, 생성 게이트에서만 다룬다. 지금과 같다.

### 1층. 일반 의류 (기본 허용, 스위치 없음)
오너 확인(9/8): FaceMarket은 의류만 다룬다. 잡화·뷰티는 스위치로 두지 않는다. 일반 의류(상의, 하의, 아우터, 원피스, 니트·스웨터, 데님, 셋업·수트, 스커트, 트레이닝·애슬레저)는 등록하면 자동 허용이고, 모델이 고를 것이 없다. 기존 어휘의 잡화·액세서리, 뷰티·화장품 두 값은 셀러 상품 분류에서 "취급 안 함"으로 막는다.

세부 품목 어휘는 그대로 살아 있다. 셀러 상품 분류와 서버 게이트는 세부값으로 계속 돌고, 모델의 허용 목록에는 일반 의류 9개가 통째로 들어간다. DB 스키마 변경 없이 화면과 입력만 바뀐다.

### 2층. 민감 품목 (기본 꺼짐, 모델이 따로 켬, 켤 때 별도 동의 문구)
| 항목 | 지금 어휘 | 비고 |
|---|---|---|
| 속옷·란제리 | 있음(금지 후보) | |
| 수영복·비키니 | 있음(금지 후보) | |
| 노출 강조 의류(시스루, 크롭, 브라탑) | **없음, 추가 제안** | 셀러 상품 분류에도 이 값을 추가해야 게이트가 작동 |

Shutterstock처럼 켤 때 단가를 따로 받을 수 있다(예: 건당 단가의 1.5배). 켜지 않으면 상세 창 제외 품목에 "속옷 · 수영복 · 노출 강조"로 표시된다.

### 3층. 채널과 용도 (셀러가 사는 SKU, 모델은 채널별로 켜고 끔)
| 채널 | 상태 |
|---|---|
| 내 쇼핑몰 상세페이지 | 기본. 지금 유일한 SKU |
| SNS 광고 소재 | 확장 SKU. 가격 로드맵에 이미 있음 |
| 오프라인 인쇄 등 | 미정 |

### (나중) 셀러 차단, 경쟁 브랜드 제외
LIKN의 "산업·경쟁사 제외"에 해당. 모델이 특정 셀러나 브랜드군을 막는 기능. 거래가 생긴 뒤에 붙인다.

## 4. 화면에 어떻게 보이나

- 모델 리스트 카드: 품목을 쓰지 않는다(오너 확인 9/8). 의류만 다루므로 카드에서 구분할 것이 없다.
- 상세 창: 허용 품목 줄은 "일반 의류"로 고정, 제외 품목 = 꺼진 민감 품목("속옷 · 수영복 · 노출 강조"). 민감 품목을 켠 모델은 그 줄이 사라지고 허용 줄에 붙는다.
- 모델 등록(라이선스 조건 단계): 일반 의류는 안내 문구만, 민감 품목 3개 스위치. 켜면 한 줄 동의가 뜬다. "속옷 착용컷은 노출이 있는 컷입니다. 켜면 셀러가 별도 승인 없이 만들 수 있어요."
- 셀러 쪽: 상품 분석이 세부 품목을 정하는 건 지금 그대로. 노출 강조 의류만 분류 값이 하나 는다.

## 5. 오너가 정할 것

1. 노출 강조 의류를 민감 품목으로 추가할지. 추가하면 셀러 상품 분류에도 같은 값을 넣어야 한다.
2. 민감 품목을 켠 모델의 단가 가산 여부와 배수.
3. 잡화·뷰티 두 어휘를 셀러 상품 분류에서 아예 빼는 시점.
4. SNS 광고 채널 SKU를 언제 여는지.
5. 셀러 차단 기능을 언제 붙이는지.

(9/8 오너 확인으로 닫힌 것: 의류만 취급, 카드에 품목 표시 안 함.)
