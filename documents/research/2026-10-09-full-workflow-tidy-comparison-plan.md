# 새 의류의 원본과 가벼운 정돈 마네킹 비교 준비

실사용 작업 모델은 gpt-6.1-sol, effort는 xhigh다. 오너의 요청은 다른 의류에서도 기존 방식과 가벼운 정돈 방식을 비교하는 것이다. 기존 유료 승인 한도는 모두 사용했으므로 이 문서는 새 유료 실행 전 준비 기록이다. 디자인 승인을 추가로 요구하지 않는다.

## 비교할 것

흰 셔츠, 핑크 골지 헨리넥, 검정 워싱 청바지 세 종류를 고른다. 각 상품의 원본 방식과 가벼운 정돈 보조 방식 한 쌍씩, 최종 마네킹 최대 여섯 장을 비교한다. 조건당 한 번인 탐색이므로 반복 우세와 일반 성공률을 확정하지 않는다. 빨간 가디건은 쓰지 않는다.

| 표본 | 원본에서 직접 확인한 검수 초점 |
| --- | --- |
| 흰 셔츠 | 앞면과 뒷면의 전체 밑단이 보이고 곡선 윤곽이 있다. 실제 곡선을 보존하고 큰 보관 접힘을 새 봉제선으로 만들지 않는다. |
| 핑크 골지 헨리넥 | 앞면 다섯 단추, 세로 골지, 가슴 절개, 어깨와 팔구멍 가장자리를 비교한다. 늘어진 물결과 밑단 설계를 구분한다. |
| 검정 워싱 청바지 | 앞면 두 허리 단추, 앞뒤 주머니, 밝은 워싱 위치, 다리 폭과 밑단을 비교한다. 워싱을 구김으로 오인해 지우지 않는다. |

세 표본의 원본 여덟 장을 직접 보아 사진 역할을 확인했다. 흰 셔츠는 Front와 Back만 있으며 Detail을 지어내지 않는다. 다른 두 상품은 Front, Back, Detail이 있다. 검정 청바지의 02 사진은 잠금 구조 확대이고 03 사진이 Back이다. 핑크 원본의 넓은 어깨를 제품 이름만으로 별도 소매라고 확정하지 않는다. 위 사람 관찰은 최종 대조용이며 자동 분석의 사실로 주입하거나 분석 결과를 사람이 수정하지 않는다.

## 같은 조건과 다른 조건

기존 조건은 원본 상품 사진으로 현재 AG-01 분석을 한 번 수행하고 유효한 사진 근거 계약을 사용한다. 원본 사진과 같은 픽셀 크롭, 분석 결과와 자동 핏, 성별 베이스와 매칭 의류를 준비해 현재 후보 생성 함수를 끝까지 실행한다.

정돈 조건은 동일한 원본 분석과 사진 근거를 그대로 사용한다. Nano Banana 2.1의 gentle 2K 정사각형 한 장을 만들고 원본 사진과 비교하는 별도 검수를 거친다. 통과한 정돈본은 최초 생성의 GENERATED ARRANGEMENT AID로만 추가한다. 원본 Front를 바꾸거나 원본 계약을 생성된 픽셀에 다시 바인딩하지 않는다. 원본 사진이 색, 무늬, 재질, 구조, 핏과 기장, 밑단의 기준이다. 보조본은 보관 구김을 가볍게 정리하는 참고만 한다.

정돈본이 원본을 바꾸거나 중요한 구조를 확인할 수 없으면 사용하지 않는다. 해당 조건은 원본 방식의 결과로 돌아갔다고 기록하고 새 착장 생성 비용을 쓰지 않는다. 검수 실패를 정돈 성공으로 세지 않는다.

두 조건 모두 기존 의류 QC와 베이스 QC, 적용 가능한 핏 검사와 untuck 검사, 필요한 보정과 보정 후 검사를 수행한다. 검수나 후속 수정에 정돈본을 원본으로 전달하지 않는다. 전문 구조 검사는 저장된 운영 설정처럼 off를 유지한다. 두 조건에 새 공통 검사 정책을 몰래 추가하지 않는다. 최종 결과를 원본과 사람이 다시 대조하고 상품 충실도와 외관 개선을 따로 기록한다.

공통 생성 템플릿과 원본 근거가 동일하며 추가 보조본의 역할을 설명하는 문구만 정돈 조건에 붙는다. 원본 입력 대체와 다르므로 지난 Front 대체 실험과 효과를 섞지 않는다. 생성 순서는 흰 셔츠와 청바지가 원본 먼저이고 헨리넥은 정돈 먼저다. 한 번씩의 순서를 교차했을 뿐 무작위 반복 실험은 아니다.

## 밑단 기준

라운드 밑단을 일괄 금지하지 않는다. 사진에서 확인한 곡선 밑단은 그대로 구현한다. 가려지거나 잘린 밑단은 확인 불가이며 곡선이나 직선의 전체 설계를 새로 단정하지 않는다. 원본의 물결과 접힘을 밑단 재단 형태로 오인하지 않는다.

현재 AG-01 계약은 이미 잘리거나 숨은 밑단을 unknown으로 기록하고, 생성용 근거 문구도 unknown에서 스타일을 추론하지 않도록 한다. 지난 실험은 `photo_structure=None`, 빈 분석과 유료 QC 0회인 첫 생성 비교여서 이 경로를 거치지 않았다. 과거 특정 파란 체크셔츠의 수동 직선 밑단 지시가 다른 모든 셔츠의 정본 요구는 아니다. 다만 사진에 없는 구조를 추정하지 않는 원칙은 이번에도 유지해야 한다.

정돈 시스템 지시에 이 원칙을 명시했다. 마네킹의 기존 생성 템플릿에는 별도의 일괄 직선 지시를 넣지 않는다. 실제 곡선인 흰 셔츠가 곡선 금지의 잘못된 대조군이 되지 않게 한다. 분석이 사진 근거를 잘못 읽거나 최종 결과가 밑단을 바꾼 경우에는 자동 통과와 별개로 실패 또는 보류를 기록한다.

## 유료 요청과 비용
