# FaceMarket 등록 흐름, 2026-09-25

화면, 서버 메일, 안내 문서가 함께 사용하는 현재 구현 기준이다. 운영 사이트 반영 여부는 배포 후 별도로 확인한다.

## 사용자에게 설명할 순서

1. **지원**: 기본 정보와 심사용 프로필을 제출한다. 이 사진으로 모델 등록이 완료되지는 않는다.
2. **지원 심사**: 결과를 이메일과 마이페이지에서 확인한다. 승인 후 등록을 시작한다.
3. **본인확인**: 필수 동의 후 인증한다. 간편인증 경로는 주민등록증 사진 제출과 담당자 신원 확인이 추가된다. 촬영과 앨범 선택 모두 뒤 7자리를 직접 가리는 단계를 거치고, 가려진 결과를 확인해야 제출할 수 있다. 원본은 단말 안에서만 다룬다.
4. **사진 18장**: 그늘 9장, 햇빛에서 방향을 바꾸며 3장씩 총 9장을 올린다. 촬영 가이드는 `/photo-guide`에서 로그인 없이 볼 수 있다.
5. **사용 조건과 증서**: 사진을 다 올리면 바로 허용할 옷 종류를 정하고 '라이선스 증서 발급하기'로 계약에 서명한다. 증서는 신원 확인이 끝나면 발급되고 철회 시까지 유효하다.
6. **테스트컷 준비**: 담당자가 신원(간편인증)과 사진을 확인하고 2일 안에 테스트컷을 보낸다. 필요한 사진은 재촬영을 요청할 수 있다. 발급 전 재촬영은 신원 승인 전에 요청하고, 새 사진과 증서용 자료를 다시 준비한 뒤 신원을 승인한다. 이미 신원 승인된 발급 대기 건은 발급 완료 뒤 재촬영을 요청한다. 등록 뒤 기다리는 '검수 중' 화면은 없다.
7. **확정 후 공개**: 모델 본인이 테스트컷을 확인·확정하면 공개되고, 이때 증서 발급 완료를 알린다. 지원 승인이나 증서 발급만으로 바로 공개되는 것은 아니다.

## 사진 안내

- 전체 등록 사진은 18장이다. 지원 심사용 프로필과 구분한다.
- 얼굴과 어깨를 촬영하며, 옆모습 두 방향과 뒷모습을 포함한다.
- 촬영 준비 안내는 안경 모자 벗기, 혼자 나오기, 후면카메라 촬영, 같은 날 찍기의 네 항목이다.
- 밝은 야외에서 도와줄 사람과 약 15분 촬영한다. 촬영 외 등록 절차는 약 10분이며 심사 대기 시간은 별도다.
- 촬영 중 실시간 검사는 없다. 서버는 업로드 때 사진을 검사하고, 이후 담당자가 확인한다.
- 저장한 사진은 다시 돌아와 이어서 등록할 수 있다.

## 문구 적용 원칙

- 한 장으로 모델이 완성된다는 표현을 쓰지 않는다.
- 3분은 지원서 작성 시간에만 쓴다. 사진 촬영과 등록 전체의 시간으로 안내하지 않는다.
- 신규 등록 사진 수는 18장이다. 기존 3장·16장 등록을 복원하는 호환 처리와, 18장 중 내부 자산 생성에 사용하는 참조 사진 수는 바꾸지 않는다.
- 서버의 미완료 오류는 해당 등록의 동의 버전에서 요구하는 사진 수를 안내한다.
- 지원 승인 메일 본문은 오너 확정 6단계 문구다(본인확인, 18장 사진 찍기, 사용 조건, 블록체인 기반 라이선스 증서 발급, 테스트컷 선정, 최종 등록 완료).
- 증서 발급 순간에는 메일을 보내지 않는다. 테스트컷을 확정하면 '등록이 최종 완료됐어요' 메일을 보낸다.
- 모델에게 가는 메일 하단은 '이 메일은 발신 전용이에요.'와 문의처(010-9592-0333, @facemarket_official) 두 줄이다.

## 2026-09-25 변경

- 등록을 마친 뒤의 '검수 중' 대기를 없앴다. 사진을 다 올리면 바로 사용 조건으로 가고, 증서는 신원 확인이 끝나는 대로 발급한다. 모델에게는 테스트컷 확정 뒤에 증서를 보여 준다.
- 신분증 촬영은 직접 셔터를 누른다. 촬영 틀 안의 사진을 크게 보여주고 사용자가 번호 위치를 눌러 가림 박스의 위치와 크기를 조절한다. 가림 결과를 별도 미리보기에서 확인해야 업로드할 수 있다. 서버는 지정 영역의 불투명 처리를 검사하고, 번호가 실제로 가려졌는지는 담당자가 신원 승인 전에 확인한다.
- 사진 페이지 첫 화면에 '찍기 전, 확인해요' 4가지를 두고, 예시 설명 문구를 지웠다.
- 사용 조건에서 체형 선택을 없앴다. 협찬 기한은 옷 수령 후 7일 이내 게시, 게시일부터 90일 유지로 바꾸고 약관 버전을 올렸다.

## 2026-09-17 정합성 점검 결과

운영 홈에서 이전 배포의 한 장 지원 안내와 3장 등록 설명이 남아 있는 것을 직접 확인했다. 작업트리 홈·FAQ·등록 안내, 승인·본인확인·증서 메일, 등록 미완료 오류, 공개 사진 수 고지와 현재 PRD를 위 흐름에 맞췄다. 기존 등록 호환 처리와 실제 제출 요건은 변경하지 않았다.

검증: 서버 전체 테스트 5,714개 통과, 79개 건너뜀. 관련 프론트 테스트 71개 통과. `pnpm build` 통과. 로컬 홈에서 18장 등록과 테스트컷 확정 후 공개 안내가 함께 표시되는 것을 확인했다. 고객에게 실제 메일을 보내거나 운영 배포를 실행하지 않았다.
