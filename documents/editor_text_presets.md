# 에디터 텍스트 프리셋과 카피 슬롯

현재 텍스트 추가·편집 계약이다. 수동 프리셋은 `src/features/editor/presets/textPresets.js`, 검증은 `tests/frontend/text-presets.test.mjs`를 따른다. 생성 페이지의 글 칸 서체, 크기, 배치는 템플릿 카탈로그(`server/app/data/page_templates_v1.json`)와 페이지 토큰(`src/lib/pageTemplates/tokens.js`)이 정한다. 자동 조립은 템플릿 조립기(`server/app/agents/page_template_assembler.py`, 같은 엔진의 프론트판 `src/lib/pageTemplates/assemble.js`)가 맡고, 목 생성기(`src/mock/db.js`)와 생성 대기 화면의 뼈대도 프론트판을 쓴다. 생성 대기 화면의 병합은 `src/lib/editorWaitSkeleton.js`가 담당한다.

## 프리셋

| 저장 키 | 화면 이름 | 글자 크기 | 굵기 | 색상 | 행간 |
|---|---|---:|---:|---|---|
| `headline` | 큰 제목 | 40 | 600 | `#0e0d14` | 자동 |
| `subtitle` | 소제목 | 26 | 600 | `#0e0d14` | 자동 |
| `body` | 설명글 | 17 | 400 | `#6b6b73` | 26 |

텍스트 색상 상수는 `TEXT_INK=#0e0d14`, `TEXT_MUTED=#6b6b73`, `TEXT_FAINT=#9a9aa2`다. 에디터의 정보 블록 프리셋(`src/features/editor/presets/infoPresets.js`)과 페이지 끝 자동 블록 중 사이즈 안내, 세탁 안내, AI 생성 안내가 이 색을 쓴다. 자동 블록의 값은 카탈로그 `autoBlocks`와 서버 `server/app/agents/page_assembler.py`에도 같은 값으로 들어 있으니 함께 맞춘다. 템플릿 글 칸과 공통 주의 블록의 색은 이 상수가 아니라 템플릿 색(카탈로그 `templates[].colors`)과 페이지 색감이 정한다. 사진 위에 얹는 첫 장 제목은 아래의 사진 대비 규칙으로 흰색(`#ffffff`) 또는 짙은 색(`#111111`, 카탈로그 `overlayColors`)을 쓴다. 패널의 축소 미리보기 크기는 22·17·13이며 실제 크기 순서를 유지한다.

기본 프리셋은 `subtitle`이다. `텍스트 추가`, `T` 단축키, 미지정 키와 알 수 없는 키는 모두 같은 기본값을 쓴다. 별도 일반 텍스트 스타일을 추가하지 않는다. 세 프리셋과 텍스트 추가 버튼은 클릭·드래그를 모두 지원한다.

빠른 스타일 전환은 `size`, `weight`, `color`, `lineHeight`, `tracking`만 바꾼다. 셀러가 정한 폰트·정렬·기울임은 유지한다. 프리셋에 없는 행간·자간은 자동값으로 되돌려 글줄 겹침을 막는다. 활성 프리셋은 대소문자 HEX, 자동 행간과 해당 폰트의 실제 지원 굵기를 정규화한 뒤 판별한다.

## 새 텍스트의 위치와 안내 문구

새 요소는 `type='text'`, `textSizing='auto'`, 기본 폰트 Pretendard, 문구 `내용을 입력하세요.`로 만든다. 첫 편집에서 문구 전체를 선택해 바로 갈아 끼울 수 있게 한다. 기본 좌표는 `(60,80)`, 캔버스 폭은 1000이다. 초기 폭은 글자 크기 × 8.8을 반올림하고, 높이는 지정 행간 또는 글자 크기 × 1.4를 반올림한다. 부착 후 실제 텍스트 크기로 다시 측정한다.

드래그 미리보기와 실제 요소는 같은 크기·좌표 계산을 쓴다. 포인터 위치가 글줄의 세로 중앙에 오며, 요소 전체를 블록 안으로 제한한다. 블록 높이를 모를 때만 세로 상한을 생략한다. 자동 관리 블록에는 일반 텍스트를 추가하지 않는다.

이번 편집에서 새로 만든 일반 텍스트를 수정하지 않았다면 선택·편집을 떠난 뒤 요소를 지운다. 저장과 발행 직전에도 같은 정리를 거쳐 안내 문구가 상세페이지에 실리지 않게 한다. 선택 상태에서 스타일만 바꾸는 동안에는 지우지 않는다. 셀러가 실제로 입력한 같은 문장, 기존 저장 요소, 말풍선, 자동 관리 블록과 카피 슬롯은 일반 안내 문구 정리 대상에서 제외한다.

## 생성 카피와 레이아웃

콘티 순서를 에디터에 보존한다. 템플릿 조립기는 같은 `pageSectionKey`가 이어진 카드 묶음을 한 섹션으로 보고, 섹션마다 `pageDesignId` 디자인의 배치로 사진과 글 칸을 놓는다. 행 정보로 사진을 묶는 방식은 쓰지 않는다. 섹션 이름은 에디터 블록 이름으로만 쓰고 자동 제목 블록으로 만들지 않는다. 자동 사이즈·세탁·AI 안내·공통 주의 블록은 섹션 뒤에 붙는다.

자동 카피는 `sourceBlockId`(섹션 첫 카드)와 `copyRole`로 콘티에 연결한다. `copyRole`은 카탈로그 섹션 종류의 글 칸 역할 이름이다(예: `title`, `para`, `items.0.desc`). 대기 중 빈 카피 슬롯도 이 연결을 유지해 생성 완료 때 채울 수 있어야 한다. 셀러가 대기 화면에서 직접 수정한 값은 늦게 도착한 생성 결과로 덮어쓰지 않는다. 비어 있는 슬롯을 임의의 판매 문구로 채우지 않는다.

글 칸은 카탈로그가 정한 출처로 채운다. 고정 문구(`static`)는 카탈로그 기본값, 사실(`fact`)은 상품명·색 이름·소재 같은 상품과 분석 값, AI 글(`ai`, `aiDraft`, `seller+ai`)은 생성 카피를 쓴다. 셀러 MD 코멘트를 받는 상품 소개 본문(`seller+ai`)은 감성형과 쇼룸형 모두 `analysis.mdComment`를 AI가 실제 쇼핑몰 상세페이지의 MD 코멘트처럼 다듬어 넣는다(2026-11-13 오너 결정). 다듬는 말투와 형식은 카피라이팅 작업이 정한다. 다듬기가 붙기 전에는 그 글을 줄바꿈까지 그대로 하나의 글상자에 넣고, 대기 화면에서도 생성 결과로 덮지 않는다. MD 코멘트가 없으면 AI 초안 자리가 되며 `aiDraft: true`를 붙인다. 쇼룸형은 상품 소개의 요약 판 맨 위에 영문 라벨 "Comment"와 이 본문을 둔다. 추천 대상, 후기, SNS 반응처럼 셀러가 고쳐 쓰는 초안 자리(`aiDraft`)는 요소에 `aiDraft: true`를 붙인다. AI가 채우는 글은 디테일 요소 섹션의 부위 설명(`items.n.desc`), 상품 소개 본문, 후기 초안이고, 나머지 AI 글 칸은 지금 빈 글과 안내 문구로 나간다. 카피 체계는 별도 카피라이팅 작업에서 정한다.

후기 섹션은 셀러가 고치기 쉽도록 AI가 초안을 넣어 두고, 셀러가 에디터에서 실제 후기로 고치는 방식이다(2026-10-26 오너 결정). 초안은 매번 조금씩 다르게 쓰고, 이름 칸(작성자) 기본값은 "김태희", 별점 기본값은 5개로 둔다.

AI 카피는 수동 텍스트 프리셋과 크기를 구분한다. 서체, 크기, 색, 행간은 카탈로그 글 칸 스타일과 페이지 토큰(글자 스타일, 색감)이 정하며 좌표와 크기는 1000px 캔버스 기준이다.

사진 위에 제목을 얹는 첫 장 디자인(`P01-D09`, `P01-D09-G`)의 상품명은 사진 폭의 70% 안에서 51, 44, 38px 순서로 줄여 두 줄에 맞추고, 38px에서만 세 줄까지 허용한다. 말줄임표를 붙이거나 글을 버리지 않는다. 자리는 컷이 나온 뒤 사진 위 대비를 재서 가운데, 위, 아래 중 3:1 이상으로 읽히는 곳에 두고, 비슷하면 가운데, 아래, 위 순서로 고른다. 세 자리 모두 3:1에 못 미치면 60% 검정(`#111111`) 받침과 흰 글자를 쓴다. 받침 자리는 가운데가 먼저이고, 가운데 받침의 절반 이상이 옷 영역에 걸리면 아래로 간다. 아래도 절반 이상 걸리면 덜 걸리는 쪽에 두고, 걸리는 정도가 같으면 가운데에 둔다. 정본은 카탈로그 `firstTitlePlate`와 `server/app/agents/page_template_contrast.py`다. 쇼룸형 첫 장(`P01-SHOW-01`)은 상품명을 사진 아래 한 줄로 둔다.

AI 카피가 없으면 `text=''`로 두고 `placeholder`에 편집 안내를 저장한다. 안내 문구는 실제 카피로 저장하지 않는다. 미리보기와 다운로드에는 빈 텍스트와 그 안내를 제외하고 높이도 실제 콘텐츠에 맞춰 계산한다. 생성 대기 중에도 이 빈 카피 슬롯은 편집 가능하며, 셀러가 고친 문구·서식을 늦은 생성 결과로 덮어쓰지 않는다. 내부 섹션 이름을 구간 제목으로 자동 노출하지 않는다. 수동 텍스트 프리셋은 셀러가 원하는 위치에 놓는 별도 기능이다.

블록 높이는 실제 콘텐츠가 저장된 높이를 넘을 때만 하단 안전 여백 50을 더해 확장한다. 편집 핸들·선택 표시·안내 UI는 내보내기 콘텐츠에 넣지 않는다. 사진과 텍스트는 각각 편집 가능한 요소로 유지한다.
