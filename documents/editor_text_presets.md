# 에디터 텍스트 프리셋과 카피 슬롯

현재 텍스트 추가·편집 계약이다. 수동 프리셋은 `src/features/editor/presets/textPresets.js`, 검증은 `tests/frontend/text-presets.test.mjs`를 따른다. AI 카피의 기본 스타일과 배치는 `src/lib/editorTextSlots.js`와 `DESIGN.md` §15.5를 따른다. 자동 카피 조립은 `server/app/agents/page_assembler.py`, 목 조립은 `src/mock/db.js`, 생성 대기 화면의 병합은 `src/lib/editorWaitSkeleton.js`가 담당한다.

## 프리셋

| 저장 키 | 화면 이름 | 글자 크기 | 굵기 | 색상 | 행간 |
|---|---|---:|---:|---|---|
| `headline` | 큰 제목 | 40 | 600 | `#0e0d14` | 자동 |
| `subtitle` | 소제목 | 26 | 600 | `#0e0d14` | 자동 |
| `body` | 설명글 | 17 | 400 | `#6b6b73` | 26 |

텍스트 색상 상수는 `TEXT_INK=#0e0d14`, `TEXT_MUTED=#6b6b73`, `TEXT_FAINT=#9a9aa2`다. 정보 블록과 일반 자동 카피도 이 색상을 공유하며, 서버에 복사된 값은 함께 맞춘다. 시그니처 상품명은 아래의 사진 대비색 규칙을 따른다. 패널의 축소 미리보기 크기는 22·17·13이며 실제 크기 순서를 유지한다.

기본 프리셋은 `subtitle`이다. `텍스트 추가`, `T` 단축키, 미지정 키와 알 수 없는 키는 모두 같은 기본값을 쓴다. 별도 일반 텍스트 스타일을 추가하지 않는다. 세 프리셋과 텍스트 추가 버튼은 클릭·드래그를 모두 지원한다.

빠른 스타일 전환은 `size`, `weight`, `color`, `lineHeight`, `tracking`만 바꾼다. 셀러가 정한 폰트·정렬·기울임은 유지한다. 프리셋에 없는 행간·자간은 자동값으로 되돌려 글줄 겹침을 막는다. 활성 프리셋은 대소문자 HEX, 자동 행간과 해당 폰트의 실제 지원 굵기를 정규화한 뒤 판별한다.

## 새 텍스트의 위치와 안내 문구

새 요소는 `type='text'`, `textSizing='auto'`, 기본 폰트 Pretendard, 문구 `내용을 입력하세요.`로 만든다. 첫 편집에서 문구 전체를 선택해 바로 갈아 끼울 수 있게 한다. 기본 좌표는 `(60,80)`, 캔버스 폭은 1000이다. 초기 폭은 글자 크기 × 8.8을 반올림하고, 높이는 지정 행간 또는 글자 크기 × 1.4를 반올림한다. 부착 후 실제 텍스트 크기로 다시 측정한다.

드래그 미리보기와 실제 요소는 같은 크기·좌표 계산을 쓴다. 포인터 위치가 글줄의 세로 중앙에 오며, 요소 전체를 블록 안으로 제한한다. 블록 높이를 모를 때만 세로 상한을 생략한다. 자동 관리 블록에는 일반 텍스트를 추가하지 않는다.

이번 편집에서 새로 만든 일반 텍스트를 수정하지 않았다면 선택·편집을 떠난 뒤 요소를 지운다. 저장과 발행 직전에도 같은 정리를 거쳐 안내 문구가 상세페이지에 실리지 않게 한다. 선택 상태에서 스타일만 바꾸는 동안에는 지우지 않는다. 셀러가 실제로 입력한 같은 문장, 기존 저장 요소, 말풍선, 자동 관리 블록과 카피 슬롯은 일반 안내 문구 정리 대상에서 제외한다.

## 생성 카피와 레이아웃

콘티 순서를 에디터에 보존한다. 여러 이미지의 행 병합은 저장된 섹션·행 정보에 따라 연속된 카드만 묶으며, 내부 섹션 이름을 자동 제목 블록으로 만들지 않는다. 자동 사이즈·세탁·AI 안내 블록은 사진 블록 뒤에 붙는다.

자동 카피는 `sourceBlockId`와 `copyRole`로 해당 콘티 컷에 연결한다. 대기 중 빈 카피 슬롯도 이 연결을 유지해 생성 완료 때 채울 수 있어야 한다. 셀러가 대기 화면에서 직접 수정한 값은 늦게 도착한 생성 결과로 덮어쓰지 않는다. 비어 있는 슬롯을 임의의 판매 문구로 채우지 않는다.

AI 카피는 기본으로 이미지 밖에 배치하며 수동 텍스트 프리셋과 크기를 구분한다. 좌표와 크기는 1000px 캔버스 기준이다. 2026-10-05 오너 결정에 따라 아래 크기와 글줄 높이를 사용한다.

| 용도 | 글자 크기 | 행간 | 배치 |
|---|---:|---:|---|
| 일반 사진의 캡션 소제목 | 44 | 60 | 사진 아래 32px 간격. 기본 본문은 만들지 않는다. |
| 두 번째 컷부터의 꼬리표 | 28 | 38 | 자간 3px. 사진을 64px 내린 자리에 짧은 역할별 라벨을 둔다. |
| 2단·3단 행 라벨 | 30 | 42 | 각 사진 아래. 제품 전체의 앞뒷면은 `FRONT`·`BACK`, 다른 행은 빈 값과 편집 안내를 사용한다. |
| 시그니처 첫 장 상품명 | 최대 60, 최소 44 | 글자 크기의 1.2배 | 사진 위. 자동 생성은 최대 두 줄이며 별도 캡션을 두지 않는다. |

시그니처 상품명은 Pretendard 굵기 700의 실제 글자 폭과 840px 한 줄 예산으로 배치한다. 어절과 허용 구두점 경계에서 줄을 나누고, 44px로도 두 줄에 다 들어가지 않으면 말줄임표를 붙인다. 셀러가 고친 글에는 자동 두 줄 제한을 적용하지 않으며 기존 저장 제목을 다시 배치하지 않는다. 자세한 나눔 규칙은 `DESIGN.md` §15.5.4와 `hookTitleLayout`이 정본이다.

시그니처 상품명 색은 생성 직후 사진 중앙 띠의 상대 명도로 정한 `hookTitleColor`를 사용한다. 값은 `#111111` 또는 `#ffffff`이며, 옛 데이터와 측정 실패에서는 흰색을 쓴다. 셀러가 고친 제목 색은 늦은 결과로 덮어쓰지 않는다.

AI 카피가 없으면 `text=''`로 두고 `placeholder`에 편집 안내를 저장한다. 안내 문구는 실제 카피로 저장하지 않는다. 미리보기와 다운로드에는 빈 텍스트와 그 안내를 제외하고 높이도 실제 콘텐츠에 맞춰 계산한다. 생성 대기 중에도 이 빈 카피 슬롯은 편집 가능하며, 셀러가 고친 문구·서식을 늦은 생성 결과로 덮어쓰지 않는다. 내부 섹션 이름을 구간 제목으로 자동 노출하지 않는다. 수동 텍스트 프리셋은 셀러가 원하는 위치에 놓는 별도 기능이다.

블록 높이는 실제 콘텐츠가 저장된 높이를 넘을 때만 하단 안전 여백 50을 더해 확장한다. 편집 핸들·선택 표시·안내 UI는 내보내기 콘텐츠에 넣지 않는다. 사진과 텍스트는 각각 편집 가능한 요소로 유지한다.
