# 마네킹 사진 구조와 전문 검사, 1차 코드 체크포인트

## 상태

기존 PR #252 이후의 별도 개선이다. 새 기능은 `MANNEQUIN_SPECIALIST_QC=off`가 기본이다. 이 문서는 운영 활성화나 이미지 품질 완성의 승인이 아니다. 배포 manifest, DB, 공유 이미지 모델, 기존 자동 가슴과 원단 및 밑단 보정 설정은 변경하지 않는다.

## 연결한 기능

- fresh 생성의 사진 구조 분석: 이름과 세부 판매 카테고리 대신 사진의 높은 확신 관찰을 전달한다. 원본 앞면의 세 겹치는 영역을 색 보정이나 업스케일 없이 추가한다. 사진의 큰 종류가 선택한 종류와 충돌하면 유료 이미지 생성 전에 중단한다.
- 구조, 디테일, 외관의 세 역할을 독립 호출한다. 상품에 맞는 확인 항목과 원본 및 결과의 확대 영역을 사용한다. 실제 봉제선 개수나 핑크 상품 전용 답은 코드에 넣지 않는다.
- 정면 컷의 뒷면처럼 정상적으로 안 보이는 부분은 결함이 아니다. 단, 요청상 보여야 할 앞면 디자인이 잘못 가려진 경우는 실제 결함이 될 수 있다. 기존 상품 영향도 검사 지시도 이 기준에 맞춘다.
- 마지막 저장 전 검사에서 전문 검사만 중대한 오류를 찾으면 현재 후보를 Sunburst로 편집한다. 기존 검사에서도 오류가 있으면 기존 원본 기반 구제를 유지하면서 양쪽의 수정 근거를 모두 전달한다. 마지막 이미지 슬롯은 한 번을 공유한다.
- 보정본은 세 역할 모두 새로 통과해야 한다. 해당 이미지의 해시와 점수를 함께 저장한다. 기존 매칭, 선언된 핏, 베이스, 시리즈 검사는 해당 설정에 따라 유지한다. 불완전하거나 불합격인 최종 보정본은 저장하지 않는다.
- 거울 원본은 기존 `sourceMirrored`의 정방향 복원 기준을 전문 검사와 편집에도 전달한다. 문자열을 참으로 해석하지 않는다.

## 설정과 범위

| 설정 | 기본값 | 뜻 |
| --- | --- | --- |
| MANNEQUIN_SPECIALIST_QC | off | shadow는 관찰만, enforce는 구조 근거와 검사 및 보정 승인 적용 |
| MANNEQUIN_SPECIALIST_MODEL | gpt-6-astra | 사진 구조와 세 전문 검사 |
| MANNEQUIN_SPECIALIST_TIMEOUT_SECONDS | 120 | 전용 대기 시간. 환경값은 15~180초, 잘못된 값은 120초 |
| MANNEQUIN_SPECIALIST_REPAIR_MODEL | gpt-image-2.5-sunburst | 전문 검사 단독 결함의 후보 편집 |

현재 구조 분석은 요청 내에서 한 번 수행하고 이벤트에 근거와 사용량을 남긴다. 업로드 분석 결과의 영구 캐시와 사진 변경 시 무효화는 구현하지 않았다. 추가 전문 검사는 저장 후보에 세 번, 실제 마지막 보정 시 세 번 더 수행한다. 다른 기존 검사를 대체했다는 의미는 아니다. shadow는 검사 비용이 발생하지만 생성 입력이나 이미지를 바꾸지 않는다.

## 검증

- 격리 서버 테스트: `DATABASE_URL='' SUPABASE_DB_URL='' python -m pytest tests -q --ignore=tests/test_personalization.py`, 4,934개 통과, 78개 skip. DB 쓰기 가능성이 있는 personalization 파일은 제외했다. 기존 Pillow 경고 390건은 변경하지 않았다.
- 별도 코드 리뷰에서 발견한 점수 없는 보정 결과 처리, 거울 원본 기준 누락, 기존 보정 지시 유실을 수정했다. 범위 한정 재리뷰에서 모두 해결됐음을 확인했다.
- 실제 OpenAI 호출: 전문 QC 18회, Sunburst 편집 1회, 사진 구조 분석 1회. HTTP 20회 모두 200, 재시도와 대체 모델 없음. 요청, 실제 입력, 코드 사본과 사용량을 로컬에 보존했다. 이미지 API 응답이 반환 모델명을 제공하지 않는 경우 요청 모델과 구분해 기록했다.
- 추정 비용 $2.505583. QC $2.37067, 편집 $0.072243, 구조 분석 $0.06267. 운영 한 컷 가격이나 청구서 확인 금액은 아니다.
- 실험 QC 대기 시간은 180초였고 응답 기록 중 16건이 30초를 넘었다. 최종 코드에 전문 검사만 120초 기본값을 추가했다. 본문과 이미지 입력은 변하지 않았지만 120초 환경의 별도 유료 재실행은 하지 않았다.

## 운영 적용 전에 남은 문제

1. 세로선이 빠진 핑크 대조를 전문 QC가 통과시켰다.
2. 정상으로 보던 그레이 상의를 목선 차이로 거절했다. 독립 시각 검토에서는 허용 가능한 착용 차이로 봤다.
3. 겹친 가슴선은 자동 편집 후 QC 세 영역 모두 통과했지만, 독립 시각 검토에서는 짧은 잔여 가슴선이 남았다고 판단했다.

따라서 자동 판정이 실제 판매 가능한 품질을 보장한다고 결론낼 수 없다. 이전 성공 핑크와 갈색 바지는 이번 전문 검사와 독립 시각 검토가 모두 통과했다. 다음 실험에서는 원본의 실제 특징 목록과 결과의 해당 부위 연결을 비교하는 방법, 보정 목표의 해소 여부, 정상 착용 변형 허용 범위를 검증한다. 아직 실험하지 않은 다음 방향을 완성 기능으로 표시하지 않는다.

이번 실험은 실제 QC 함수와 보정 요청 helper를 사용했으나 전체 운영 저장과 DB 및 R2 흐름을 실행하지 않았다. 기존 자동 후처리를 모두 켠 전체 생성 흐름, 좌우 반전 실사 입력, 재사용 캐시, 비용과 처리 시간의 운영 계측은 별도 확인이 필요하다. 로컬 비교 보고서의 이름은 `mannequin-visible-fidelity-pr-2026-09-12/report.html`이며 상품 사진은 PR에 포함하지 않는다.
