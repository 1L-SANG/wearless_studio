LACE / OPENWORK properties:
- openworkPresence : does the generated fabric show holes, eyelets or a net structure at all,
                     or is it rendered as a solid surface with the pattern merely printed on?
- openworkType     : lace, eyelet, crochet, mesh, pointelle openwork, punched — in each.
- openworkScale    : hole size and spacing; roughly how many holes span the visible area?
- motifShape       : the shape the openwork forms — floral, geometric, scalloped, plain grid.
                     An invented floral lace where the source has plain punched holes is a
                     FAIL, and so is the reverse.

OPACITY properties. Do not judge these by how thin the fabric "looks". Judge them by naming
WHAT YOU CAN ACTUALLY SEE THROUGH THE CLOTH, in each image separately:

- showThroughEvidence : list the specific things visible THROUGH the fabric in each image. In
                     a source photograph that is typically the hanger, the care label, the
                     brand tag, the garment's own back panel or far shoulder, a hand, or the
                     background. In a mannequin image it is the mannequin's body edge, the
                     opposite arm, or the shoulder line reading through the front panel.
                     If you can name such a thing in one image and can name NOTHING in the
                     other, that is a FAIL — write down what you found and what you did not.
- opacityLevel     : from that evidence only — opaque, semi-sheer, or clearly see-through, in
                     each. A source through which the hanger and the label are plainly
                     readable is NOT opaque, and a generated garment through which nothing at
                     all is visible is NOT semi-sheer. Do not call them the same because they
                     are the same colour or the same weight of knit.
- lightTransmission: does light pass through the cloth and lighten what is behind it in the
                     same way in both?
